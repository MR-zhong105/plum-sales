## 一、Claude Code 相关

### 1. learn-claude-code ⭐73k+

- **说明**: Bash is all you need - 从零到一构建类Claude Code的agent harness
- **语言**: Python
- **价值**: 深入学习Claude Code内部原理
- **首页**: http://learn.shareai.run

### 2. claude-howto ⭐40k+
- **仓库**: https://github.com/luongnv89/claude-howto
- **说明**: 视觉化、示例驱动的Claude Code指南 - 从基础概念到高级智能体
- **语言**: Python
- **价值**: 最佳学习入门资源

### 3. ai-guide ⭐18k+
- **仓库**: https://github.com/liyupi/ai-guide

- **内容**: DeepSeek/GPT/Claude/Gemini/GLM教程、Agent Skills/RAG/MCP/A2A、AI编程教程
- **语言**: JavaScript
- **首页**: https://ai.codefather.cn

## 🔧 如何合并视频

### 方法1: 双击批处理文件 (推荐)
1. 打开文件夹: `H:\Obsidian Vault\AI开发工具\`
2. 双击运行 `merge.bat`
3. 等待合并完成
4. 视频会自动打开

### 方法2: 使用剪映 (最简单)
1. 打开剪映
2. 导入所有 `sequence*.mp4` 文件
3. 按顺序排列到时间线
4. 导出视频

### 方法3: 手动运行 FFmpeg
打开命令提示符，运行：
```cmd
cd "H:\Obsidian Vault\AI开发工具\output"
"C:\Program Files\ShareX\ffmpeg.exe" -f concat -safe 0 -i concat.txt -c copy final.mp4
```

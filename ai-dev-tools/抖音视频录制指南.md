## 🎬 录制步骤

### 方法1: 浏览器直接录制

#### 步骤1: 打开PPT
```bash
# 文件位置
H:\Obsidian Vault\AI开发工具\AI编程助手大比拼-抖音风格PPT.html
```

#### 步骤2: 全屏模式
- 按 `F11` 进入全屏
- 或使用浏览器扩展 (如 Full Page Screen Capture)

#### 步骤3: 选择录屏软件
推荐软件：
| 软件 | 价格 | 特点 |
|------|------|------|
| OBS Studio | 免费 | 专业录屏，可添加音频 |
| ShareX | 免费 | 轻量快捷，Windows自带 |
| 剪映 | 免费 | 内置录屏+剪辑 |
| Bandicam | 付费 | 高质量录制 |

#### 步骤4: 开始录制
```
1. 打开录屏软件
2. 选择录制区域 (全屏或浏览器窗口)
3. 开启系统音频 (播放BGM)
4. 按 F5 刷新页面
5. 开始翻页演示 (使用 ← → 键或点击)
6. 录制完成后停止
```

## ✂️ 后期剪辑

### 使用剪映 (推荐)

#### 步骤1: 导入视频
```
1. 打开剪映
2. 点击"开始创作"
3. 导入录制的PPT视频
```

#### 步骤2: 添加字幕
```
1. 点击"文本" → "新建文本"
2. 输入字幕内容
3. 调整位置、字体、颜色
4. 使用"识别字幕"功能自动添加
```

#### 步骤3: 添加音乐
```
1. 点击"音频" → "音乐"
2. 选择BGM
3. 调整音量 (20-30%)
4. 设置淡入淡出
```

#### 步骤4: 添加特效
```
1. 点击"特效" → "画面特效"
2. 选择适合的特效
3. 调整强度
```

#### 步骤5: 导出
```
1. 点击右上角"导出"
2. 选择分辨率 (1080p)
3. 选择帧率 (30fps)
4. 导出MP4文件
```

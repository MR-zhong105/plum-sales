## 快速开始

### Claude Code 入门
```bash
# 安装
npm install -g @anthropic-ai/claude-code

# 启动
claude

# 切换模型
/model
```

### Codex CLI 入门
```bash
# 安装
npm install -g @openai/codex

# 启动
codex

# 直接执行
codex "Fix the bug in auth.js"
```

## 学习路径

### 初级
1. 阅读 [Claude Code 学习笔记](./Claude Code 学习笔记.md)
2. 尝试基本命令和配置
3. 了解 Hooks 系统

### 中级
1. 学习 [MCP 扩展开发](./Claude Code MCP 扩展开发.md)
2. 配置自定义技能
3. 使用智能体并行处理

### 高级
1. 学习 [工作流编排](./Claude Code 多智能体工作流编排.md)
2. 开发自定义 MCP 服务器
3. 设计复杂自动化流程

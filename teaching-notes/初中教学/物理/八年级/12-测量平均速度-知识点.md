# 测量平均速度 知识点

## 基本信息

- **学科**: 物理
- **年级**: 八年级
- **所属单元**: 第一章 机械运动
- **重要程度**: 重点

## 知识内容

### 1. 实验原理

**原理**：v = s/t

### 2. 实验器材

- 斜面
- 小车
- 刻度尺
- 停表
- 金属片（挡片）

### 3. 实验步骤

1. 安装实验器材，使斜面保持较小的坡度
2. 用刻度尺测量小车通过的路程s
3. 用停表测量小车运动的时间t
4. 计算平均速度v = s/t
5. 改变路程，重复实验

### 4. 注意事项

1. 斜面坡度要小，便于测量时间
2. 小车从斜面顶端由静止释放
3. 金属片放在斜面底端，便于准确计时
4. 计时要准确，听到小车撞击金属片的声音立即停止计时

### 5. 数据处理

| 路段 | 路程s/m | 时间t/s | 平均速度v/(m/s) |
|------|---------|---------|-----------------|
| 上半段 |       |         |                 |
| 下半段 |       |         |                 |
| 全程 |         |         |                 |

### 6. 实验结论

- 小车在斜面上做变速直线运动
- 下半段平均速度最大，上半段最小
- v下 > v上

## 典型例题

**例题1**：在"测量物体运动的平均速度"实验中，下列说法正确的是（  ）
A. 斜面坡度越大越好
B. 金属片的作用是便于测量路程
C. 小车从斜面顶端由静止释放
D. 全程平均速度等于各段平均速度之和

**答案**：C

**例题2**：如图，小车从斜面顶端滑下，测得全程路程为1.2m，上半程路程为0.6m，全程时间为2.4s，上半程时间为1.6s。求：
(1) 上半程的平均速度
(2) 下半程的平均速度
(3) 全程的平均速度

**解**：
(1) v上 = s上/t上 = 0.6/1.6 = 0.375 m/s
(2) s下 = 0.6m，t下 = 2.4 - 1.6 = 0.8s
    v下 = s下/t下 = 0.6/0.8 = 0.75 m/s
(3) v全 = s全/t全 = 1.2/2.4 = 0.5 m/s

**例题3**：在实验中，若小车过了起点才开始计时，则测得的速度偏______；若小车过了终点才开始计时，则测得的速度偏______。

**答案**：大；小

## 易错点提醒

### 易错点1：斜面坡度过大
**错误**：斜面坡度越大越好
**正确**：坡度要小，便于测量时间

### 易错点2：计时不准确
**错误**：看到小车释放就开始计时
**正确**：应该听到小车撞击金属片的声音就停止计时

### 易错点3：数据处理错误
**错误**：平均速度等于各段速度平均值
**正确**：平均速度等于总路程除以总时间

# 质量与密度 知识点

## 基本信息

- **学科**: 物理
- **年级**: 八年级
- **所属单元**: 第六章 质量与密度
- **重要程度**: 重点

## 知识内容

### 1. 质量

**定义**：物体所含物质的多少叫做质量

**单位**：
- 主单位：千克(kg)
- 常用单位：吨(t)、克(g)、毫克(mg)
- 换算：1t = 10³kg，1kg = 10³g，1g = 10³mg

**性质**：质量是物体本身的属性，不随形状、状态、位置、温度改变

**测量工具**：天平

**天平使用**：
1. 放：放在水平台上
2. 移：游码移到标尺左端零刻度线
3. 调：调节平衡螺母，使指针指在分度盘中央
4. 称：左物右码，用镊子夹取砝码
5. 读：m物 = m码 + m游

**注意**：
- 不能超过天平的测量范围
- 保持天平干燥清洁
- 砝码要用镊子夹取

### 2. 密度

**定义**：某种物质组成的物体的质量与它的体积之比叫做这种物质的密度

**公式**：ρ = m/V

**单位**：
- 国际单位：千克/米³(kg/m³)
- 常用单位：克/厘米³(g/cm³)
- 换算：1g/cm³ = 1000kg/m³

**水的密度**：ρ水 = 1.0×10³kg/m³ = 1g/cm³

**物理意义**：1m³水的质量是1.0×10³kg

### 3. 密度的应用

**鉴别物质**：不同物质密度一般不同

**计算质量**：m = ρV（体积不方便测量时）

**计算体积**：V = m/ρ（质量不方便测量时）

### 4. 密度与温度

**一般规律**：温度升高，体积膨胀，密度减小

**特例**：水在0~4℃时，温度升高，体积缩小，密度增大（反常膨胀）

**应用**：
- 冬天水管冻裂
- 锅炉不能装得太满

### 5. 密度与状态

**规律**：同种物质，状态不同，密度不同

**实例**：
- 水和冰：ρ水 > ρ冰
- 冰熔化成水，质量不变，体积减小，密度增大

## 典型例题

**例题1**：关于质量，下列说法正确的是（  ）
A. 把铁块加热，质量变大
B. 把铁块切成两半，质量变小
C. 把铁块从地球带到月球，质量不变
D. 把铁块熔化成铁水，质量变小

**答案**：C

**例题2**：关于密度，下列说法正确的是（  ）
A. 密度与质量成正比
B. 密度与体积成反比
C. 密度是物质的一种特性，与质量和体积无关
D. 同种物质的密度一定相同

**答案**：C

**例题3**：一个质量为54g的铝球，体积是30cm³，判断这个铝球是空心还是实心？（ρ铝=2.7g/cm³）

**解法一（比较密度）**：
ρ球 = m/V = 54g/30cm³ = 1.8g/cm³
因为 ρ球 < ρ铝，所以是空心的

**解法二（比较体积）**：
V实 = m/ρ铝 = 54g/2.7g/cm³ = 20cm³
因为 V球 > V实，所以是空心的

**解法三（比较质量）**：
m实 = ρ铝×V球 = 2.7g/cm³×30cm³ = 81g
因为 m球 < m实，所以是空心的

**空心体积**：V空 = V球 - V实 = 30cm³ - 20cm³ = 10cm³

## 易错点提醒

### 易错点1：质量随形状改变
**错误**：把铁丝弯成环，质量改变
**正确**：质量不随形状改变

### 易错点2：密度与质量体积有关
**错误**：密度与质量成正比，与体积成反比
**正确**：密度是物质特性，与质量和体积无关

### 易错点3：空心判断错误
**错误**：只看密度大小
**正确**：要用三种方法之一综合判断

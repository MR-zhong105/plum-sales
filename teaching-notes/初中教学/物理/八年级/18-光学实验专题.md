# 光学实验专题

> 八年级物理光学核心实验

## 知识内容

### 1. 探究光的反射定律

**实验装置**：平面镜、激光笔、白色光屏、量角器

**结论**：
- 反射光线、入射光线和法线在同一平面内
- 反射光线和入射光线分居法线两侧
- 反射角等于入射角

**注意事项**：
- 光屏要垂直于平面镜
- 入射光线、反射光线、法线在同一平面

### 2. 探究平面镜成像特点

**实验装置**：玻璃板、两支相同的蜡烛、刻度尺、白纸

**结论**：
- 像与物大小相等
- 像与物到镜面距离相等
- 像与物的连线与镜面垂直
- 成虚像

**玻璃板代替平面镜的原因**：便于确定像的位置

**两支相同蜡烛的目的**：比较像与物的大小关系

### 3. 探究光的折射规律

**结论**：
- 光从空气斜射入水中时，折射角小于入射角
- 光从水斜射入空气时，折射角大于入射角
- 垂直入射时，传播方向不变

### 4. 探究凸透镜成像规律

**实验装置**：凸透镜、光具座、蜡烛、光屏

**规律**：
| 物距u | 像距v | 像的性质 | 应用 |
|-------|-------|---------|------|
| u>2f | f<v<2f | 倒立缩小实像 | 照相机 |
| u=2f | v=2f | 倒立等大实像 | 测焦距 |
| f<u<2f | v>2f | 倒立放大实像 | 投影仪 |
| u=f | 不成像 | - | - |
| u<f | | 正立放大虚像 | 放大镜 |

**口诀**：一倍焦距分虚实，二倍焦距分大小；物近像远像变大，物远像近像变小

## 典型例题

**例题1**：（中考题）在"探究平面镜成像特点"实验中，用玻璃板代替平面镜的目的是____。
**答案**：便于确定像的位置

**例题2**：凸透镜焦距为10cm，当物体距透镜15cm时，成像特点是____。
**答案**：倒立、放大的实像（f<u<2f）

## 易错点提醒

### 易错点1：反射角与入射角关系
**正确**：反射角等于入射角，不是入射角等于反射角（因果倒置）

### 易错点2：凸透镜成像规律记混
**技巧**：物近像远像变大（实像情况下）

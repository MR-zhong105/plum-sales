# 力学综合专题

> 八年级物理力学知识汇总

## 知识内容

### 1. 力的基本概念

| 概念 | 说明 |
|------|------|
| 力的定义 | 物体对物体的作用 |
| 力的作用效果 | 改变物体运动状态、改变物体形状 |
| 力的三要素 | 大小、方向、作用点 |
| 力的示意图 | 用带箭头的线段表示力 |

### 2. 重力

**公式**：G = mg（g=9.8N/kg≈10N/kg）
**方向**：竖直向下
**作用点**：重心

### 3. 摩擦力

**影响因素**：压力大小、接触面粗糙程度
**方向**：与相对运动（或相对运动趋势）方向相反
**增大方法**：增大压力、增大接触面粗糙程度
**减小方法**：减小压力、减小接触面粗糙程度、变滑动为滚动、加润滑剂

### 4. 压强

**固体压强**：p = F/S
**液体压强**：p = ρgh
**大气压强**：标准大气压p₀=1.013×10⁵Pa

### 5. 浮力

**阿基米德原理**：F浮 = G排 = ρ液gV排
**浮沉条件**：
- F浮>G物→上浮→漂浮（F浮=G物）
- F浮=G物→悬浮
- F浮<G物→下沉

### 6. 功和机械能

**功**：W = Fs（力与距离方向一致）
**功率**：P = W/t = Fv
**机械能**：动能+势能
**机械能守恒**：只有动能和势能转化时，机械能总量不变

## 典型例题

**例题1**：一个质量为50kg的物体放在水平地面上，与地面接触面积为0.02m²。求：
(1) 物体对地面的压力；
(2) 物体对地面的压强。
**解**：(1) F=G=mg=50×10=500N
    (2) p=F/S=500/0.02=2.5×10⁴Pa

**例题2**：一个体积为100cm³的物体浸没在水中，受到的浮力是多少？
**解**：F浮=ρ水gV排=1.0×10³×10×100×10⁻⁶=1N

## 易错点提醒

### 易错点1：压力一定等于重力
**正确**：只有在水平面上且无其他外力时，F压=G

### 易错点2：浮力与深度有关
**正确**：浸没后浮力与深度无关，只与ρ液和V排有关

# 机械运动 教案

## 基本信息

- **学科**: 物理
- **年级**: 八年级
- **单元**: 第一章 机械运动
- **课题**: 1.1 长度和时间的测量
- **课时**: 1课时

## 教学目标

### 知识与技能
- 知道长度的国际单位及常用单位
- 会使用刻度尺测量长度
- 知道时间的国际单位及常用单位
- 能用秒表测量时间

### 过程与方法
- 通过观察和实验，学习测量方法
- 体会估测在日常生活中的应用

### 情感态度与价值观
- 养成认真细致的学习习惯
- 认识测量在科学探究中的重要性

## 教学重难点

**重点**: 刻度尺的正确使用
**难点**: 长度单位的换算

## 教学过程

### 一、导入新课（5分钟）

**情境引入**：
展示操场跑道、教室长度等图片，提问：
- 如何测量操场的长度？
- 如何测量黑板的宽度？
- 测量的工具是什么？

**引出课题**：长度和时间的测量

### 二、新课讲授（25分钟）

#### 1. 长度的测量

**单位体系**：
```
千米(km) → 米(m) → 分米(dm) → 厘米(cm) → 毫米(mm) → 微米(μm) → 纳米(nm)
          ÷1000      ÷10       ÷10       ÷10       ÷1000      ÷1000
```

**常用估测**：
- 中学生身高：约1.6m
- 课桌高度：约0.8m
- 铅笔长度：约18cm
- 头发直径：约70μm

**刻度尺的使用**：
1. **选**：根据测量要求选择适当的刻度尺
2. **看**：观察零刻度线、量程、分度值
3. **放**：刻度尺要放正，有刻度的一边紧贴被测物体
4. **读**：视线要正对刻度线，估读到分度值的下一位
5. **记**：记录数字和单位

**注意**：零刻度线磨损时，可从其他整刻度线开始测量

#### 2. 时间的测量

**单位体系**：
```
小时(h) → 分(min) → 秒(s) → 毫秒(ms)
          ÷60      ÷60      ÷1000
```

**测量工具**：
- 古代：日晷、沙漏
- 现代：钟表、秒表
- 实验室：停表

#### 3. 误差

**概念**：测量值与真实值之间的差异
**原因**：测量工具、测量方法、测量者
**减小方法**：多次测量取平均值

### 三、课堂练习（10分钟）

**练习1**：完成单位换算
- 2.5m = ____ cm
- 3600s = ____ min = ____ h
- 0.5μm = ____ nm

**练习2**：刻度尺读数
展示刻度尺测量图片，让学生读数并指出错误

### 四、课堂小结（3分钟）

1. 长度单位换算关系
2. 刻度尺的正确使用方法
3. 误差的概念及减小方法

### 五、布置作业（2分钟）

- 教材P13 练习1-3
- 用刻度尺测量课本长和宽，记录3次数据

## 板书设计

```
1.1 长度和时间的测量

一、长度的测量
   单位：m（基本单位）
   换算：1km=10³m, 1m=10²cm=10³mm=10⁶μm=10⁹nm
   
二、刻度尺的使用
   选 → 看 → 放 → 读 → 记
   
三、时间的测量
   单位：s（基本单位）
   工具：停表
   
四、误差
   测量值 ≠ 真实值
   减小：多次测量取平均值
```

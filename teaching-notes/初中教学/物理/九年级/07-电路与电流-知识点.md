# 电路与电流 知识点

## 知识内容

### 1. 电荷

**两种电荷**：
- 正电荷：丝绸摩擦过的玻璃棒所带的电荷
- 负电荷：毛皮摩擦过的橡胶棒所带的电荷

**电荷间作用规律**：同种电荷相互排斥，异种电荷相互吸引

**验电器**：检验物体是否带电，原理是同种电荷相互排斥

### 2. 电流

**定义**：电荷的定向移动形成电流

**方向规定**：正电荷定向移动的方向为电流方向（与自由电子定向移动方向相反）

**形成条件**：
- 有电源（提供电压）
- 电路闭合

**单位**：安培（A），1A = 1000mA = 10⁶μA

### 3. 电路

**组成**：电源、用电器、开关、导线

**三种状态**：
| 状态 | 特点 |
|------|------|
| 通路 | 处处连通，有电流 |
| 断路 | 某处断开，无电流 |
| 短路 | 电源两极直接连通，电流很大（危险！） |

**串联电路**：元件逐个顺次连接
- 电流：I = I₁ = I₂
- 电压：U = U₁ + U₂
- 电阻：R = R₁ + R₂

**并联电路**：元件并列连接
- 电流：I = I₁ + I₂
- 电压：U = U₁ = U₂
- 电阻：1/R = 1/R₁ + 1/R₂

### 4. 电流表的使用

- 串联在被测电路中
- 电流从正接线柱流入，负接线柱流出
- 不允许直接接在电源两极
- 先选大量程试触，再选择合适的量程

## 典型例题

**例题1**：（中考题）关于电流，下列说法正确的是（）
A. 电荷移动就形成电流
B. 电流方向与正电荷定向移动方向相同
C. 电流方向与负电荷定向移动方向相同
D. 电路中有电压就一定有电流
**答案**：B

**例题2**：串联电路中，两个电阻R₁=10Ω，R₂=20Ω，电源电压6V，求电路中的电流。
**解**：R总=10+20=30Ω，I=U/R总=6/30=0.2A

## 易错点提醒

### 易错点1：有电压就有电流
**正确**：有电压且电路闭合才有电流

### 易错点2：电流方向与电子移动方向相同
**正确**：电流方向与自由电子（负电荷）定向移动方向相反

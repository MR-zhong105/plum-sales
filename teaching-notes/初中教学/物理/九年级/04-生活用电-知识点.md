# 生活用电 知识点

## 基本信息

- **学科**: 物理
- **年级**: 九年级
- **所属单元**: 第十九章 生活用电
- **重要程度**: 重点

## 知识内容

### 1. 家庭电路的组成

**组成部分**：
```
进户线 → 电能表 → 总开关 → 保险装置 → 用电器、插座
```

**各部分作用**：
| 元件 | 作用 | 安装位置 |
|------|------|----------|
| 进户线 | 提供电能 | 户外 |
| 电能表 | 测量用电量 | 干路最前端 |
| 总开关 | 控制整个电路 | 电能表后 |
| 保险装置 | 保护电路 | 总开关后 |
| 用电器 | 消耗电能 | 支路 |
| 插座 | 连接可移动用电器 | 并联在电路中 |

### 2. 火线和零线

**进户线**：
- 火线：与大地之间有220V电压
- 零线：与大地之间无电压

**测电笔**：
- 用途：辨别火线和零线
- 结构：笔尖金属体、电阻、氖管、弹簧、笔尾金属体
- 使用方法：手接触笔尾金属体，笔尖接触电线
- 现象：氖管发光→火线；不发光→零线

### 3. 触电类型

**单相触电**：人体接触火线
- 电流路径：火线→人体→大地

**双线触电**：人体同时接触火线和零线
- 电流路径：火线→人体→零线

**高压触电**：
- 电弧触电：靠近高压带电体
- 跨步电压触电：靠近高压线落地处

### 4. 安全用电原则

1. 不接触低压带电体
2. 不靠近高压带电体
3. 更换灯泡、搬动电器前断开电源
4. 不使用破损的电线
5. 不在电线上晾衣服
6. 发现有人触电，先切断电源再施救

### 5. 保险丝

**材料**：铅锑合金（电阻率大、熔点低）

**作用**：当电流过大时，自动熔断，切断电路

**选择原则**：
- 额定电流等于或略大于电路正常工作时的最大电流
- 不能用铜丝、铁丝代替保险丝

**保险丝熔断原因**：
1. 短路
2. 过载（用电器总功率过大）

### 6. 三线插头

**组成**：
- 火线（L）
- 零线（N）
- 地线（E）

**作用**：将用电器的金属外壳与大地连接，防止触电

**安装原则**：
- 有金属外壳的用电器必须接地
- 开关接在火线上
- 螺丝口灯泡的螺旋套接零线

## 典型例题

**例题1**：关于家庭电路，下列说法正确的是（  ）
A. 电能表要安装在总开关的后面
B. 保险丝熔断一定是短路造成的
C. 家庭电路中的用电器都是串联的
D. 使用测电笔时，手不能接触笔尾金属体

**答案**：B

**解析**：
A错误：电能表应安装在总开关前面
B正确：保险丝熔断原因是短路或过载
C错误：用电器都是并联的
D错误：使用测电笔时，手必须接触笔尾金属体

**例题2**：小明家中有以下用电器：空调2000W、冰箱150W、电视100W、洗衣机500W、电灯100W。所有用电器同时工作时，电路中的总电流是多少？（设电压为220V）

**解**：
总功率 P = 2000 + 150 + 100 + 500 + 100 = 2850W
总电流 I = P/U = 2850/220 ≈ 12.95A

**例题3**：为什么不能用铜丝代替保险丝？

**答案**：
铜丝的电阻率小、熔点高，当电路中电流过大时，铜丝不易熔断，不能起到保护电路的作用，可能导致火灾。

## 易错点提醒

### 易错点1：测电笔使用错误
**错误**：手不能接触笔尾金属体
**正确**：手必须接触笔尾金属体

### 易错点2：保险丝选择错误
**错误**：保险丝越粗越好
**正确**：额定电流等于或略大于正常工作电流

### 易错点3：触电抢救错误
**错误**：直接用手拉触电者
**正确**：先切断电源，再用绝缘物体挑开电线

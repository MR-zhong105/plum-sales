# 电学实验综合专题

> 九年级物理电学核心实验汇总

## 知识内容

### 1. 伏安法测电阻（详细版）

**实验器材**：电源、开关、滑动变阻器、待测电阻、电流表、电压表、导线

**电路连接**：
- 电流表串联，电压表并联
- 滑动变阻器"一上一下"
- 开关断开，滑片移到阻值最大处

**数据记录表格**：
| 实验次数 | 电压U/V | 电流I/A | 电阻R/Ω |
|---------|---------|---------|---------|
| 1 | | | |
| 2 | | | |
| 3 | | | |

**注意事项**：
- 电表量程选择：先大量程试触
- 滑动变阻器作用：保护电路+改变电压
- 多次测量求平均值减小误差

### 2. 测量小灯泡电功率

**与测电阻实验的区别**：
| 对比项 | 测电阻 | 测功率 |
|--------|--------|--------|
| 原理 | R=U/I | P=UI |
| 多次测量目的 | 求平均值减小误差 | 测量不同电压下的功率 |
| 能否求平均值 | 能 | 不能 |

**额定功率测量**：
- 调节滑片使电压表示数=额定电压
- 读出电流表示数
- P额=U额×I额

### 3. 探究电流与电压、电阻关系

**控制变量法**：
- 探究I与U：保持R不变，调节滑片改变U
- 探究I与R：保持U不变，更换不同R，调节滑片保持U不变

**图像法**：
- I-U图像：过原点的直线（正比例）
- I-1/R图像：过原点的直线（正比例）

### 4. 探究焦耳定律

**实验装置**：两个密封容器（内有电阻丝）、U形管、电源

**控制变量法**：
- 探究Q与I：保持R、t不变，改变I
- 探究Q与R：保持I、t不变，改变R
- 探究Q与t：保持I、R不变，改变t

**转换法**：通过U形管液面高度差反映产生热量的多少

### 5. 电学实验故障分析

| 现象 | 故障原因 | 排查方法 |
|------|---------|---------|
| 电流表无示数，电压表有示数 | 待测电阻断路 | 检查电阻两端接线 |
| 电流表有示数，电压表无示数 | 待测电阻短路 | 检查电阻是否短路 |
| 电表指针反向偏转 | 正负接线柱接反 | 对调接线柱 |
| 电表指针超出量程 | 量程选择过小 | 换大量程 |
| 灯泡不亮，电流表有示数 | 灯泡短路 | 检查灯泡 |
| 灯泡不亮，电流表无示数 | 电路断路 | 逐个检查 |

## 典型例题

**例题1**：（中考题）在"伏安法测电阻"实验中，闭合开关后，发现电流表有示数，电压表无示数，则故障可能是（）
A. 电阻R断路  B. 电阻R短路  C. 滑动变阻器断路  D. 电流表断路
**答案**：B

**例题2**：在"测量小灯泡额定功率"实验中，小灯泡额定电压为3.8V，电阻约为10Ω。
(1) 电源电压至少为____V
(2) 滑动变阻器应选____（A:10Ω 1A 或 B:50Ω 0.5A）
(3) 调节滑片使电压表示数为3.8V，电流表示数为0.36A，则额定功率为____W
**答案**：(1) 6  (2) B  (3) 1.368W

## 易错点提醒

### 易错点1：测功率时求平均值
**正确**：不同电压下功率不同，不能求平均值

### 易错点2：滑动变阻器作用答不全
**正确**：保护电路+改变电压/电流

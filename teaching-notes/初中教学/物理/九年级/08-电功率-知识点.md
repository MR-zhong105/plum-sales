# 电功率 知识点

## 知识内容

### 1. 电功

**定义**：电流所做的功

**公式**：W = UIt = I²Rt = U²t/R

**单位**：焦耳（J），千瓦时（kW·h）
　　1 kW·h = 3.6×10⁶ J

### 2. 电功率

**定义**：电流在单位时间内所做的功

**公式**：P = W/t = UI = I²R = U²/R

**单位**：瓦特（W），千瓦（kW），1kW = 1000W

**额定功率**：用电器在额定电压下工作时的功率
**实际功率**：用电器在实际电压下工作时的功率

### 3. 焦耳定律

**内容**：电流通过导体产生的热量跟电流的平方成正比，跟导体的电阻成正比，跟通电时间成正比

**公式**：Q = I²Rt

**纯电阻电路**：Q = W = UIt = I²Rt = U²t/R

### 4. 电学综合计算

**串联电路**：
- 电流处处相等，电压按电阻分配
- P总 = P₁ + P₂
- 电阻越大，功率越大（P=I²R）

**并联电路**：
- 电压处处相等，电流按电阻反比分配
- P总 = P₁ + P₂
- 电阻越小，功率越大（P=U²/R）

### 5. 安全用电

- 不接触低压带电体，不靠近高压带电体
- 更换灯泡、检修电路前先断开开关
- 保险丝用电阻率大、熔点低的铅锑合金制成

## 典型例题

**例题1**：（中考题）标有"220V 40W"的灯泡，正常工作时：
(1) 电流是多少？
(2) 电阻是多少？
(3) 工作10小时消耗多少电能？
**解**：
(1) I = P/U = 40/220 ≈ 0.18A
(2) R = U²/P = 220²/40 = 1210Ω
(3) W = Pt = 40W × 10h = 0.4kW × 10h = 0.4kW·h

**例题2**：两盏灯L₁"220V 100W"和L₂"220V 60W"串联接入220V电路，哪盏灯更亮？
**解**：R₁=U²/P₁=484Ω，R₂=U²/P₂=807Ω
　　串联I相同，P=I²R，R₂>R₁，所以L₂更亮

## 易错点提醒

### 易错点1：额定功率与实际功率混淆
**正确**：额定功率是固定值，实际功率随实际电压变化

### 易错点2：串联并联功率判断
**技巧**：串联看电阻（P=I²R，电阻大功率大），并联看电阻（P=U²/R，电阻小功率大）

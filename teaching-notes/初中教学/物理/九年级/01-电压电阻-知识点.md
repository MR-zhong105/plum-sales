# 电压 电阻 知识点

## 基本信息

- **学科**: 物理
- **年级**: 九年级
- **所属单元**: 第十六章 电压 电阻
- **重要程度**: 重点

## 知识内容

### 1. 电压

**定义**：电压是使电荷定向移动形成电流的原因

**符号**：U

**单位**：
- 主单位：伏特(V)
- 常用单位：千伏(kV)、毫伏(mV)、微伏(μV)
- 换算：1kV = 10³V，1V = 10³mV，1mV = 10³μV

**常见电压值**：
| 电源 | 电压 |
|------|------|
| 一节干电池 | 1.5V |
| 家庭电路 | 220V |
| 对人体安全电压 | 不高于36V |
| 蓄电池 | 2V |

**测量工具**：电压表

**使用方法**：
1. 电压表要并联在被测电路两端
2. 电流从"+"接线柱流入，"-"接线柱流出
3. 被测电压不超过量程
4. 可以直接接在电源两极上

### 2. 电阻

**定义**：导体对电流的阻碍作用叫做电阻

**符号**：R

**单位**：
- 主单位：欧姆(Ω)
- 常用单位：千欧(kΩ)、兆欧(MΩ)
- 换算：1MΩ = 10³kΩ = 10⁶Ω

**影响因素**：
| 因素 | 关系 | 说明 |
|------|------|------|
| 材料 | 不同材料电阻不同 | 铜的电阻比铁小 |
| 长度 | 越长电阻越大 | 同种材料、横截面积相同时 |
| 横截面积 | 越大电阻越小 | 同种材料、长度相同时 |
| 温度 | 大多数金属温度越高电阻越大 | 半导体相反 |

**测量工具**：伏安法（电压表+电流表）

### 3. 滑动变阻器

**原理**：通过改变接入电路中电阻线的长度来改变电阻

**作用**：
1. 保护电路
2. 改变电路中的电流
3. 改变部分电路两端的电压

**使用方法**：
1. 串联在电路中
2. 接线柱"一上一下"
3. 闭合开关前，滑片应放在阻值最大处

### 4. 欧姆定律

**内容**：导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比

**公式**：I = U/R

**变形公式**：
- U = IR
- R = U/I

**注意**：
- R = U/I只是计算式，电阻是导体本身属性
- 应用时要统一单位

## 典型例题

**例题1**：关于电压，下列说法正确的是（  ）
A. 电路两端有电压，电路中就一定有电流
B. 电路中要有持续电流，必须有电源
C. 电源是提供电流的装置
D. 电压是形成电流的原因，有电压就一定有电流

**答案**：B

**例题2**：一段导体两端电压为4V时，通过导体的电流为0.5A，导体的电阻为____Ω；当导体两端电压为0V时，导体的电阻为____Ω。

**答案**：8；8

**解析**：R = U/I = 4V/0.5A = 8Ω。电阻是导体本身属性，与电压无关。

**例题3**：如图，电源电压不变，闭合开关S，当滑动变阻器滑片P向右移动时，电流表和电压表的示数如何变化？

**答案**：电流表示数变小，电压表示数不变。

## 易错点提醒

### 易错点1：电压表串联使用
**错误**：电压表串联在电路中
**正确**：电压表要并联在被测电路两端

### 易错点2：电阻随电压变化
**错误**：电压越大，电阻越大
**正确**：电阻是导体本身属性，与电压无关

### 易错点3：滑动变阻器接法错误
**错误**：同时接上面两个接线柱
**正确**：要"一上一下"接线

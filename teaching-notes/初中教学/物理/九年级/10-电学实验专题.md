# 电学实验专题

> 九年级物理中考核心实验

## 知识内容

### 1. 伏安法测电阻

**原理**：R = U/I

**电路**：电源、开关、滑动变阻器、待测电阻、电流表、电压表

**滑动变阻器作用**：
- 保护电路
- 改变待测电阻两端电压，多次测量求平均值减小误差

**注意事项**：
- 连接电路时开关断开
- 闭合开关前滑片移到阻值最大处
- 电流表串联，电压表并联
- 电流从正接线柱流入

### 2. 伏安法测小灯泡电功率

**原理**：P = UI

**与测电阻的区别**：
- 测电阻：多次测量求平均值减小误差
- 测功率：测量不同电压下的实际功率，不能求平均值

**额定功率**：在额定电压下的功率
**实际功率**：在实际电压下的功率

### 3. 探究电流与电压、电阻的关系

**控制变量法**：
- 探究I与U关系：保持R不变，改变U
- 探究I与R关系：保持U不变，改变R

**结论**：
- 电阻一定时，电流与电压成正比
- 电压一定时，电流与电阻成反比

### 4. 探究焦耳定律

**控制变量法**：
- 探究Q与I关系：保持R、t不变
- 探究Q与R关系：保持I、t不变
- 探究Q与t关系：保持I、R不变

**结论**：Q = I²Rt

### 5. 电学实验常见故障

| 现象 | 原因 |
|------|------|
| 电流表无示数，电压表有示数 | 待测电阻断路 |
| 电流表有示数，电压表无示数 | 待测电阻短路 |
| 电流表、电压表都有示数但很小 | 滑动变阻器阻值太大 |
| 电表指针反向偏转 | 正负接线柱接反 |
| 电表指针超出量程 | 量程选择太小 |

## 典型例题

**例题1**：（中考题）在"伏安法测电阻"实验中，某同学连接电路后闭合开关，发现电流表有示数，电压表无示数，则故障可能是（）
A. 电阻R断路  B. 电阻R短路  C. 滑动变阻器断路  D. 电流表断路
**答案**：B

**例题2**：在"测量小灯泡额定功率"实验中，小灯泡额定电压为2.5V，正常发光时电阻约为10Ω。
(1) 电源电压至少为____V
(2) 滑动变阻器应选____（A:10Ω 1A 或 B:50Ω 0.5A）
(3) 调节滑片使电压表示数为2.5V，电流表示数为0.26A，则额定功率为____W
**答案**：(1) 3  (2) B  (3) 0.65W

## 易错点提醒

### 易错点1：测电阻与测功率的实验目的混淆
**正确**：测电阻求平均值减小误差；测功率不能求平均值（不同电压下功率不同）

### 易错点2：滑动变阻器作用答不全
**正确**：保护电路+改变电压/电流，实现多次测量

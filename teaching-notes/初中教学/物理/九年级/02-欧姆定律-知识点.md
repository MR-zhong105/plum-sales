# 欧姆定律 知识点

## 基本信息

- **学科**: 物理
- **年级**: 九年级
- **所属单元**: 第十七章 欧姆定律
- **重要程度**: 重点

## 知识内容

### 1. 欧姆定律

**内容**：导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比

**公式**：I = U/R

**适用条件**：
- 纯电阻电路
- 同一导体（或同一电路）
- 同时性（同一时刻）

### 2. 串联电路

**特点**：
| 物理量 | 规律 |
|--------|------|
| 电流 | I = I₁ = I₂ |
| 电压 | U = U₁ + U₂ |
| 电阻 | R = R₁ + R₂ |
| 电压分配 | U₁/U₂ = R₁/R₂ |

### 3. 并联电路

**特点**：
| 物理量 | 规律 |
|--------|------|
| 电流 | I = I₁ + I₂ |
| 电压 | U = U₁ = U₂ |
| 电阻 | 1/R = 1/R₁ + 1/R₂ |
| 电流分配 | I₁/I₂ = R₂/R₁ |

### 4. 电功

**定义**：电流做功的过程，就是电能转化为其他形式能的过程

**公式**：W = UIt = I²Rt = U²t/R

**单位**：焦耳(J)，千瓦时(kW·h)
- 1kW·h = 3.6×10⁶J

### 5. 电功率

**定义**：电流在单位时间内所做的功

**公式**：
```
P = W/t = UI = I²R = U²/R
```

**单位**：瓦特(W)，千瓦(kW)
- 1kW = 10³W

**额定功率与实际功率**：
- 额定电压：用电器正常工作时的电压
- 额定功率：用电器在额定电压下的功率
- 实际功率：用电器在实际电压下的功率

### 6. 焦耳定律

**内容**：电流通过导体产生的热量跟电流的平方成正比，跟导体的电阻成正比，跟通电时间成正比

**公式**：Q = I²Rt

**应用**：
- 电热器：电炉、电热水壶、电饭煲
- 电热危害：电视机散热、电脑散热

## 典型例题

**例题1**：将电阻R₁和R₂串联后接入电路，已知R₁ = 10Ω，R₂ = 20Ω，电源电压为12V，求电路中的电流和各电阻两端的电压。

**解**：
R总 = R₁ + R₂ = 10Ω + 20Ω = 30Ω
I = U/R总 = 12V/30Ω = 0.4A
U₁ = IR₁ = 0.4A × 10Ω = 4V
U₂ = IR₂ = 0.4A × 20Ω = 8V

**例题2**：将电阻R₁和R₂并联后接入电路，已知R₁ = 10Ω，R₂ = 20Ω，电源电压为12V，求各支路电流和干路电流。

**解**：
I₁ = U/R₁ = 12V/10Ω = 1.2A
I₂ = U/R₂ = 12V/20Ω = 0.6A
I总 = I₁ + I₂ = 1.2A + 0.6A = 1.8A

**例题3**：标有"220V 40W"的灯泡，正常工作时：
(1) 通过灯泡的电流是多少？
(2) 灯泡的电阻是多少？
(3) 工作10小时消耗多少电能？

**解**：
(1) I = P/U = 40W/220V ≈ 0.18A
(2) R = U²/P = (220V)²/40W = 1210Ω
(3) W = Pt = 40W × 10h = 0.4kW × 10h = 4kW·h

## 易错点提醒

### 易错点1：欧姆定律适用范围
**错误**：欧姆定律适用于所有电路
**正确**：欧姆定律只适用于纯电阻电路

### 易错点2：额定功率与实际功率混淆
**错误**：灯泡实际功率一定是40W
**正确**：只有在额定电压下，实际功率才等于额定功率

### 易错点3：串并联判断错误
**错误**：电流表所在支路是并联
**正确**：电流表相当于导线，电压表相当于断路

# 电功率 知识点

## 基本信息

- **学科**: 物理
- **年级**: 九年级
- **所属单元**: 第十八章 电功率
- **重要程度**: 重点

## 知识内容

### 1. 电能

**定义**：电流做功的过程，就是电能转化为其他形式能的过程

**单位**：
- 国际单位：焦耳(J)
- 常用单位：千瓦时(kW·h)，俗称"度"
- 换算：1kW·h = 3.6×10⁶J

**测量工具**：电能表

**读数**：月末读数减去月初读数

### 2. 电功

**定义**：电流所做的功

**公式**：W = UIt

**推导公式**：
- W = I²Rt（纯电阻电路）
- W = U²t/R（纯电阻电路）

### 3. 电功率

**定义**：电流在单位时间内所做的功，表示电流做功的快慢

**公式**：
```
P = W/t = UI
```

**推导公式**：
- P = I²R（纯电阻电路）
- P = U²/R（纯电阻电路）

**单位**：
- 国际单位：瓦特(W)
- 常用单位：千瓦(kW)
- 换算：1kW = 1000W

### 4. 额定功率与实际功率

| 概念 | 定义 |
|------|------|
| 额定电压 | 用电器正常工作时的电压 |
| 额定功率 | 用电器在额定电压下的功率 |
| 实际电压 | 用电器实际工作时的电压 |
| 实际功率 | 用电器在实际电压下的功率 |

**关系**：
- U实 = U额时，P实 = P额，正常发光
- U实 > U额时，P实 > P额，灯泡很亮，易烧坏
- U实 < U额时，P实 < P额，灯泡发光暗

### 5. 焦耳定律

**内容**：电流通过导体产生的热量跟电流的平方成正比，跟导体的电阻成正比，跟通电时间成正比

**公式**：Q = I²Rt

**推导公式**（纯电阻电路）：
- Q = W = UIt = Pt = U²t/R

### 6. 家庭电路

**组成**：
```
进户线 → 电能表 → 总开关 → 保险装置 → 用电器、插座
```

**火线与零线**：
- 火线：与大地之间有220V电压
- 零线：与大地之间无电压

**触电类型**：
1. 单线触电：人体接触火线
2. 双线触电：人体同时接触火线和零线
3. 电弧触电：靠近高压带电体
4. 跨步电压触电：靠近高压线落地处

**安全用电原则**：
- 不接触低压带电体
- 不靠近高压带电体
- 更换灯泡、搬动电器前断开电源
- 保险丝用电阻率大、熔点低的合金制成

### 7. 测电笔

**用途**：辨别火线和零线

**使用**：手接触笔尾金属体，笔尖接触电线

**现象**：氖管发光 → 火线；不发光 → 零线

## 典型例题

**例题1**：一个标有"220V 100W"的灯泡，正常工作时：
(1) 通过灯泡的电流是多少？
(2) 灯泡的电阻是多少？
(3) 正常工作5小时消耗多少电能？

**解**：
(1) I = P/U = 100W/220V ≈ 0.45A
(2) R = U²/P = (220V)²/100W = 484Ω
(3) W = Pt = 100W × 5h = 0.1kW × 5h = 0.5kW·h

**例题2**：把"220V 40W"和"220V 100W"的两个灯泡串联后接在220V电路中，哪个灯泡更亮？

**解**：
R₁ = U²/P₁ = (220V)²/40W = 1210Ω
R₂ = U²/P₂ = (220V)²/100W = 484Ω

串联时，I相同，P = I²R
∵ R₁ > R₂
∴ P₁ > P₂
∴ "220V 40W"的灯泡更亮

**例题3**：某家庭上月末电能表读数为1234.5kW·h，本月末读数为1284.5kW·h，求本月消耗的电能。

**解**：
W = 1284.5kW·h - 1234.5kW·h = 50kW·h

## 易错点提醒

### 易错点1：串联时功率大的灯泡亮
**错误**：100W灯泡比40W灯泡亮
**正确**：串联时电阻大的灯泡亮，40W灯泡更亮

### 易错点2：电能表读数错误
**错误**：直接读本月示数
**正确**：本月末减去上月末

### 易错点3：安全用电常识错误
**错误**：可以用湿手触摸开关
**正确**：水是导体，湿手触摸开关容易触电

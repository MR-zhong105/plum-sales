# 几何图形初步 知识点

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **所属单元**: 第四章 几何图形初步
- **重要程度**: 重点

## 知识内容

### 1. 立体图形与平面图形

**立体图形**：各部分不都在同一平面内的图形
- 常见立体图形：长方体、正方体、圆柱、圆锥、球

**平面图形**：各部分都在同一平面内的图形
- 常见平面图形：三角形、四边形、圆、多边形

### 2. 点、线、面、体

**关系**：
- 点动成线
- 线动成面
- 面动成体

### 3. 直线、射线、线段

#### （1）直线
- 定义：没有端点，向两端无限延伸
- 性质：两点确定一条直线
- 表示方法：用两个大写字母或一个小写字母表示

#### （2）射线
- 定义：有一个端点，向一端无限延伸
- 表示方法：用两个大写字母表示，端点字母在前

#### （3）线段
- 定义：有两个端点，不能延伸
- 性质：两点之间，线段最短
- 表示方法：用两个大写字母或一个小写字母表示

#### （4）比较方法
- 度量法：用刻度尺测量
- 叠合法：把线段叠在一起比较

#### （5）中点
- 定义：把线段分成两条相等线段的点
- 性质：AM = BM = 1/2 AB

### 4. 角

#### （1）定义
- 有公共端点的两条射线组成的图形叫做角
- 角也可以看做一条射线绕着它的端点旋转而形成的图形

#### （2）表示方法
- 用三个大写字母：∠AOB
- 用一个大写字母：∠O
- 用数字：∠1
- 用希腊字母：∠α

#### （3）角的度量
- 单位：度(°)、分(′)、秒(″)
- 换算：1° = 60′，1′ = 60″

#### （4）角的分类
| 类型 | 度数范围 |
|------|----------|
| 锐角 | 0° < α < 90° |
| 直角 | α = 90° |
| 钝角 | 90° < α < 180° |
| 平角 | α = 180° |
| 周角 | α = 360° |

#### （5）角的性质
- 角的大小与边的长短无关
- 角的大小与张开程度有关

#### （6）角的平分线
- 定义：从一个角的顶点出发，把这个角分成相等的两个角的射线
- 性质：∠AOC = ∠BOC = 1/2 ∠AOB

#### （7）余角和补角
| 概念 | 定义 | 性质 |
|------|------|------|
| 余角 | 两个角的和为90° | 同角（等角）的余角相等 |
| 补角 | 两个角的和为180° | 同角（等角）的补角相等 |

### 5. 几何初步知识

#### （1）三视图
- 主视图：从正面看
- 俯视图：从上面看
- 左视图：从左面看

#### （2）展开图
- 圆柱：两个圆 + 一个长方形
- 圆锥：一个圆 + 一个扇形
- 正方体：六个正方形

## 典型例题

**例题1**：下列说法正确的是（  ）
A. 直线比射线长
B. 射线比线段长
C. 直线没有端点，射线有一个端点，线段有两个端点
D. 线段可以度量，直线和射线不可以度量

**答案**：C

**例题2**：如图，点C是线段AB的中点，点D是线段CB的中点，若AD=9cm，求AB的长。

**解**：
设CD = x
∵ D是CB的中点
∴ CD = DB = x，CB = 2x

∵ C是AB的中点
∴ AC = CB = 2x

∴ AB = AC + CB = 4x

∵ AD = AC + CD = 2x + x = 3x = 9
∴ x = 3
∴ AB = 4x = 12cm

**例题3**：一个角的补角比这个角的余角的3倍大10°，求这个角的度数。

**解**：设这个角为x
```
180° - x = 3(90° - x) + 10°
180° - x = 270° - 3x + 10°
180° - x = 280° - 3x
2x = 100°
x = 50°
```
答：这个角是50°。

## 易错点提醒

### 易错点1：直线和射线可以比较长短
**错误**：直线比射线长
**正确**：直线和射线都是无限长的，不能比较长短

### 易错点2：余角和补角混淆
**错误**：互为余角的两个角和为180°
**正确**：互为余角的两个角和为90°，互为补角的两个角和为180°

### 易错点3：角平分线是直线
**错误**：角平分线是直线
**正确**：角平分线是射线

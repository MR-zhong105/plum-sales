# 平面直角坐标系

> 七年级数学核心知识点

## 知识内容

### 1. 相关概念

- **平面直角坐标系**：在平面内，两条互相垂直且有公共原点的数轴组成
- **x轴（横轴）**：水平方向的数轴，正方向向右
- **y轴（纵轴）**：竖直方向的数轴，正方向向上
- **原点**：两轴的交点O(0,0)

### 2. 点的坐标

**有序实数对**(x, y)：
- x：横坐标（点到y轴的距离，右正左负）
- y：纵坐标（点到x轴的距离，上正下负）

### 3. 各象限点的坐标特征

| 象限 | 横坐标 | 纵坐标 | 示例 |
|------|--------|--------|------|
| 第一象限 | + | + | (3, 2) |
| 第二象限 | - | + | (-3, 2) |
| 第三象限 | - | - | (-3, -2) |
| 第四象限 | + | - | (3, -2) |

**坐标轴上的点**：
- x轴上：(x, 0)
- y轴上：(0, y)
- 原点：(0, 0)

### 4. 点到坐标轴的距离

- 点P(x, y)到x轴的距离 = |y|
- 点P(x, y)到y轴的距离 = |x|
- 点P到原点的距离 = $\sqrt{x^2+y^2}$

### 5. 点的平移

| 平移方向 | 坐标变化 | 示例 |
|----------|---------|------|
| 向右a个单位 | (x+a, y) | (1,2)→(3,2) |
| 向左a个单位 | (x-a, y) | (1,2)→(-1,2) |
| 向上b个单位 | (x, y+b) | (1,2)→(1,4) |
| 向下b个单位 | (x, y-b) | (1,2)→(1,0) |

## 典型例题

**例题1**：（中考题）点P(-3, 4)在（）
A. 第一象限  B. 第二象限  C. 第三象限  D. 第四象限
**答案**：B

**例题2**：点A(2, -3)关于x轴对称的点坐标是____，关于y轴对称的点坐标是____
**答案**：(2, 3)；(-2, -3)

**例题3**：点P(x, y)在第四象限，且|x|=3，|y|=2，则点P的坐标是____
**答案**：(3, -2)

## 易错点提醒

### 易错点1：象限记忆错误
**口诀**：一(+,+) 二(-,+) 三(-,-) 四(+,-)

### 易错点2：对称点坐标记错
**技巧**：关于x轴对称→横不变纵变号；关于y轴对称→纵不变横变号

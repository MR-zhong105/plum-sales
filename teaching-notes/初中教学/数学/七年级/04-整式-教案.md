# 整式的加减 教案

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **单元**: 第二章 整式的加减
- **课题**: 2.1 整式
- **课时**: 2课时

## 教学目标

### 知识与技能
- 理解单项式、多项式、整式的概念
- 能确定单项式的系数和次数
- 能确定多项式的项数和次数
- 掌握去括号法则

### 过程与方法
- 经历概念的形成过程，培养抽象思维能力
- 通过练习巩固，提高运算能力

### 情感态度与价值观
- 感受数学语言的简洁美
- 培养严谨的数学学习习惯

## 教学重难点

**重点**: 单项式、多项式的概念
**难点**: 单项式的次数、多项式的次数

## 教学过程

### 第一课时

#### 一、导入新课（5分钟）

**情境创设**：
学校用塑料运动场跑道，面积是3200平方米，长是y米，那么宽是多少米？
如果宽是x米，长是多少米？

**问题引导**：
1. 宽 = 3200/y，这是什么类型的式子？
2. 长 = 3200/x，这又是什么类型的式子？
3. 这些式子与以前学过的式子有什么不同？

#### 二、新课讲授（25分钟）

##### 1. 单项式的概念

**定义**：数与字母的积组成的代数式叫做单项式

**补充说明**：
- 单独的一个数或一个字母也是单项式
- 单项式中不能含有加减运算

**举例**：
- 单项式：3x, -5ab, πr², 7, a
- 不是单项式：x+y, 1/x, a+b

**单项式的系数**：单项式中的数字因数

**单项式的次数**：单项式中所有字母的指数和

**练习**：
| 单项式 | 系数 | 次数 |
|--------|------|------|
| 3x | 3 | 1 |
| -5ab | -5 | 2 |
| πr² | π | 2 |
| -x²y | -1 | 3 |
| 7 | 7 | 0 |

##### 2. 多项式的概念

**定义**：几个单项式的和叫做多项式

**相关概念**：
- 项：多项式中的每个单项式
- 常数项：不含字母的项
- 多项式的次数：多项式中次数最高的项的次数

**举例**：
- x² + 2x + 3 是三次三项式
- 3a²b - 2ab² + 5 是三次三项式

##### 3. 整式的概念

**定义**：单项式和多项式统称为整式

**总结**：
```
整式
├── 单项式
│   ├── 系数
│   └── 次数
└── 多项式
    ├── 项
    ├── 常数项
    └── 次数
```

#### 三、课堂练习（10分钟）

**练习1**：判断下列各式哪些是单项式，哪些是多项式，哪些是整式
(1) 3x    (2) x+y    (3) -5    (4) ab/2    (5) 1/x    (6) x²-2x+1

**练习2**：填写下列单项式的系数和次数
| 单项式 | 系数 | 次数 |
|--------|------|------|
| -2πr |      |      |
| 3x²y³ |      |      |
| -m |      |      |

**练习3**：说出下列多项式的项、常数项和次数
(1) x³ - 2x² + 3x - 4
(2) 5a²b - 3ab² + 2

#### 四、课堂小结（5分钟）

1. 单项式的概念、系数、次数
2. 多项式的概念、项、常数项、次数
3. 整式的分类

#### 五、布置作业（5分钟）

- 教材P68 练习1、2、3

### 第二课时

#### 一、复习导入（5分钟）

回顾单项式、多项式、整式的概念。

#### 二、新课讲授（20分钟）

##### 去括号法则

**法则**：
1. 括号前面是"+"号，去掉括号和"+"号，括号内各项符号不变
2. 括号前面是"-"号，去掉括号和"-"号，括号内各项符号都要改变

**记忆口诀**：
> 去括号，看符号：
> 是"+"号，不变号；
> 是"-"号，全变号。

**示例**：
```
+(3x - 2y + 1) = 3x - 2y + 1
-(3x - 2y + 1) = -3x + 2y - 1
a + (b - c) = a + b - c
a - (b - c) = a - b + c
```

#### 三、课堂练习（15分钟）

**练习1**：去括号
(1) +(a - b + c)
(2) -(a - b + c)
(3) -(-a + b - c)
(4) +(x - y) - (x + y)

**练习2**：化简
(1) 3x + (2x - 5)
(2) 5a - (3a - 2)
(3) 2(x + y) - 3(x - y)

#### 四、课堂小结（3分钟）

去括号法则的应用。

#### 五、布置作业（2分钟）

- 教材P70 练习1、2
- 预习合并同类项

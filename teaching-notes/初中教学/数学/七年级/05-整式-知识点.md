# 整式 知识点

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **所属单元**: 第二章 整式的加减
- **重要程度**: 重点

## 知识内容

### 1. 单项式

**定义**：数与字母的积组成的代数式叫做单项式

**注意**：
- 单独的一个数或一个字母也是单项式
- 分母中含有字母的式子不是单项式

**单项式的系数**：单项式中的数字因数
- 注意系数包括前面的符号
- π是常数，不是字母
- 系数是1或-1时，1通常省略不写

**单项式的次数**：单项式中所有字母的指数和
- 单独一个非零数的次数是0
- 次数是1时，1通常省略不写

### 2. 多项式

**定义**：几个单项式的和叫做多项式

**相关概念**：
- **项**：多项式中的每个单项式
- **常数项**：不含字母的项
- **多项式的次数**：多项式中次数最高的项的次数

**命名规则**：
- 几次几项式 = 次数 + 项数
- 例：x³ - 2x² + 3x - 4 是三次四项式

### 3. 整式

**定义**：单项式和多项式统称为整式

### 4. 去括号法则

**法则**：
1. 括号前面是"+"号，去掉括号和"+"号，括号内各项符号不变
2. 括号前面是"-"号，去掉括号和"-"号，括号内各项符号都要改变

**记忆口诀**：
> 去括号，看符号：
> 是"+"号，不变号；
> 是"-"号，全变号。

**示例**：
```
+(3x - 2y) = 3x - 2y
-(3x - 2y) = -3x + 2y
a + (b - c + d) = a + b - c + d
a - (b - c + d) = a - b + c - d
```

### 5. 合并同类项

**同类项**：所含字母相同，并且相同字母的指数也相同的项

**合并同类项法则**：
- 系数相加，字母和字母的指数不变

**步骤**：
1. 找：找出同类项
2. 移：把同类项移到一起
3. 合：合并同类项

**示例**：
```
3x² + 2x - x² + 4x
= 3x² - x² + 2x + 4x
= 2x² + 6x
```

## 典型例题

**例题1**：判断下列说法是否正确
(1) -3²x²y的系数是-3
(2) πr²的次数是2
(3) x³ - 2x + 1是三次二项式
(4) 3x与3x²是同类项

**答案**：
(1) ×（系数是-9）
(2) √
(3) ×（是三次三项式）
(4) ×（x的次数不同）

**例题2**：去括号并化简
(1) 2(a + b) - 3(a - b)
(2) -(2x - 3y) + (x + 2y)

**答案**：
(1) 2a + 2b - 3a + 3b = -a + 5b
(2) -2x + 3y + x + 2y = -x + 5y

**例题3**：合并同类项
(1) 5x² - 3x + 2x² + x - 1
(2) 3ab - 2a²b + a²b - 4ab² + ab

**答案**：
(1) 7x² - 2x - 1
(2) 4ab - a²b - 4ab²

## 易错点提醒

### 易错点1：单项式系数漏掉符号
**错误**：-3x²的系数是3
**正确**：系数是-3

### 易错点2：π当成字母
**错误**：πr²的次数是3
**正确**：π是常数，次数是2

### 易错点3：去括号变号错误
**错误**：-(a-b) = -a-b
**正确**：-(a-b) = -a+b

### 易错点4：同类项判断错误
**错误**：3x与3x²是同类项
**正确**：同类项要求字母相同且指数相同

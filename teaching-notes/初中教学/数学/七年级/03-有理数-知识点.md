# 有理数 知识点

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **所属单元**: 第一章 有理数
- **重要程度**: 重点

## 知识内容

### 1. 有理数的概念

**定义**：整数和分数统称有理数

**分类**：
```
有理数
├── 整数
│   ├── 正整数（如：1, 2, 3...）
│   ├── 0
│   └── 负整数（如：-1, -2, -3...）
└── 分数
    ├── 正分数（如：1/2, 0.3...）
    └── 负分数（如：-1/2, -0.3...）
```

**注意**：
- 0是整数，但不是正数也不是负数
- 有限小数和无限循环小数都可以化成分数，属于分数

### 2. 数轴

**定义**：规定了原点、正方向、单位长度的直线叫做数轴

**三要素**：
1. 原点：表示0的点
2. 正方向：通常规定向右为正
3. 单位长度：选取适当的长度作为单位

**数轴上的点与有理数的关系**：
- 每一个有理数都可以用数轴上的点表示
- 数轴上的点并不都表示有理数（如π）

### 3. 相反数

**定义**：只有符号不同的两个数叫做互为相反数

**性质**：
- 正数的相反数是负数
- 负数的相反数是正数
- 0的相反数是0
- 互为相反数的两个数之和为0：a + (-a) = 0

**几何意义**：在数轴上，互为相反数的两个点位于原点两侧，且到原点的距离相等

### 4. 绝对值

**定义**：数轴上表示数a的点与原点的距离叫做数a的绝对值，记作|a|

**性质**：
- 正数的绝对值是它本身：|a| = a (a > 0)
- 负数的绝对值是它的相反数：|a| = -a (a < 0)
- 0的绝对值是0：|0| = 0
- 任何有理数的绝对值都是非负数：|a| ≥ 0

**比较大小**：
- 正数 > 0 > 负数
- 两个负数，绝对值大的反而小

### 5. 有理数的大小比较

**方法一：数轴法**
- 在数轴上，右边的数总比左边的数大

**方法二：法则法**
- 正数大于零，零大于负数
- 正数大于一切负数
- 两个负数，绝对值大的反而小

### 6. 有理数的加减法

**加法法则**：
1. 同号两数相加，取相同的符号，并把绝对值相加
2. 异号两数相加，绝对值相等时和为0；绝对值不相等时，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值
3. 一个数同0相加，仍得这个数

**减法法则**：
减去一个数，等于加上这个数的相反数
```
a - b = a + (-b)
```

### 7. 有理数的乘除法

**乘法法则**：
- 两数相乘，同号得正，异号得负，并把绝对值相乘
- 任何数与0相乘，仍得0
- 多个不为0的数相乘，积的符号由负因数的个数决定：奇数个负因数积为负，偶数个负因数积为正

**除法法则**：
1. 除以一个不等于0的数，等于乘这个数的倒数
2. 两数相除，同号得正，异号得负，并把绝对值相除
3. 0除以任何一个不等于0的数，都得0

### 8. 有理数的乘方

**定义**：求n个相同因数a的积的运算叫做乘方

**记法**：aⁿ，读作"a的n次方"或"a的n次幂"

**性质**：
- 正数的任何次幂都是正数
- 负数的奇数次幂是负数，负数的偶数次幂是正数
- 0的任何正整数次幂都是0

**混合运算顺序**：
1. 先乘方，再乘除，最后加减
2. 同级运算，从左到右进行
3. 如有括号，先做括号内的运算

## 典型例题

**例题1**：计算 (-3) + 5 - (-2)

**解**：
(-3) + 5 - (-2)
= -3 + 5 + 2
= 4

**例题2**：计算 (-2)³ × (-3)²

**解**：
(-2)³ × (-3)²
= (-8) × 9
= -72

**例题3**：比较大小：-(-3) 和 -|-3|

**解**：
-(-3) = 3
-|-3| = -3
因为 3 > -3
所以 -(-3) > -|-3|

## 易错点提醒

### 易错点1：-a不一定是负数
**错误**：-a是负数
**正确**：当a>0时，-a是负数；当a<0时，-a是正数；当a=0时，-a=0

### 易错点2：|a| = a
**错误**：|a| = a
**正确**：当a≥0时，|a|=a；当a<0时，|a|=-a

### 易错点3：(-2)²与-2²
**错误**：(-2)² = -2²
**正确**：(-2)² = 4，-2² = -4

### 易错点4：两个负数比较大小
**错误**：-5 > -3（因为5>3）
**正确**：-5 < -3（两个负数，绝对值大的反而小）

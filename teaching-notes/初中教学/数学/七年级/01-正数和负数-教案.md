# 有理数 教案

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **单元**: 第一章 有理数
- **课题**: 1.1 正数和负数
- **课时**: 1课时

## 教学目标

### 知识与技能
- 理解正数和负数的概念
- 能运用正负数表示具有相反意义的量
- 理解0既不是正数也不是负数

### 过程与方法
- 通过实例体会引入负数的必要性
- 经历从具体情境抽象出数学概念的过程

### 情感态度与价值观
- 感受数学与生活的紧密联系
- 培养用数学眼光观察生活的习惯

## 教学重难点

**重点**: 正数和负数的概念，用正负数表示具有相反意义的量

**难点**: 理解负数的意义，0的特殊含义

## 教学过程

### 一、导入新课（5分钟）

**情境引入**：
展示天气预报图：北京 -5℃~5℃，哈尔滨 -15℃~-3℃

提问：
- "5℃"和"-5℃"表示什么意思？
- 为什么会有负温度？
- 生活中还有哪些地方用到负数？

**设计意图**：从学生熟悉的生活情境出发，激发学习兴趣。

### 二、新课讲授（25分钟）

#### 1. 正数和负数的概念

**讲解**：
- 像 5、1.2、$\frac{1}{3}$ 这样大于0的数叫做正数
- 像 -5、-3.6、$-\frac{2}{3}$ 这样在正数前面加上负号"-"的数叫做负数
- 0既不是正数，也不是负数

**板书**：
```
正数：5, 1.2, +3, ...
负数：-5, -3.6, -2, ...
0：既不是正数，也不是负数
```

#### 2. 用正负数表示具有相反意义的量

**例题1**：
某仓库运进面粉7.5吨记作+7.5吨，那么运出3.8吨应记作什么？

**分析**：
- "运进"与"运出"是具有相反意义的量
- 运进记为正，则运出记为负
- 运出3.8吨记作 -3.8吨

**变式练习**：
- 盈利100元记作+100元，亏损50元记作____
- 向东走10米记作+10米，向西走8米记作____
- 上升5米记作+5米，下降3米记作____

**设计意图**：通过多层练习，帮助学生理解正负数的实际意义。

### 三、课堂练习（10分钟）

**练习1**：判断下列各数，哪些是正数？哪些是负数？
+3, -4, 0, -0.5, +$\frac{1}{2}$, -10, 8

**练习2**：用正负数表示下列具有相反意义的量：
(1) 电梯上升15层，下降10层
(2) 货车运货20吨，卸货15吨
(3) 小明存钱50元，取钱30元

**练习3**：（拓展）
如果规定向东为正，那么：
- 向西走50米记作什么？
- -80米表示什么意思？
- 0米表示什么？

### 四、课堂小结（3分钟）

**学生总结**：
- 什么是正数和负数？
- 0是正数还是负数？
- 正负数可以表示什么？

**教师补充**：
1. 正数大于0，负数小于0
2. 0是正负数的分界点
3. 正负数常用来表示具有相反意义的量

### 五、布置作业（2分钟）

**必做题**：
- 教材P6 练习1、2、3

**选做题**：
- 收集生活中使用正负数的例子，下节课分享

## 板书设计

```
1.1 正数和负数

一、正数和负数的概念
   正数：> 0
   负数：< 0（前面带"-"）
   0：既不是正数，也不是负数

二、用正负数表示具有相反意义的量
   例：运进 +7.5吨  运出 -3.8吨
   
   特征：
   1. 意义相反
   2. 都是数量
   3. 单位相同
```

## 教学反思

**成功之处**：
- 从生活情境导入，学生参与度高
- 练习设计层层递进，符合认知规律

**不足之处**：
- 部分学生对"0既不是正数也不是负数"理解不够深入
- 时间把控需要改进，练习时间略显紧张

**改进措施**：
- 增加关于0的讨论环节
- 精简例题，留出更多练习时间

# 相交线与平行线 知识点

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **所属单元**: 第五章 相交线与平行线
- **重要程度**: 重点

## 知识内容

### 1. 相交线

#### （1）对顶角
- 定义：一个角的两边分别是另一个角两边的反向延长线
- 性质：对顶角相等

#### （2）邻补角
- 定义：两个角有一条公共边，它们的另一边互为反向延长线
- 性质：邻补角互补（和为180°）

#### （3）垂线
- 定义：两条直线相交成直角时，这两条直线互相垂直
- 性质：
  1. 过一点有且只有一条直线与已知直线垂直
  2. 垂线段最短
- 距离：直线外一点到这条直线的垂线段的长度

### 2. 平行线

#### （1）定义
在同一平面内，不相交的两条直线叫做平行线

#### （2）平行公理
经过直线外一点，有且只有一条直线与这条直线平行

#### （3）平行线的判定
| 判定方法 | 条件 |
|----------|------|
| 同位角相等 | 两直线平行 |
| 内错角相等 | 两直线平行 |
| 同旁内角互补 | 两直线平行 |

#### （4）平行线的性质
| 性质 | 内容 |
|------|------|
| 同位角 | 两直线平行，同位角相等 |
| 内错角 | 两直线平行，内错角相等 |
| 同旁内角 | 两直线平行，同旁内角互补 |

### 3. 命题与证明

**命题**：判断一件事情的语句叫做命题

**结构**：题设（条件）+ 结论

**分类**：
- 真命题：题设成立，结论一定成立
- 假命题：题设成立，结论不一定成立

**证明**：根据已知条件，经过推理判断命题真假的过程

### 4. 平移

**定义**：把一个图形整体沿某一直线方向移动，得到一个新图形

**性质**：
1. 对应点所连的线段平行且相等
2. 对应线段平行且相等
3. 对应角相等

**作图步骤**：
1. 找出关键点的对应点
2. 连接对应点
3. 画出新图形

## 典型例题

**例题1**：如图，直线AB、CD相交于点O，∠AOE = 90°，∠AOC = 35°，求∠DOE的度数。

**解**：
∵ ∠AOC = 35°
∴ ∠BOD = ∠AOC = 35°（对顶角相等）

∵ ∠AOE = 90°
∴ ∠BOE = 90°

∴ ∠DOE = ∠BOE - ∠BOD = 90° - 35° = 55°

**例题2**：如图，已知∠1 = ∠2，∠3 = 70°，求∠4的度数。

**解**：
∵ ∠1 = ∠2
∴ a ∥ b（内错角相等，两直线平行）

∴ ∠4 = ∠3 = 70°（两直线平行，同位角相等）

**例题3**：如图，已知AB∥CD，∠B = 60°，∠D = 40°，求∠BED的度数。

**解**：
过点E作EF∥AB
∵ AB∥CD
∴ EF∥AB∥CD

∵ EF∥AB
∴ ∠BEF = ∠B = 60°（两直线平行，内错角相等）

∵ EF∥CD
∴ ∠DEF = ∠D = 40°（两直线平行，内错角相等）

∴ ∠BED = ∠BEF + ∠DEF = 60° + 40° = 100°

## 易错点提醒

### 易错点1：判定和性质混淆
**错误**：同位角相等，两直线平行（这是性质，不是判定）
**正确**：同位角相等，两直线平行（判定）；两直线平行，同位角相等（性质）

### 易错点2：垂线段最短理解错误
**错误**：两点之间，垂线段最短
**正确**：两点之间，线段最短；直线外一点与直线上各点连接的所有线段中，垂线段最短

### 易错点3：平移性质遗漏
**错误**：平移只改变位置，不改变形状和大小
**正确**：平移不仅不改变形状和大小，对应点连线还平行且相等

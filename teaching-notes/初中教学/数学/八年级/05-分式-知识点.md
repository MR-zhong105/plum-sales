# 分式 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十五章 分式
- **重要程度**: 重点

## 知识内容

### 1. 分式的概念

**定义**：一般地，如果A、B表示两个整式，并且B中含有字母，那么式子A/B叫做分式

**有意义的条件**：B ≠ 0

**值为0的条件**：A = 0 且 B ≠ 0

### 2. 分式的基本性质

**性质**：分式的分子与分母同乘（或除以）同一个不等于0的整式，分式的值不变

```
A/B = (A×M)/(B×M)
A/B = (A÷M)/(B÷M)
```

**应用**：
- 约分
- 通分

### 3. 分式的运算

#### （1）加减法
**同分母**：a/c ± b/c = (a±b)/c

**异分母**：先通分，再加减

```
a/b ± c/d = ad/bd ± bc/bd = (ad±bc)/bd
```

#### （2）乘除法
**乘法**：a/b × c/d = ac/bd

**除法**：a/b ÷ c/d = a/b × d/c = ad/bc

#### （3）乘方
(a/b)ⁿ = aⁿ/bⁿ

### 4. 分式方程

**定义**：分母中含有未知数的方程叫做分式方程

**解法步骤**：
1. 去分母：方程两边同乘最简公分母
2. 解整式方程
3. 检验：代入最简公分母，看是否为0
4. 写答案

**注意**：分式方程必须检验，增根要舍去

### 5. 最简公分母

**确定方法**：
1. 系数：取各系数的最小公倍数
2. 字母：取各字母的最高次幂
3. 因式：取各因式的最高次幂

## 典型例题

**例题1**：当x为何值时，分式x-1/x+2有意义？

**解**：
分式有意义的条件是分母不为0
∴ x + 2 ≠ 0
∴ x ≠ -2

**例题2**：解分式方程 2/x = 1/x-1

**解**：
去分母，得：
2(x-1) = x
2x - 2 = x
x = 2

检验：当x=2时，x(x-1) = 2×1 = 2 ≠ 0
∴ x = 2是原方程的解

**例题3**：计算 (a/b)² ÷ (a/b)·(b/a)

**解**：
原式 = a²/b² × b/a × b/a
= a²b² / (b²·a·a)
= 1

## 易错点提醒

### 易错点1：分式有意义忘条件
**错误**：x/0有意义
**正确**：分母不能为0，分式无意义

### 易错点2：解分式方程不检验
**错误**：解出x=3就结束
**正确**：必须检验，排除增根

### 易错点3：约分漏掉符号
**错误**：(a-b)/(b-a) = 1
**正确**：(a-b)/(b-a) = -(a-b)/(a-b) = -1

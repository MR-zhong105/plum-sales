# 等腰三角形 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十三章 轴对称
- **重要程度**: 重点

## 知识内容

### 1. 等腰三角形的性质

**定义**：有两边相等的三角形叫做等腰三角形

**性质定理**：
1. 等边对等角（等腰三角形的两个底角相等）
2. 三线合一（顶角平分线、底边上的中线、底边上的高互相重合）
3. 轴对称图形，对称轴是顶角平分线所在的直线

**推论**：
- 等边三角形的三个角都相等，每个角都等于60°
- 有一个角是60°的等腰三角形是等边三角形

### 2. 等腰三角形的判定

**判定定理**：
- 如果一个三角形有两个角相等，那么这两个角所对的边也相等（等角对等边）

**推论**：
- 三个角都相等的三角形是等边三角形
- 有一个角是60°的等腰三角形是等边三角形

### 3. 等边三角形的性质

**性质**：
1. 三条边都相等
2. 三个角都相等，每个角都是60°
3. 三线合一
4. 是轴对称图形，有三条对称轴

### 4. 含30°角的直角三角形

**性质**：在直角三角形中，如果一个锐角等于30°，那么它所对的直角边等于斜边的一半

**逆定理**：在直角三角形中，如果一条直角边等于斜边的一半，那么这条直角边所对的角等于30°

## 典型例题

**例题1**：已知等腰三角形的一个角是50°，求其他两个角的度数。

**解**：分两种情况讨论：
- 当50°是顶角时，底角 = (180°-50°)÷2 = 65°
- 当50°是底角时，另一个底角也是50°，顶角 = 180°-50°-50° = 80°

**答案**：50°、65°、65° 或 50°、50°、80°

**例题2**：如图，在△ABC中，AB=AC，点D在AC上，且BD=BC=AD，求△ABC各角的度数。

**解**：
设∠A = x
∵ AD = BD
∴ ∠ABD = ∠A = x
∴ ∠BDC = ∠A + ∠ABD = 2x

∵ BD = BC
∴ ∠C = ∠BDC = 2x

∵ AB = AC
∴ ∠ABC = ∠C = 2x

在△ABC中：
∠A + ∠ABC + ∠C = 180°
x + 2x + 2x = 180°
5x = 180°
x = 36°

∴ ∠A = 36°，∠ABC = ∠C = 72°

**例题3**：如图，在△ABC中，AB=AC，DE垂直平分AB，∠ADE=40°，求∠DBC的度数。

**解**：
∵ DE垂直平分AB
∴ AD = BD
∴ ∠A = ∠ABD

∵ ∠ADE = 40°，∠AED = 90°
∴ ∠A = 50°
∴ ∠ABD = 50°

∵ AB = AC
∴ ∠ABC = ∠C = (180°-50°)÷2 = 65°

∴ ∠DBC = ∠ABC - ∠ABD = 65° - 50° = 15°

## 易错点提醒

### 易错点1：等腰三角形顶角底角不分
**错误**：只算一种情况
**正确**：要分顶角和底角两种情况讨论

### 易错点2：三线合一用错
**错误**：任意一条中线也是高
**正确**：只有顶角的平分线、底边上的中线、底边上的高才重合

### 易错点3：等边三角形判定错误
**错误**：三个角相等的三角形不一定是等边三角形
**正确**：三个角都相等的三角形是等边三角形

# 多边形及其内角和 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十一章 三角形
- **重要程度**: 重点

## 知识内容

### 1. 多边形的相关概念

**定义**：在平面内，由一些线段首尾顺次相接组成的封闭图形叫做多边形

**相关概念**：
- 边：组成多边形的线段
- 顶点：相邻两边的公共端点
- 内角：相邻两边组成的角
- 外角：一边与另一边的延长线组成的角
- 对角线：连接不相邻两个顶点的线段

### 2. 多边形的对角线

**公式**：n边形从一个顶点出发可画(n-3)条对角线
**总对角线条数**：n(n-3)/2

**示例**：
| 边形 | 对角线条数 |
|------|-----------|
| 三角形 | 0 |
| 四边形 | 2 |
| 五边形 | 5 |
| 六边形 | 9 |

### 3. 多边形的内角和

**定理**：n边形的内角和等于(n-2)×180°

**推导方法**：
1. 从一个顶点出发，连接对角线，将n边形分成(n-2)个三角形
2. 每个三角形内角和为180°
3. n边形内角和 = (n-2)×180°

**特例**：
- 三角形：(3-2)×180° = 180°
- 四边形：(4-2)×180° = 360°
- 五边形：(5-2)×180° = 540°

### 4. 多边形的外角和

**定理**：任意多边形的外角和等于360°

**注意**：与边数无关

### 5. 正多边形

**定义**：各边相等，各角也相等的多边形

**性质**：
- 正n边形的每个内角 = (n-2)×180°/n
- 正n边形的每个外角 = 360°/n

**特例**：
- 正三角形：每个内角60°
- 正方形：每个内角90°
- 正六边形：每个内角120°

## 典型例题

**例题1**：一个多边形的内角和是1080°，它是几边形？

**解**：
设它是n边形
```
(n-2) × 180° = 1080°
n - 2 = 6
n = 8
```
答：它是八边形。

**例题2**：一个多边形的每个外角都是36°，它是几边形？

**解**：
360° ÷ 36° = 10
答：它是十边形。

**例题3**：一个多边形的内角和比外角和大880°，求这个多边形的边数。

**解**：
设它是n边形
```
(n-2) × 180° - 360° = 880°
(n-2) × 180° = 1240°
n - 2 = 1240/180
n - 2 = 6.89...
```
（此题无整数解，题目可能有误）

修正：内角和比外角和大720°
```
(n-2) × 180° - 360° = 720°
(n-2) × 180° = 1080°
n - 2 = 6
n = 8
```
答：它是八边形。

## 易错点提醒

### 易错点1：内角和公式记错
**错误**：n边形内角和 = n×180°
**正确**：n边形内角和 = (n-2)×180°

### 易错点2：外角和忘记是定值
**错误**：多边形边数越多，外角和越大
**正确**：任意多边形外角和都是360°

### 易错点3：对角线条数计算错误
**错误**：n边形对角线 = n(n-1)/2
**正确**：n边形对角线 = n(n-3)/2

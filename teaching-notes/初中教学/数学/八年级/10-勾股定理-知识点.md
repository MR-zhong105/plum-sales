# 勾股定理 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十七章 勾股定理
- **重要程度**: 重点

## 知识内容

### 1. 勾股定理

**内容**：如果直角三角形的两条直角边长分别为a、b，斜边长为c，那么 a² + b² = c²

**证明方法**：
- 面积法
- 赵爽弦图
- 欧几里得证明

**历史**：
- 中国：商高（三三故出于勾股）、赵爽弦图
- 西方：毕达哥拉斯定理

### 2. 勾股定理的逆定理

**内容**：如果三角形的三边长a、b、c满足 a² + b² = c²，那么这个三角形是直角三角形

**用途**：判断一个三角形是否为直角三角形

### 3. 勾股数

**定义**：满足 a² + b² = c² 的三个正整数

**常见勾股数**：
| 勾股数 | 倍数 |
|--------|------|
| 3, 4, 5 | 6, 8, 10; 9, 12, 15... |
| 5, 12, 13 | 10, 24, 26... |
| 8, 15, 17 | 16, 30, 34... |
| 7, 24, 25 | 14, 48, 50... |

### 4. 勾股定理的应用

**求边长**：
- 已知两边求第三边
- 注意区分直角边和斜边

**求面积**：
- 已知两边求面积
- 需要先用勾股定理求第三边

**最短路径问题**：
- 立体图形表面最短路径问题
- 展开后利用勾股定理求解

## 典型例题

**例题1**：在Rt△ABC中，∠C = 90°，若a = 6，b = 8，则c = ______。

**解**：
c² = a² + b² = 36 + 64 = 100
∴ c = 10

**例题2**：判断下列各组数是否为勾股数：
(1) 5, 12, 13
(2) 6, 8, 10
(3) 7, 24, 25

**解**：
(1) 5² + 12² = 25 + 144 = 169 = 13²，是勾股数
(2) 6² + 8² = 36 + 64 = 100 = 10²，是勾股数
(3) 7² + 24² = 49 + 576 = 625 = 25²，是勾股数

**例题3**：如图，一个圆柱体高8cm，底面半径2cm，一只蚂蚁从点A爬到点B，求最短路径。

**解**：
将圆柱侧面展开，得到一个长方形
长方形的长 = 底面周长的一半 = πr = 2π ≈ 6.28cm
长方形的宽 = 圆柱的高 = 8cm

AB = √(6.28² + 8²) ≈ √(39.44 + 64) ≈ √103.44 ≈ 10.17cm

**例题4**：如图，在△ABC中，AB = 13，AC = 15，BC边上的高AD = 12，求BC的长。

**解**：
在Rt△ABD中：BD² = AB² - AD² = 169 - 144 = 25
∴ BD = 5

在Rt△ACD中：CD² = AC² - AD² = 225 - 144 = 81
∴ CD = 9

分两种情况：
- 当D在BC上时：BC = BD + CD = 5 + 9 = 14
- 当D在BC延长线上时：BC = CD - BD = 9 - 5 = 4

答：BC的长为14或4。

## 易错点提醒

### 易错点1：没说明是直角三角形
**错误**：在△ABC中，AB = 5，AC = 12，则BC = 13
**正确**：必须说明是直角三角形，且BC是斜边

### 易错点2：勾股定理用错
**错误**：a² + b² = c²，所以c = a + b
**正确**：c = √(a² + b²)

### 易错点3：忽略多解情况
**错误**：只算一种情况
**正确**：要考虑高在三角形内部和外部的情况

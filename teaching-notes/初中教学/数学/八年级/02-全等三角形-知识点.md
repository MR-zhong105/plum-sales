# 全等三角形 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十二章 全等三角形
- **重要程度**: 重点

## 知识内容

### 1. 全等三角形的概念

**定义**：能够完全重合的两个三角形叫做全等三角形

**性质**：
- 对应边相等
- 对应角相等

**表示**：△ABC ≌ △DEF

### 2. 全等三角形的判定

**一般三角形**：
| 判定方法 | 条件 | 简写 |
|----------|------|------|
| SSS | 三边对应相等 | 边边边 |
| SAS | 两边及其夹角对应相等 | 边角边 |
| ASA | 两角及其夹边对应相等 | 角边角 |
| AAS | 两角及其中一角的对边对应相等 | 角角边 |

**直角三角形**：
| 判定方法 | 条件 | 简写 |
|----------|------|------|
| HL | 斜边和一条直角边对应相等 | 斜边直角边 |

**注意**：AAA和SSA不能判定全等

### 3. 角平分线的性质

**定理**：角平分线上的点到角两边的距离相等

**逆定理**：到角两边距离相等的点在角的平分线上

### 4. 证明思路

**证明线段相等**：
- 证明两条线段所在的三角形全等
- 利用等腰三角形性质
- 利用角平分线性质

**证明角相等**：
- 证明两个角所在的三角形全等
- 利用等腰三角形性质
- 利用平行线性质

## 典型例题

**例题1**：如图，AB=AD，CB=CD，求证：∠B=∠D。

**证明**：
在△ABC和△ADC中，
```
AB = AD（已知）
CB = CD（已知）
AC = AC（公共边）
```
∴ △ABC ≌ △ADC（SSS）
∴ ∠B = ∠D（全等三角形对应角相等）

**例题2**：已知：如图，AB∥CD，AB=CD，求证：AD∥BC。

**证明**：
∵ AB∥CD
∴ ∠BAC = ∠DCA（两直线平行，内错角相等）

在△ABC和△CDA中，
```
AB = CD（已知）
∠BAC = ∠DCA（已证）
AC = CA（公共边）
```
∴ △ABC ≌ △CDA（SAS）
∴ ∠BCA = ∠DAC（全等三角形对应角相等）
∴ AD∥BC（内错角相等，两直线平行）

**例题3**：如图，OP平分∠AOB，PC⊥OA于C，PD⊥OB于D，求证：PC=PD。

**证明**：
∵ OP平分∠AOB
∴ ∠AOP = ∠BOP

∵ PC⊥OA，PD⊥OB
∴ ∠OCP = ∠ODP = 90°

在△OCP和△ODP中，
```
∠OCP = ∠ODP（已证）
∠AOP = ∠BOP（已证）
OP = OP（公共边）
```
∴ △OCP ≌ △ODP（AAS）
∴ PC = PD（全等三角形对应边相等）

## 易错点提醒

### 易错点1：SSA判定全等
**错误**：两边和其中一边的对角对应相等，两三角形全等
**正确**：SSA不能判定全等

### 易错点2：对应关系错误
**错误**：△ABC ≌ △DEF，认为AB=DE，BC=EF，AC=DF
**正确**：对应顶点要写对，△ABC ≌ △DEF表示A对应D，B对应E，C对应F

### 易错点3：忽略隐含条件
**错误**：忘记公共边、对顶角等隐含条件
**正确**：解题时要善于发现隐含条件

# 三角形 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十一章 三角形
- **重要程度**: 重点

## 知识内容

### 1. 三角形的有关概念

**定义**：由不在同一条直线上的三条线段首尾顺次相接所组成的图形叫做三角形

**相关概念**：
- 边：三角形的线段
- 角：相邻两边组成的角
- 顶点：相邻两边的公共端点

**表示方法**：△ABC，读作"三角形ABC"

### 2. 三角形的分类

**按角分类**：
```
三角形
├── 锐角三角形（三个角都是锐角）
├── 直角三角形（有一个角是直角）
└── 钝角三角形（有一个角是钝角）
```

**按边分类**：
```
三角形
├── 不等边三角形（三边都不相等）
└── 等腰三角形
    ├── 等边三角形（三边都相等）
    └── 底和腰不等的等腰三角形
```

### 3. 三角形的三边关系

**定理**：三角形两边之和大于第三边，两边之差小于第三边

**应用**：
1. 判断三条线段能否组成三角形
2. 确定第三边的取值范围

**公式**：|a - b| < c < a + b

### 4. 三角形的重要线段

**高**：从顶点向对边作垂线，顶点与垂足之间的线段

**中线**：连接顶点与对边中点的线段

**角平分线**：三角形一个角的平分线与对边相交，这个角的顶点与交点之间的线段

**性质**：
- 三角形的高、中线、角平分线都是线段
- 三条高（或中线、角平分线）交于一点

### 5. 三角形的内角和

**定理**：三角形三个内角的和等于180°

**推论**：
1. 直角三角形的两个锐角互余
2. 三角形的外角等于与它不相邻的两个内角的和
3. 三角形的外角大于与它不相邻的任何一个内角

### 6. 多边形

**定义**：在平面内，由一些线段首尾顺次相接组成的封闭图形叫做多边形

**正多边形**：各边相等，各角也相等的多边形

**内角和公式**：(n-2) × 180°

**外角和**：360°（与边数无关）

## 典型例题

**例题1**：下列长度的三条线段能组成三角形的是（  ）
A. 1, 2, 3    B. 2, 3, 6    C. 3, 4, 5    D. 4, 4, 9

**答案**：C

**解析**：根据三角形三边关系，两边之和大于第三边。C选项中3+4>5，能组成三角形。

**例题2**：一个三角形的两个内角分别是40°和60°，这个三角形是（  ）
A. 锐角三角形    B. 直角三角形    C. 钝角三角形    D. 无法确定

**答案**：B

**解析**：第三个角 = 180° - 40° - 60° = 80°，三个角都是锐角，是锐角三角形。

**例题3**：一个多边形的内角和是1080°，它是几边形？

**解**：设它是n边形
```
(n-2) × 180° = 1080°
n - 2 = 6
n = 8
```
答：它是八边形。

## 易错点提醒

### 易错点1：三边关系判断错误
**错误**：1+2=3，能组成三角形
**正确**：1+2=3，不满足"大于"，不能组成三角形

### 易错点2：内角和公式记错
**错误**：多边形内角和 = n × 180°
**正确**：多边形内角和 = (n-2) × 180°

### 易错点3：外角性质混淆
**错误**：三角形的外角等于任意一个内角
**正确**：三角形的外角等于与它不相邻的两个内角的和

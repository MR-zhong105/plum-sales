# 平行四边形 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十八章 平行四边形
- **重要程度**: 重点

## 知识内容

### 1. 平行四边形

**定义**：两组对边分别平行的四边形叫做平行四边形

**性质**：
| 性质 | 内容 |
|------|------|
| 边 | 对边平行且相等 |
| 角 | 对角相等，邻角互补 |
| 对角线 | 互相平分 |

**判定方法**：
| 判定 | 条件 |
|------|------|
| 定义法 | 两组对边分别平行 |
| 边 | 两组对边分别相等 |
| 边 | 一组对边平行且相等 |
| 角 | 两组对角分别相等 |
| 对角线 | 对角线互相平分 |

### 2. 矩形

**定义**：有一个角是直角的平行四边形叫做矩形

**性质**：
- 具有平行四边形的所有性质
- 四个角都是直角
- 对角线相等且互相平分

**判定方法**：
1. 有一个角是直角的平行四边形是矩形
2. 对角线相等的平行四边形是矩形
3. 有三个角是直角的四边形是矩形

**重要定理**：直角三角形斜边上的中线等于斜边的一半

### 3. 菱形

**定义**：有一组邻边相等的平行四边形叫做菱形

**性质**：
- 具有平行四边形的所有性质
- 四条边都相等
- 对角线互相垂直，每条对角线平分一组对角

**判定方法**：
1. 有一组邻边相等的平行四边形是菱形
2. 对角线互相垂直的平行四边形是菱形
3. 四条边都相等的四边形是菱形

**面积公式**：S = 对角线乘积的一半 = ab/2

### 4. 正方形

**定义**：有一组邻边相等且有一个角是直角的平行四边形叫做正方形

**性质**：
- 具有平行四边形、矩形、菱形的所有性质
- 四条边都相等
- 四个角都是直角
- 对角线相等、垂直且互相平分

**判定方法**：
1. 有一组邻边相等的矩形是正方形
2. 有一个角是直角的菱形是正方形
3. 对角线互相垂直且相等的平行四边形是正方形

### 5. 中位线定理

**三角形中位线**：连接三角形两边中点的线段

**定理**：三角形的中位线平行于第三边，并且等于第三边的一半

**梯形中位线**：连接梯形两腰中点的线段

**定理**：梯形的中位线平行于两底，并且等于两底和的一半

## 典型例题

**例题1**：如图，在□ABCD中，对角线AC、BD相交于点O，下列条件不能判定□ABCD是矩形的是（  ）
A. AC = BD
B. ∠ABC = 90°
C. AB = BC
D. ∠DAO = ∠ADO

**答案**：C

**解析**：AB = BC只能说明是菱形，不能说明是矩形

**例题2**：如图，在菱形ABCD中，对角线AC、BD相交于点O，下列结论不一定成立的是（  ）
A. AB = AD
B. AC ⊥ BD
C. AC = BD
D. ∠DAC = ∠BAC

**答案**：C

**解析**：菱形的对角线不一定相等

**例题3**：如图，在△ABC中，D、E、F分别是AB、AC、BC的中点，若△DEF的周长为10，则△ABC的周长为多少？

**解**：
∵ D、E、F分别是AB、AC、BC的中点
∴ DE、EF、DF分别是△ABC的中位线
∴ DE = 1/2 BC，EF = 1/2 AB，DF = 1/2 AC

∴ △DEF的周长 = 1/2 △ABC的周长
∴ △ABC的周长 = 2 × 10 = 20

## 易错点提醒

### 易错点1：矩形和菱形判定混淆
**错误**：对角线相等的四边形是矩形
**正确**：对角线相等的平行四边形是矩形

### 易错点2：菱形面积公式记错
**错误**：菱形面积 = 边长 × 高（这是平行四边形面积）
**正确**：菱形面积 = 对角线乘积的一半

### 易错点3：正方形判定遗漏条件
**错误**：对角线相等的菱形是正方形
**正确**：对角线相等的菱形一定是正方形（这个是正确的，但要注意逻辑）

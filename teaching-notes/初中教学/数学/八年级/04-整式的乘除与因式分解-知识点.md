# 整式的乘除与因式分解 知识点

## 基本信息

- **学科**: 数学
- **年级**: 八年级
- **所属单元**: 第十四章 整式的乘除与因式分解
- **重要程度**: 重点

## 知识内容

### 1. 幂的运算性质

| 公式 | 名称 |
|------|------|
| a^m · a^n = a^(m+n) | 同底数幂相乘 |
| a^m ÷ a^n = a^(m-n) | 同底数幂相除 |
| (a^m)^n = a^(mn) | 幂的乘方 |
| (ab)^n = a^n · b^n | 积的乘方 |
| a^0 = 1 (a≠0) | 零指数幂 |
| a^(-p) = 1/a^p | 负整数指数幂 |

### 2. 整式的乘法

**单项式×单项式**：
系数相乘，同底数幂相乘，单独字母照抄

**单项式×多项式**：
分配律：m(a+b+c) = ma + mb + mc

**多项式×多项式**：
(a+m)(a+n) = a² + (m+n)a + mn

**乘法公式**：
| 公式 | 名称 |
|------|------|
| (a+b)² = a² + 2ab + b² | 完全平方和公式 |
| (a-b)² = a² - 2ab + b² | 完全平方差公式 |
| (a+b)(a-b) = a² - b² | 平方差公式 |

### 3. 整式的除法

**单项式÷单项式**：
系数相除，同底数幂相除，单独字母照抄

**多项式÷单项式**：
分配律：(a+b+c)÷m = a÷m + b÷m + c÷m

### 4. 因式分解

**定义**：把一个多项式化成几个整式的积的形式

**方法**：

#### （1）提公因式法
```
ma + mb + mc = m(a + b + c)
```

#### （2）公式法
```
a² - b² = (a+b)(a-b)           # 平方差公式
a² ± 2ab + b² = (a±b)²        # 完全平方公式
```

#### （3）十字相乘法
```
x² + (p+q)x + pq = (x+p)(x+q)
```

### 5. 因式分解与整式乘法的关系

```
因式分解 ←→ 整式乘法
（互逆运算）
```

## 典型例题

**例题1**：计算 (2x²y)³

**解**：
(2x²y)³ = 2³ · (x²)³ · y³ = 8x⁶y³

**例题2**：计算 (a+3)²

**解**：
(a+3)² = a² + 6a + 9

**例题3**：因式分解 x² - 9

**解**：
x² - 9 = x² - 3² = (x+3)(x-3)

**例题4**：因式分解 x² + 5x + 6

**解**：
x² + 5x + 6 = (x+2)(x+3)

**例题5**：因式分解 2x² - 8

**解**：
2x² - 8 = 2(x² - 4) = 2(x+2)(x-2)

## 易错点提醒

### 易错点1：幂的运算混淆
**错误**：a² · a³ = a⁶
**正确**：a² · a³ = a⁵（同底数幂相乘，指数相加）

### 易错点2：完全平方公式漏项
**错误**：(a+b)² = a² + b²
**正确**：(a+b)² = a² + 2ab + b²

### 易错点3：因式分解不彻底
**错误**：x⁴ - 1 = (x²+1)(x²-1)
**正确**：x⁴ - 1 = (x²+1)(x+1)(x-1)

### 易错点4：负指数计算错误
**错误**：2⁻³ = -8
**正确**：2⁻³ = 1/8

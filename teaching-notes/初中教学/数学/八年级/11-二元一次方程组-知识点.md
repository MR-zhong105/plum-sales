# 二元一次方程组

> 七年级数学核心知识点

## 知识内容

### 1. 相关概念

- **二元一次方程**：含有两个未知数，含未知数的项的次数都是1的方程
- **二元一次方程组**：由两个二元一次方程组成的方程组
- **方程组的解**：使两个方程都成立的未知数的值

### 2. 解法

**代入消元法**：
1. 用一个方程表示一个未知数（用另一个未知数表示）
2. 代入另一个方程，消去一个未知数
3. 解一元一次方程
4. 回代求另一个未知数

**加减消元法**：
1. 将两个方程的某一未知数的系数化为相等或相反
2. 两式相加或相减，消去一个未知数
3. 解一元一次方程
4. 回代求另一个未知数

### 3. 应用题类型

| 类型 | 等量关系 |
|------|---------|
| 配套问题 | 甲:乙 = 配套比 |
| 行程问题 | 路程 = 速度 × 时间 |
| 工程问题 | 工作总量 = 工作效率 × 时间 |
| 利润问题 | 利润 = 售价 - 进价 |
| 数字问题 | 十位×10 + 个位 = 数值 |

## 典型例题

**例题1**：解方程组 $\begin{cases} x+y=5 \ 2x-y=1 \end{cases}$
**解**：两式相加：3x=6，x=2
　　代入：2+y=5，y=3
　　∴ $\begin{cases} x=2 \ y=3 \end{cases}$

**例题2**：（中考题）已知 $\begin{cases} x=2 \ y=1 \end{cases}$ 是方程ax+by=3的解，则2a+b=____
**答案**：2a+b = a·2+b·1 = 3

## 易错点提醒

### 易错点1：代入时忘记加括号
**正确**：代入时若表达式含加减，要加括号

### 易错点2：检验遗漏
**正确**：解完后代入原方程组检验

# 圆 知识点

## 基本信息

- **学科**: 数学
- **年级**: 九年级
- **所属单元**: 第二十四章 圆
- **重要程度**: 重点

## 知识内容

### 1. 圆的基本概念

**定义**：平面上到定点的距离等于定长的所有点组成的图形叫做圆

**相关概念**：
- 圆心：定点O
- 半径：定长r
- 弦：连接圆上两点的线段
- 直径：经过圆心的弦（最长的弦）
- 弧：圆上任意两点间的部分
- 圆周角：顶点在圆上，两边与圆相交的角
- 圆心角：顶点在圆心的角

### 2. 圆的性质

#### （1）垂径定理
**内容**：垂直于弦的直径平分这条弦，并且平分弦所对的两条弧

**推论**：
- 平分弦（不是直径）的直径垂直于弦
- 弦的垂直平分线经过圆心
- 平分弧的直径垂直平分弧所对的弦

#### （2）圆心角、弧、弦的关系
在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦也相等

#### （3）圆周角定理
**内容**：一条弧所对的圆周角等于它所对的圆心角的一半

**推论**：
- 同弧或等弧所对的圆周角相等
- 直径所对的圆周角是直角（90°）
- 90°的圆周角所对的弦是直径

### 3. 点与圆的位置关系

| 位置关系 | 数量关系 |
|----------|----------|
| 点在圆内 | d < r |
| 点在圆上 | d = r |
| 点在圆外 | d > r |

### 4. 直线与圆的位置关系

| 位置关系 | 公共点个数 | 圆心到直线距离d与半径r的关系 |
|----------|------------|------------------------------|
| 相离 | 0个 | d > r |
| 相切 | 1个 | d = r |
| 相交 | 2个 | d < r |

**切线的判定**：
1. 经过半径外端且垂直于这条半径的直线是圆的切线
2. 圆心到直线的距离等于半径

**切线的性质**：
- 切线垂直于过切点的半径
- 从圆外一点引圆的两条切线，切线长相等

### 5. 弧长与扇形面积

**弧长公式**：l = nπr/180

**扇形面积公式**：
```
S = nπr²/360 = 1/2·l·r
```

**圆锥的侧面展开图**：
- 侧面展开是扇形
- 扇形半径 = 圆锥母线长l
- 扇形弧长 = 圆锥底面周长2πr
- 侧面积 = πrl
- 表面积 = πrl + πr²

## 典型例题

**例题1**：已知圆的半径为5cm，圆心到直线l的距离为3cm，则直线l与圆的位置关系是（  ）
A. 相离    B. 相切    C. 相交    D. 无法确定

**答案**：C

**解析**：d = 3 < r = 5，所以直线与圆相交。

**例题2**：如图，AB是⊙O的直径，点C在⊙O上，∠A = 30°，求∠B的度数。

**解**：
∵ AB是直径
∴ ∠C = 90°（直径所对的圆周角是直角）

∵ ∠A + ∠B + ∠C = 180°
∴ ∠B = 180° - 90° - 30° = 60°

**例题3**：已知扇形的圆心角为120°，半径为6cm，求扇形的面积。

**解**：
S = nπr²/360
= 120 × π × 6²/360
= 120 × 36π/360
= 12π cm²

## 易错点提醒

### 易错点1：圆周角定理记错
**错误**：圆周角等于圆心角
**正确**：圆周角等于圆心角的一半

### 易错点2：切线判定条件遗漏
**错误**：垂直于半径的直线是切线
**正确**：必须同时满足"经过半径外端"和"垂直于半径"

### 易错点3：弧长公式记错
**错误**：l = nπr/360
**正确**：l = nπr/180

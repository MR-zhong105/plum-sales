# 一元二次方程 知识点

## 基本信息

- **学科**: 数学
- **年级**: 九年级
- **所属单元**: 第二十一章 一元二次方程
- **重要程度**: 重点

## 知识内容

### 1. 一元二次方程的概念

**定义**：只含有一个未知数（元），未知数的最高次数是2，等号两边都是整式的方程

**一般形式**：ax² + bx + c = 0（a ≠ 0）

**注意**：a ≠ 0 是一元二次方程的根本条件

### 2. 解一元二次方程

#### （1）直接开平方法
```
x² = a（a ≥ 0）
x = ±√a
```

#### （2）配方法
```
步骤：
1. 二次项系数化为1
2. 移项
3. 配方（两边加一次项系数一半的平方）
4. 开方
```

#### （3）公式法
```
求根公式：
x = (-b ± √(b²-4ac)) / 2a

判别式：Δ = b² - 4ac

Δ > 0 → 两个不相等的实数根
Δ = 0 → 两个相等的实数根
Δ < 0 → 无实数根
```

#### （4）因式分解法
```
步骤：
1. 移项，使右边为0
2. 左边因式分解
3. 令每个因式为0，解方程
```

### 3. 韦达定理

**内容**：若x₁、x₂是ax² + bx + c = 0的两个根，则
```
x₁ + x₂ = -b/a
x₁ · x₂ = c/a
```

### 4. 应用题类型

| 类型 | 公式 |
|------|------|
| 增长率问题 | a(1+x)ⁿ = b |
| 利润问题 | 利润 = 售价 - 进价 |
| 面积问题 | 根据面积公式列方程 |
| 数字问题 | 设未知数表示数字 |

## 典型例题

**例题1**：解方程 x² - 5x + 6 = 0

**解**：
因式分解：(x-2)(x-3) = 0
∴ x₁ = 2，x₂ = 3

**例题2**：关于x的方程 x² - 4x + m = 0 有两个相等的实数根，求m的值。

**解**：
∵ 方程有两个相等的实数根
∴ Δ = 0
∴ (-4)² - 4×1×m = 0
∴ 16 - 4m = 0
∴ m = 4

**例题3**：某商品原价100元，经过两次涨价后价格为121元，求平均每次涨价的百分率。

**解**：设平均每次涨价x
```
100(1+x)² = 121
(1+x)² = 1.21
1+x = ±1.1
x₁ = 0.1 = 10%
x₂ = -2.1（不合题意，舍去）
```
答：平均每次涨价10%。

## 易错点提醒

### 易错点1：忽略二次项系数不为0
**错误**：m²x² + mx - 1 = 0是一元二次方程
**正确**：需满足m² ≠ 0，即m ≠ 0

### 易错点2：判别式符号错误
**错误**：Δ = b² + 4ac
**正确**：Δ = b² - 4ac

### 易错点3：增根未舍去
**错误**：解出x=-3直接用
**正确**：需检验是否符合题意

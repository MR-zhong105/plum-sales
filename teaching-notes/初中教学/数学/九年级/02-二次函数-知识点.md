# 二次函数 知识点

## 基本信息

- **学科**: 数学
- **年级**: 九年级
- **所属单元**: 第二十二章 二次函数
- **重要程度**: 重点

## 知识内容

### 1. 二次函数的概念

**定义**：一般地，形如y = ax² + bx + c（a ≠ 0）的函数叫做二次函数

**注意**：a ≠ 0是二次函数的根本条件

### 2. 二次函数的图像与性质

#### （1）y = ax²

| a > 0 | a < 0 |
|-------|-------|
| 开口向上 | 开口向下 |
| 有最低点 | 有最高点 |
| 顶点(0,0) | 顶点(0,0) |
| 对称轴y轴 | 对称轴y轴 |

#### （2）y = a(x-h)² + k

| 性质 | 内容 |
|------|------|
| 顶点 | (h, k) |
| 对称轴 | 直线x = h |
| 开口方向 | a > 0向上，a < 0向下 |
| 最值 | a > 0时，x=h时y最小=k；a < 0时，x=h时y最大=k |

### 3. 二次函数与一元二次方程的关系

**抛物线与x轴交点个数**：
- Δ > 0 → 两个交点
- Δ = 0 → 一个交点（相切）
- Δ < 0 → 无交点

**交点坐标**：令y = 0，解方程ax² + bx + c = 0

### 4. 二次函数的应用

**最值问题**：
- 求最大面积、最大利润等
- 利用顶点坐标公式

**综合应用**：
- 利润问题
- 面积问题
- 运动问题

## 典型例题

**例题1**：已知二次函数y = 2x² - 4x + 1，求：
(1) 开口方向
(2) 对称轴
(3) 顶点坐标
(4) 最值

**解**：
(1) a = 2 > 0，开口向上
(2) x = -b/(2a) = 4/4 = 1
(3) 顶点坐标(1, -1)
(4) 当x = 1时，y最小 = -1

**例题2**：求抛物线y = x² - 4x + 3与x轴的交点坐标。

**解**：
令y = 0：
```
x² - 4x + 3 = 0
(x-1)(x-3) = 0
x₁ = 1，x₂ = 3
```
∴ 交点坐标为(1, 0)和(3, 0)

**例题3**：某商品进价40元，售价60元时每天可卖出300件。售价每涨1元，销量减少10件。求售价多少时利润最大？

**解**：设售价涨x元，利润为y元
```
y = (60 + x - 40)(300 - 10x)
y = (20 + x)(300 - 10x)
y = -10x² + 100x + 6000
y = -10(x-5)² + 6250
```
当x = 5时，y最大 = 6250
售价 = 60 + 5 = 65元

答：售价65元时利润最大，最大利润6250元。

## 易错点提醒

### 易错点1：忽略a≠0
**错误**：y = (m-1)x² + 2x + 1是二次函数
**正确**：需满足m - 1 ≠ 0，即m ≠ 1

### 易错点2：顶点坐标公式记错
**错误**：顶点横坐标x = b/(2a)
**正确**：顶点横坐标x = -b/(2a)

### 易错点3：最值问题忘记检验
**错误**：直接写顶点最值
**正确**：需检验自变量取值范围

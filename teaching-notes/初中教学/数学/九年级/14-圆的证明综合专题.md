# 圆的证明综合专题

> 九年级数学中考压轴题核心题型

## 知识内容

### 1. 圆的基本性质

| 定理 | 内容 |
|------|------|
| 垂径定理 | 垂直于弦的直径平分弦，并且平分弦所对的两条弧 |
| 圆心角定理 | 在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦相等 |
| 圆周角定理 | 一条弧所对的圆周角等于它所对的圆心角的一半 |
| 推论 | 同弧或等弧所对的圆周角相等；直径所对的圆周角是直角 |

### 2. 点与圆的位置关系

| 位置 | 条件 |
|------|------|
| 点在圆外 | d > r |
| 点在圆上 | d = r |
| 点在圆内 | d < r |

### 3. 直线与圆的位置关系

| 位置 | 条件 | 公共点个数 |
|------|------|-----------|
| 相离 | d > r | 0 |
| 相切 | d = r | 1 |
| 相交 | d < r | 2 |

### 4. 切线的判定与性质

**判定**：
- 过半径外端且垂直于半径的直线是切线
- 到圆心的距离等于半径的直线是切线

**性质**：
- 切线垂直于过切点的半径
- 从圆外一点引圆的两条切线，切线长相等

### 5. 弧长与扇形面积

- 弧长公式：l = nπr/180
- 扇形面积公式：S = nπr²/360 = lr/2
- 圆锥侧面展开图：扇形半径=母线长l，弧长=底面周长2πr

### 6. 圆中的常见模型

| 模型 | 特点 | 常用方法 |
|------|------|---------|
| 弦切角模型 | 弦切角等于所夹弧所对圆周角 | 连半径证垂直 |
| 内接四边形 | 对角互补，外角等于内对角 | 找圆周角 |
| 切线长模型 | 从圆外一点引两条切线 | 连圆心和切点 |
| 垂径定理模型 | 弦、直径、弦心距 | 构造直角三角形 |

## 典型例题

**例题1**：（中考题）如图，AB是⊙O的直径，C是⊙O上一点，AD⊥CD于点D，AC平分∠DAB。
(1) 求证：CD是⊙O的切线；
(2) 若AB=10，AC=8，求AD的长。

**证明**：
(1) 连接OC
∵OA=OC，∴∠OAC=∠OCA
∵AC平分∠DAB，∴∠DAC=∠OAC
∴∠DAC=∠OCA，∴OC∥AD
∵AD⊥CD，∴OC⊥CD
∴CD是⊙O的切线

(2) 连接BC
∵AB是直径，∴∠ACB=90°
在Rt△ABC中，BC=√(AB²-AC²)=√(100-64)=6
∵∠DAC=∠CAB，∠ADC=∠ACB=90°
∴△ADC∽△ACB
∴AD/AC=AC/AB，AD=AC²/AB=64/10=6.4

**例题2**：如图，PA、PB是⊙O的切线，A、B为切点，∠APB=60°，PA=6cm，求⊙O的半径。
**解**：连接OA、OB、OP
∵PA、PB是切线，∴OA⊥PA，∠APO=30°
在Rt△APO中，OA=PA·tan30°=6×√3/3=2√3cm

## 易错点提醒

### 易错点1：切线判定漏掉"过半径外端"
**正确**：必须同时满足"过半径外端"和"垂直于半径"两个条件

### 易错点2：圆周角定理忘记"同弧或等弧"
**正确**：同弧或等弧所对的圆周角相等

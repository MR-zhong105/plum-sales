# 相似三角形

> 九年级数学核心知识点，中考必考

## 知识内容

### 1. 相似三角形定义

对应角相等，对应边成比例的三角形叫做相似三角形

**记法**：△ABC ∽ △DEF

### 2. 相似三角形的判定

| 判定方法 | 条件 |
|----------|------|
| 定义法 | 三个角对应相等，三边对应成比例 |
| AA | 两角对应相等 |
| SAS | 两边对应成比例且夹角相等 |
| SSS | 三边对应成比例 |

**直角三角形**：斜边和一条直角边对应成比例（HL相似）

### 3. 相似三角形的性质

- 对应角相等，对应边成比例
- 相似比：对应边的比 k
- 面积比 = k²
- 周长比 = k
- 对应高、对应中线、对应角平分线之比 = k

### 4. 常见相似模型

| 模型 | 特点 |
|------|------|
| A字型 | 平行线截三角形 |
| X字型 | 平行线截对角线 |
| 母子型 | 直角三角形斜边上的高 |
| 手拉手 | 共顶点相似 |

### 5. 平行线分线段成比例

三条平行线截两条直线，所得的对应线段成比例

## 典型例题

**例题1**：（中考题）如图，DE∥BC，AD=2，DB=3，则△ADE与△ABC的面积比是（）
A. 2:3  B. 4:9  C. 4:25  D. 2:5
**答案**：C（AD:AB=2:5，面积比=4:25）

**例题2**：在△ABC中，D、E分别是AB、AC上的点，DE∥BC，AD=3，DB=2，AE=4.5，求EC
**解**：AD/DB = AE/EC，3/2 = 4.5/EC，EC = 3

## 易错点提醒

### 易错点1：相似比与全等混淆
**正确**：相似比k=1时，两三角形全等

### 易错点2：面积比等于相似比
**正确**：面积比=相似比的平方

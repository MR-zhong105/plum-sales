# 中考真题汇编：数与代数

> 中考高频考点专题

## 知识内容

### 1. 实数

**考点**：
- 相反数、绝对值、倒数
- 科学记数法
- 实数运算

**真题示例**：
- 计算：|−3| + (π−3)⁰ − √9 + (1/2)⁻¹
- 答案：3 + 1 − 3 + 2 = 3

### 2. 整式与因式分解

**考点**：
- 整式加减乘除
- 乘法公式
- 因式分解

**真题示例**：
- 化简：(a+2)²−(a+1)(a−1)
- 答案：a²+4a+4−(a²−1) = 4a+5

### 3. 分式

**考点**：
- 分式有意义的条件
- 分式化简求值
- 分式方程

**真题示例**：
- 先化简，再求值：(x²−1)/(x²−2x+1) ÷ (x+1)/(x−1)，其中x=2
- 答案：原式=1，当x=2时，值为1

### 4. 方程与不等式

**考点**：
- 一元一次方程
- 一元二次方程
- 不等式组

**真题示例**：
- 解方程：x²−4x+3=0
- 答案：x₁=1，x₂=3

- 解不等式组：{x−1>0, 2x−4≤0}
- 答案：1<x≤2

### 5. 函数

**考点**：
- 一次函数
- 反比例函数
- 二次函数

**真题示例**：
- 已知二次函数y=ax²+bx+c的图像过点(1,0)、(3,0)、(0,−3)，求解析式
- 答案：y=x²−4x+3

## 答题技巧

1. **计算题**：仔细审题，注意符号，步步有据
2. **化简求值**：先化简再代入，避免直接代入复杂计算
3. **方程不等式**：注意检验，不等式注意方向
4. **函数题**：画图辅助，数形结合

## 易错点提醒

- 绝对值化简忘记分类讨论
- 分式方程忘记检验
- 不等式两边同乘负数忘记变号
- 函数最值忘记考虑定义域

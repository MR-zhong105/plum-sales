# 旋转 知识点

## 基本信息

- **学科**: 数学
- **年级**: 九年级
- **所属单元**: 第二十三章 旋转
- **重要程度**: 重点

## 知识内容

### 1. 旋转的概念

**定义**：在平面内，把一个图形绕着一个定点沿某个方向转动一个角度，这样的图形运动叫做旋转

**相关概念**：
- 旋转中心：定点O
- 旋转方向：顺时针或逆时针
- 旋转角：对应点与旋转中心连线的夹角

**性质**：
1. 对应点到旋转中心的距离相等
2. 对应点与旋转中心所连线段的夹角等于旋转角
3. 旋转前后的图形全等

### 2. 中心对称

**定义**：把一个图形绕着某一点旋转180°，如果它能够与另一个图形重合，那么就说这两个图形关于这个点对称

**性质**：
- 对称点所连线段都经过对称中心
- 对称点所连线段被对称中心平分

**中心对称图形**：
- 平行四边形
- 矩形
- 菱形
- 正方形
- 圆

### 3. 坐标变换

| 变换 | 坐标变化 |
|------|----------|
| 关于x轴对称 | (x, y) → (x, -y) |
| 关于y轴对称 | (x, y) → (-x, y) |
| 关于原点对称 | (x, y) → (-x, -y) |
| 顺时针旋转90° | (x, y) → (y, -x) |
| 逆时针旋转90° | (x, y) → (-y, x) |

## 典型例题

**例题1**：如图，△ABC绕点O旋转后得到△DEF，已知∠A = 60°，∠B = 70°，求∠F的度数。

**解**：
∵ △ABC ≌ △DEF（旋转不改变图形大小）
∴ ∠F = ∠C

∵ ∠A + ∠B + ∠C = 180°
∴ ∠C = 180° - 60° - 70° = 50°

∴ ∠F = 50°

**例题2**：点P(3, -4)关于原点对称的点的坐标是（  ）
A. (-3, 4)    B. (3, 4)    C. (-3, -4)    D. (4, -3)

**答案**：A

**例题3**：如图，在□ABCD中，对角线AC、BD相交于点O，E、F是对角线AC上的两点，当E、F满足什么条件时，四边形BFDE是平行四边形？

**解**：当OE = OF时，四边形BFDE是平行四边形。

证明：
∵ 四边形ABCD是平行四边形
∴ OB = OD，OA = OC

∵ OE = OF
∴ OE + OA = OF + OC（或OE - OA = OF - OC）
∴ AE = CF

∴ 四边形BFDE是平行四边形（对角线互相平分的四边形是平行四边形）

## 易错点提醒

### 易错点1：旋转角搞错
**错误**：旋转角是任意两点的夹角
**正确**：旋转角是对应点与旋转中心连线的夹角

### 易错点2：中心对称与轴对称混淆
**错误**：中心对称就是轴对称
**正确**：中心对称绕点旋转180°，轴对称沿直线对折

### 易错点3：坐标变换记错
**错误**：关于x轴对称，y不变
**正确**：关于x轴对称，x不变，y变号

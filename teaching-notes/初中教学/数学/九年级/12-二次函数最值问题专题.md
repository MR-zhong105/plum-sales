# 二次函数最值问题专题

> 九年级数学中考核心题型

## 知识内容

### 1. 二次函数最值公式

**顶点式**：y = a(x-h)² + k
- 顶点坐标：(h, k)
- 当a>0时，x=h时，y最小=k
- 当a<0时，x=h时，y最大=k

**一般式**：y = ax² + bx + c
- 对称轴：x = -b/(2a)
- 顶点纵坐标：y = (4ac-b²)/(4a)

### 2. 实际应用中的最值问题

**利润最大化**：
- 利润 = (售价 - 进价) × 销售量
- 销售量通常与售价成一次函数关系
- 建立二次函数模型，求顶点

**面积最大化**：
- 矩形面积 = 长 × 宽
- 利用周长约束建立函数关系
- 求顶点或端点最值

**费用最小化**：
- 总费用 = 固定费用 + 变动费用
- 建立二次函数模型

### 3. 定义域限制

**实际问题中的定义域**：
- 自变量有范围限制（如时间≥0，长度>0）
- 需判断顶点是否在定义域内
- 若顶点不在定义域内，最值在端点取得

### 4. 解题步骤

1. 设未知数，建立函数关系式
2. 确定定义域
3. 求顶点坐标（对称轴）
4. 判断顶点是否在定义域内
5. 比较顶点与端点函数值
6. 得出结论

## 典型例题

**例题1**：（中考题）某商品进价为每件40元，售价为每件50元时，每月可卖出210件。如果每件商品的售价每上涨1元，则每月少卖10件。
(1) 设每件商品的售价上涨x元(x为正整数)，每月利润为y元，求y与x的函数关系式；
(2) 每件商品的售价定为多少元时，每月可获得最大利润？最大利润是多少？

**解**：
(1) y = (50+x-40)(210-10x) = (10+x)(210-10x) = -10x²+110x+2100
(2) 对称轴x = -110/(2×(-10)) = 5.5
    ∵x为正整数，∴x=5或x=6
    当x=5时，y=-10×25+110×5+2100=2400
    当x=6时，y=-10×36+110×6+2100=2400
    ∴售价为55元或66元时，最大利润为2400元

**例题2**：用24m长的篱笆围成一个一面靠墙的矩形花圃，求面积最大值。
**解**：设宽为xm，则长为(24-2x)m
    S = x(24-2x) = -2x²+24x = -2(x-6)²+72
    当x=6时，S最大=72m²
    此时长为24-12=12m

## 易错点提醒

### 易错点1：忘记考虑定义域
**正确**：实际问题中自变量有范围，需判断顶点是否在范围内

### 易错点2：最值在端点时计算错误
**正确**：顶点不在定义域内时，最值在离对称轴较近的端点取得

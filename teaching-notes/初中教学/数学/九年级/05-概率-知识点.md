# 概率 知识点

## 基本信息

- **学科**: 数学
- **年级**: 九年级
- **所属单元**: 第二十五章 概率初步
- **重要程度**: 重点

## 知识内容

### 1. 随机事件

**定义**：在一定条件下，可能发生也可能不发生的事件叫做随机事件

**分类**：
| 类型 | 定义 | 概率 |
|------|------|------|
| 必然事件 | 在一定条件下必然发生的事件 | P = 1 |
| 不可能事件 | 在一定条件下不可能发生的事件 | P = 0 |
| 随机事件 | 在一定条件下可能发生也可能不发生的事件 | 0 < P < 1 |

### 2. 概率的概念

**定义**：一般地，在大量重复试验中，如果事件A发生的频率m/n会稳定在某个常数p附近，这个常数p就叫做事件A的概率，记作P(A) = p

**性质**：
- 0 ≤ P(A) ≤ 1
- P(必然事件) = 1
- P(不可能事件) = 0

### 3. 概率的计算

#### （1）列举法
当试验结果有限且等可能时，可以用列举法求概率。

```
P(A) = m/n
其中n为所有等可能结果数，m为事件A包含的结果数
```

#### （2）树状图法
用于两步或多步试验

#### （3）列表法
用于两步试验，列出所有可能结果

### 4. 用频率估计概率

**方法**：当试验次数很大时，频率稳定在概率附近，可用频率估计概率

**注意**：频率 ≠ 概率，频率是实验值，概率是理论值

## 典型例题

**例题1**：下列事件中，是随机事件的是（  ）
A. 太阳从东方升起
B. 明天会下雨
C. 水在0℃结冰
D. 三角形内角和为180°

**答案**：B

**解析**：明天可能下雨也可能不下雨，是随机事件。

**例题2**：一个不透明的袋子里装有3个红球和2个白球，这些球除颜色外都相同。从袋子中随机摸出一个球，摸到红球的概率是（  ）
A. 1/5    B. 2/5    C. 3/5    D. 2/3

**答案**：C

**解析**：P(红球) = 3/(3+2) = 3/5

**例题3**：同时掷两枚质地均匀的硬币，求下列事件的概率：
(1) 两枚正面朝上
(2) 一枚正面朝上，一枚反面朝上
(3) 至少有一枚正面朝上

**解**：
所有可能结果：(正,正)、(正,反)、(反,正)、(反,反)，共4种

(1) P(两正) = 1/4

(2) P(一正一反) = 2/4 = 1/2

(3) P(至少一正) = 3/4

## 易错点提醒

### 易错点1：概率为0的事件不可能发生
**错误**：概率为0的事件不可能发生
**正确**：概率为0的事件是不可能发生事件

### 易错点2：频率等于概率
**错误**：频率就是概率
**正确**：频率估计概率，频率是实验值，概率是理论值

### 易错点3：重复计算
**错误**：(正,反)和(反,正)算一种
**正确**：两种情况要分别计算

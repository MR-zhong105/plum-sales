# 初中教学笔记系统 - 快速开始

## 🎯 第一步：了解系统

打开 [[00-初中教学导航|初中教学导航]] 了解系统架构。

## 📝 第二步：创建第一份笔记

### 方式一：使用模板（推荐）
1. 在Obsidian中按 `Ctrl+N` 创建新笔记
2. 输入笔记标题
3. 在笔记中插入模板：`Ctrl+P` → "插入模板"
4. 选择对应的初中教学模板

### 方式二：手动创建
1. 在对应学科目录下创建笔记
2. 按照目录结构填写内容
3. 使用 `[[ ]]` 创建双向链接

## 📂 第三步：组织内容

### 教案结构
```
初中教学/
├── 数学/七年级/
│   ├── 01-正数和负数-教案.md
│   └── 02-正数和负数-知识点.md
├── 语文/七年级/
│   └── 03-春-教案.md
└── 试题库/七年级/
    └── 01-有理数单元测试.md
```

### 命名规范
- 格式：`序号-课题-类型.md`
- 示例：`01-正数和负数-教案.md`
- 类型：教案、知识点、试题、学生档案等

## 🏷️ 第四步：使用标签

### 必用标签
- `#初中教学` - 所有教学笔记
- `#七年级` / `#八年级` / `#九年级` - 年级
- `#教案` / `#知识点` / `#试题` - 内容类型

### 可选标签
- `#重点` / `#难点` / `#常考点` / `#易错点`
- `#单元测试` / `#期中` / `#期末` / `#中考`

## 💡 第六步：高效使用

### 每日备课流程
1. 打开 [[00-初中教学导航|教学导航]]
2. 查看今日课程对应的知识点笔记
3. 使用教案模板创建教案
4. 准备相关试题

### 考试后流程
1. 使用 [[Templates/初中教学/考试分析模板|考试分析模板]] 创建分析笔记
2. 记录学生错题
3. 更新学生档案
4. 完善知识点笔记

### 教研活动流程
1. 使用 [[Templates/初中教学/教研记录模板|教研记录模板]] 记录活动
2. 整理研讨成果
3. 应用到后续教学中

## ❓ 常见问题

**Q: 如何快速找到某节课的教案？**
A: 使用 `Ctrl+O` 搜索笔记标题，或使用标签过滤。

**Q: 如何查看某个知识点的所有教案？**
A: 点击知识点的反向链接，或使用图表视图。

**Q: 如何导入H盘的教案资料？**
A: 在相应资源库笔记中更新链接，或手动整理到对应目录。

# 初中教学笔记系统使用指南

## 🚀 快速开始

### 1. 创建第一份教案
1. 在Obsidian中按 `Ctrl+N` 创建新笔记
2. 选择模板：`初中教学/教案模板`
3. 填写学科、年级、课题等信息
4. 开始编写教案内容

### 2. 建立知识点笔记
1. 使用 `初中教学/知识点模板`
2. 按学科和单元组织知识点
3. 添加典型例题和易错点

### 3. 记录学生情况
1. 使用 `初中教学/学生档案模板`
2. 为每个重要学生建立档案
3. 记录学业表现和沟通情况

## 💡 高效使用技巧

### 1. 双向链接
- 在教案中链接到相关知识点：`[[二次函数]]`
- 在知识点中链接到相关教案：`[[二次函数教案]]`
- 使用反向链接查看知识点被哪些教案引用

### 2. 标签聚合
- 点击标签可查看该标签下所有笔记
- 方便按学科、年级、内容类型筛选

### 3. 搜索功能
- `Ctrl+O` 快速打开笔记
- `Ctrl+E` 搜索内容
- 使用标签过滤搜索结果

### 4. 图表视图
- 启用「关系图谱」查看笔记关联
- 发现知识点之间的联系

## 📝 日常 workflow

### 备课流程
1. 查看知识点笔记，明确教学重点
2. 使用教案模板创建教案
3. 制作配套课件
4. 准备相关试题

### 上课流程
1. 打开教案笔记
2. 按教学设计实施课堂
3. 记录课堂生成和问题

### 作业批改
1. 记录学生常见错误
2. 更新学生档案
3. 完善知识点笔记

### 考试分析
1. 使用考试分析模板
2. 统计成绩分布
3. 分析典型错误
4. 制定改进措施

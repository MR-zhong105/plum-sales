# 鸦片战争

> 八年级历史中考核心考点

## 知识内容

### 1. 战争背景

**根本原因**：英国完成工业革命，需要开辟海外市场和原料产地

**直接原因**：林则徐虎门销烟（1839年6月）

**贸易逆差**：中国出口茶叶、丝绸、瓷器，进口鸦片，导致白银外流

### 2. 战争过程

| 时间 | 事件 |
|------|------|
| 1840年6月 | 鸦片战争爆发，英军封锁珠江口 |
| 1841年 | 英军攻占厦门、定海，进犯广东 |
| 1842年 | 英军到达南京江面 |

### 3. 《南京条约》（1842年）

| 内容 | 影响 |
|------|------|
| 割香港岛给英国 | 中国领土主权开始遭到破坏 |
| 赔款2100万银元 | 加重人民负担 |
| 开放广州、厦门、福州、宁波、上海五处为通商口岸 | 中国开始丧失贸易自主权 |
| 协定关税 | 中国关税自主权开始丧失 |

**后续条约**：《虎门条约》（1843年）、《望厦条约》（1844年中美）、《黄浦条约》（1844年中法）

### 4. 战争影响

- 中国**开始沦为**半殖民地半封建社会
- 是中国近代史的开端
- 社会性质发生改变：从封建社会变为半殖民地半封建社会
- 主要矛盾：帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾
- 革命任务：反帝反封建

### 5. 林则徐

- 领导虎门销烟（1839年6月3日-25日），销毁鸦片237万斤
- 被誉为民族英雄
- 主张"睁眼看世界"，编译《四洲志》

## 典型例题

**例题1**：（中考题）鸦片战争成为中国近代史开端的理由是（）
A. 战争使中国战败
B. 战争改变了中国的社会性质
C. 战争签订了一系列不平等条约
D. 战争开放了通商口岸
**答案**：B

**例题2**：《南京条约》中，破坏中国关税自主权的是（）
A. 割香港岛  B. 赔款2100万银元  C. 开放五处通商口岸  D. 协定关税
**答案**：D

**例题3**：鸦片战争爆发的根本原因是（）
A. 林则徐虎门销烟
B. 英国需要开辟海外市场和原料产地
C. 中英贸易逆差
D. 清朝闭关锁国
**答案**：B

## 易错点提醒

### 易错点1：开始沦为 vs 完全沦为
- 鸦片战争→**开始沦为**半殖民地半封建社会
- 甲午中日战争→**大大加深**半殖民地化
- 八国联军侵华→**完全沦为**半殖民地半封建社会

### 易错点2：香港岛 vs 香港特别行政区
- 《南京条约》割的是**香港岛**
- 1997年回归的是**香港**（含香港岛、九龙、新界）

# 氧气 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第二单元 我们周围的空气
- **重要程度**: 重点

## 知识内容

### 1. 氧气的物理性质

- 无色、无味气体
- 密度比空气略大（1.429g/L）
- 不易溶于水（1L水溶解约30mL氧气）
- 三态变化：
  - 183℃ → 淡蓝色液体
  - -218℃ → 淡蓝色雪花状固体

### 2. 氧气的化学性质

**总体特征**：化学性质比较活泼，具有氧化性

**与物质反应**：

#### （1）与非金属反应

**碳(C)**：
- 在空气中：红热，无火焰
- 在氧气中：发出白光，放热，生成使澄清石灰水变浑浊的气体
- 方程式：C + O₂ → CO₂（点燃）

**硫(S)**：
- 在空气中：淡蓝色火焰
- 在氧气中：明亮的蓝紫色火焰，放热，生成有刺激性气味的气体
- 方程式：S + O₂ → SO₂（点燃）
- 注意：集气瓶底部放少量水，吸收SO₂，防止污染

**磷(P)**：
- 在空气中：黄白色火焰，产生大量白烟
- 在氧气中：剧烈燃烧，发出白光，产生大量白烟
- 方程式：4P + 5O₂ → 2P₂O₅（点燃）

**氢气(H₂)**：
- 在空气中：淡蓝色火焰
- 在氧气中：安静燃烧，发出淡蓝色火焰，放热
- 方程式：2H₂ + O₂ → 2H₂O（点燃）

#### （2）与金属反应

**铁(Fe)**：
- 在空气中：不能燃烧
- 在氧气中：剧烈燃烧，火星四射，放热，生成黑色固体
- 方程式：3Fe + 2O₂ → Fe₃O₄（点燃）
- 注意：集气瓶底部放少量水或细沙，防止高温熔融物炸裂瓶底

**铝(Al)**：
- 在空气中：表面生成致密氧化膜
- 在氧气中：剧烈燃烧，发出耀眼白光，放热，生成白色固体
- 方程式：4Al + 3O₂ → 2Al₂O₃（点燃）

**镁(Mg)**：
- 在空气中：发出耀眼白光，放热，生成白色固体
- 在氧气中：更剧烈
- 方程式：2Mg + O₂ → 2MgO（点燃）

**铜(Cu)**：
- 在空气中：加热变黑
- 在氧气中：加热变黑
- 方程式：2Cu + O₂ → 2CuO（加热）

#### （3）与化合物反应

**一氧化碳(CO)**：
- 在氧气中：蓝色火焰
- 方程式：2CO + O₂ → 2CO₂（点燃）

**甲烷(CH₄)**：
- 在氧气中：明亮的蓝色火焰
- 方程式：CH₄ + 2O₂ → CO₂ + 2H₂O（点燃）

**石蜡**：
- 在氧气中：发出白光，瓶壁有水雾，生成使石灰水变浑浊的气体

### 3. 反应类型

**化合反应**：由两种或两种以上物质生成另一种物质的反应
```
A + B → AB
```

**氧化反应**：物质与氧发生的反应
- 剧烈氧化：燃烧
- 缓慢氧化：呼吸、食物腐败、铁生锈

### 4. 氧气的制取

#### （1）实验室制法

**方法一：加热高锰酸钾**
- 药品：高锰酸钾(KMnO₄)
- 方程式：2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑（加热）
- 装置：固体加热型
- 步骤：查、装、定、点、收、离、熄
- 注意：试管口放一团棉花，防止粉末进入导管

**方法二：过氧化氢分解**
- 药品：过氧化氢(H₂O₂)溶液、二氧化锰(MnO₂)
- 方程式：2H₂O₂ → 2H₂O + O₂↑（MnO₂催化）
- 装置：固液常温型
- 优点：操作简单、安全、环保

#### （2）工业制法

**分离液态空气法**：
- 原理：利用氮气和氧气的沸点不同
- 过程：空气净化→液化→蒸发→分离
- 性质：物理变化

#### （3）收集方法

| 方法 | 原理 | 收集气体 |
|------|------|----------|
| 排水法 | 氧气不易溶于水 | 较纯净 |
| 向上排空气法 | 氧气密度比空气大 | 较干燥 |

**验满方法**：
- 排水法：集气瓶口有气泡冒出
- 向上排空气法：带火星木条放瓶口，复燃则满

**检验方法**：带火星木条伸入集气瓶，复燃则是氧气

### 5. 催化剂

**定义**：在化学反应里能改变其他物质的化学反应速率，而本身的质量和化学性质在反应前后都没有发生变化的物质

**特点**：
- "一变"：改变反应速率
- "两不变"：质量和化学性质不变

**注意**：
- 催化剂不是反应物也不是生成物
- 同一个反应可以有多种催化剂
- 催化剂有专一性

## 典型例题

**例题1**：下列关于氧气的说法正确的是（  ）
A. 氧气能支持燃烧，可用作燃料
B. 氧气约占总质量的21%
C. 鱼类能在水中生存，说明氧气易溶于水
D. 物质与氧气发生的反应都是氧化反应

**答案**：D

**例题2**：实验室用高锰酸钾制取氧气时，下列说法错误的是（  ）
A. 试管口要略向下倾斜
B. 试管口要放一团棉花
C. 先预热，再集中加热
D. 实验完毕先熄灭酒精灯，再移出导管

**答案**：D（应先移出导管，再熄灭酒精灯）

**例题3**：下列反应中，属于化合反应的是（  ），属于氧化反应的是（  ）。
① 硫 + 氧气 → 二氧化硫
② 蜡烛 + 氧气 → 二氧化碳 + 水
③ 氢气 + 氧气 → 水
④ 碱式碳酸铜 → 氧化铜 + 水 + 二氧化碳

**答案**：化合反应：①③；氧化反应：①②③

## 易错点提醒

### 易错点1：氧气是燃料
**错误**：氧气可以作燃料
**正确**：氧气能支持燃烧，但本身不能燃烧

### 易错点2：氧气易溶于水
**错误**：氧气易溶于水
**正确**：氧气不易溶于水

### 易错点3：催化剂只能加快反应速率
**错误**：催化剂只能加快反应速率
**正确**：催化剂可以加快也可以减慢反应速率

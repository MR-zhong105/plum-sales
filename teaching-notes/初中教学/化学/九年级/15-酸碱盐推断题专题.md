# 酸碱盐推断题专题

> 中考高频考点

## 知识内容

### 1. 常见物质颜色

| 物质 | 颜色 |
|------|------|
| Cu²⁺溶液 | 蓝色 |
| Fe²⁺溶液 | 浅绿色 |
| Fe³⁺溶液 | 黄色 |
| CuO | 黑色 |
| Fe₃O₄ | 黑色 |
| Cu | 红色 |
| Fe | 黑色粉末 |
| C | 黑色 |
| MnO₂ | 黑色 |
| CaCO₃ | 白色沉淀 |
| BaSO₄ | 白色沉淀（不溶于酸） |
| AgCl | 白色沉淀（不溶于酸） |
| Cu(OH)₂ | 蓝色沉淀 |
| Fe(OH)₃ | 红褐色沉淀 |
| BaCO₃ | 白色沉淀（溶于酸） |
| Ca(OH)₂ | 白色沉淀 |

### 2. 常见沉淀

| 沉淀 | 颜色 | 溶于酸？ |
|------|------|---------|
| CaCO₃ | 白色 | 溶 |
| BaCO₃ | 白色 | 溶 |
| BaSO₄ | 白色 | 不溶 |
| AgCl | 白色 | 不溶 |
| Cu(OH)₂ | 蓝色 | 溶 |
| Fe(OH)₃ | 红褐色 | 溶 |

### 3. 常见气体

| 气体 | 颜色 | 气味 | 检验方法 |
|------|------|------|---------|
| H₂ | 无色 | 无味 | 点燃，产物使无水CuSO₄变蓝 |
| O₂ | 无色 | 无味 | 带火星木条复燃 |
| CO₂ | 无色 | 无味 | 使澄清石灰水变浑浊 |
| CO | 无色 | 无味 | 可燃，还原CuO |
| HCl | 无色 | 刺激性 | 白雾，使湿润蓝色石蕊试纸变红 |
| NH₃ | 无色 | 刺激性 | 使湿润红色石蕊试纸变蓝 |
| SO₂ | 无色 | 刺激性 | 使品红溶液褪色 |

### 4. 推断题解题技巧

1. **找突破口**：颜色、沉淀、气体、特殊反应
2. **顺推逆推结合**：从已知条件正向推导，从结论反向验证
3. **代入检验**：将推断结果代入原题验证

### 5. 常见推断突破口

- **沉淀突破口**：白色沉淀（CaCO₃、BaCO₃、BaSO₄、AgCl、Ca(OH)₂）、蓝色沉淀[Cu(OH)₂]、红褐色沉淀[Fe(OH)₃]
- **气体突破口**：CO₂（使石灰水变浑）、O₂（复燃）、H₂（可燃）、NH₃（使石蕊变蓝）
- **颜色突破口**：Cu²⁺（蓝）、Fe²⁺（浅绿）、Fe³⁺（黄）
- **反应突破口**：实验室制CO₂（CaCO₃+HCl）、制O₂（H₂O₂/MnO₂）、炼铁（CO+Fe₂O₃）

## 典型例题

**例题1**：A-H是初中化学常见物质，A是大理石主要成分，B是胃酸主要成分，C是蓝色溶液，D是最常用的溶剂，E是红色金属，F是黑色氧化物，G是蓝色沉淀，H是白色沉淀。
推断：A=CaCO₃，B=HCl，C=CuCl₂，D=H₂O，E=Cu，F=CuO，G=Cu(OH)₂，H=AgCl

**例题2**：A-F是初中化学常见物质，A是最常用的溶剂，B是红棕色粉末，C是蓝色溶液，D是浅绿色溶液，E是红色固体，F是白色沉淀。
推断：A=H₂O，B=Fe₂O₃，C=CuSO₄，D=FeSO₄，E=Cu，F=BaSO₄

## 易错点提醒

### 易错点1：BaSO₄和AgCl溶于酸
**正确**：BaSO₄和AgCl不溶于稀硝酸，这是重要的鉴别特征

### 易错点2：Fe³⁺与Fe²⁺颜色混淆
**正确**：Fe³⁺溶液黄色，Fe²⁺溶液浅绿色

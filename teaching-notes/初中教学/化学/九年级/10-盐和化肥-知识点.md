# 盐 化肥 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第十一单元 盐 化肥
- **重要程度**: 重点

## 知识内容

### 1. 盐的性质

**定义**：由金属离子（或铵根离子）和酸根离子构成的化合物

**常见的盐**：
| 盐 | 化学式 | 俗称 | 用途 |
|----|--------|------|------|
| 氯化钠 | NaCl | 食盐 | 调味品、融雪剂、生理盐水 |
| 碳酸钠 | Na₂CO₃ | 纯碱、苏打 | 洗涤剂、玻璃、造纸 |
| 碳酸氢钠 | NaHCO₃ | 小苏打 | 发酵粉、治疗胃酸过多 |
| 碳酸钙 | CaCO₃ | - | 建筑材料、补钙剂 |
| 硫酸铜 | CuSO₄ | - | 杀菌剂、电镀、游泳池消毒 |

### 2. 盐的化学性质

#### （1）盐 + 金属 → 新盐 + 新金属
```
Fe + CuSO₄ → FeSO₄ + Cu
Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag
```
**条件**：金属活动性顺序中，前面的金属能把后面的金属从其盐溶液中置换出来

#### （2）盐 + 酸 → 新盐 + 新酸
```
CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl
```

#### （3）盐 + 碱 → 新盐 + 新碱
```
2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄
3NaOH + FeCl₃ → Fe(OH)₃↓ + 3NaCl
```

#### （4）盐 + 盐 → 两种新盐
```
AgNO₃ + NaCl → AgCl↓ + NaNO₃
BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
```

### 3. 复分解反应

**定义**：两种化合物互相交换成分，生成另外两种化合物的反应

**条件**：生成物中有沉淀、气体或水

**记忆口诀**：
> 碱盐可溶反应生，酸盐微溶或可溶
> 盐盐都可溶，生成沉淀才反应

### 4. 化肥

#### （1）氮肥
- 作用：促进植物茎、叶生长茂盛，叶色浓绿
- 常见氮肥：
  - 尿素 CO(NH₂)₂
  - 铵态氮肥：NH₄HCO₃、NH₄Cl、(NH₄)₂SO₄
  - 硝态氮肥：NaNO₃、NH₄NO₃
- 注意：铵态氮肥不能与碱性物质混合使用

#### （2）磷肥
- 作用：促进植物根系发达，增强抗寒抗旱能力
- 常见磷肥：
  - 磷矿粉 Ca₃(PO₄)₂
  - 钙镁磷肥
  - 过磷酸钙 Ca(H₂PO₄)₂和CaSO₄的混合物

#### （3）钾肥
- 作用：促进植物生长健壮，茎秆粗硬，增强抗病虫害和抗倒伏能力
- 常见钾肥：
  - 硫酸钾 K₂SO₄
  - 氯化钾 KCl

#### （4）复合肥
- 定义：含有两种或两种以上营养元素的化肥
- 常见复合肥：
  - 磷酸二氢铵 NH₄H₂PO₄
  - 硝酸钾 KNO₃

### 5. 离子的检验

| 离子 | 检验方法 | 现象 |
|------|----------|------|
| Cl⁻ | 加AgNO₃溶液和稀HNO₃ | 白色沉淀 |
| SO₄²⁻ | 加Ba(NO₃)₂溶液和稀HNO₃ | 白色沉淀 |
| CO₃²⁻ | 加稀盐酸 | 产生使澄清石灰水变浑浊的气体 |
| NH₄⁺ | 加NaOH溶液并加热 | 产生使湿润红色石蕊试纸变蓝的气体 |

## 典型例题

**例题1**：下列各组物质中，都能溶于水的是（  ）
A. AgCl、BaSO₄    B. Mg(OH)₂、Cu(OH)₂
C. NaCl、KNO₃    D. CaCO₃、BaCO₃

**答案**：C

**例题2**：下列反应中，属于复分解反应的是（  ）
A. Zn + H₂SO₄ → ZnSO₄ + H₂↑
B. CaCO₃ → CaO + CO₂↑
C. NaOH + HCl → NaCl + H₂O
D. 2H₂ + O₂ → 2H₂O

**答案**：C

**例题3**：下列化肥中，属于复合肥的是（  ）
A. NH₄HCO₃    B. KCl    C. Ca(H₂PO₄)₂    D. KNO₃

**答案**：D

## 易错点提醒

### 易错点1：铵态氮肥与碱性物质混用
**错误**：NH₄Cl与草木灰（K₂CO₃）混合使用
**正确**：铵态氮肥不能与碱性物质混合使用，否则会释放氨气，降低肥效

### 易错点2：沉淀颜色记错
**错误**：AgCl是黄色沉淀
**正确**：AgCl是白色沉淀，AgI是黄色沉淀

### 易错点3：复分解反应条件忽略
**错误**：NaCl + KNO₃ → NaNO₃ + KCl
**正确**：没有沉淀、气体或水生成，反应不发生

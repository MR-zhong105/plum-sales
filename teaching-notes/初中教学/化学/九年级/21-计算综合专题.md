# 化学计算综合专题

> 中考核心计算题型

## 知识内容

### 1. 根据化学式的计算

**相对分子质量**：Mr = 各原子相对原子质量×原子个数之和

**元素质量分数**：ω = (该元素相对原子质量×原子个数/相对分子质量)×100%

**化合物中某元素质量**：m(元素) = m(化合物)×ω(元素)

### 2. 根据化学方程式的计算

**基本步骤**：
1. 设未知数
2. 写出化学方程式
3. 标出已知量和未知量
4. 列比例式求解
5. 写出答案

**注意**：
- 化学方程式必须配平
- 已知量必须是纯净物的质量
- 单位要统一

### 3. 含杂质物质的计算

**公式**：
- 纯净物质量 = 混合物质量×纯度
- 纯度 = 纯净物质量/混合物质量×100%

### 4. 溶液计算

**溶质质量分数**：ω = m(溶质)/m(溶液)×100%

**稀释问题**：m(浓)×ω(浓) = m(稀)×ω(稀)

**溶液混合**：m(总)=m(1)+m(2)，m(溶质总)=m(溶质1)+m(溶质2)

### 5. 综合计算题型

**题型1**：不纯物质参与反应
**题型2**：溶液参与反应
**题型3**：多次反应计算
**题型4**：表格数据分析
**题型5**：图像数据分析

## 典型例题

**例题1**：（中考题）将10g石灰石（主要成分CaCO₃）与足量稀盐酸反应，生成CO₂ 3.52g，求石灰石中CaCO₃的质量分数。
**解**：
CaCO₃+2HCl=CaCl₂+H₂O+CO₂↑
100                    44
x                      3.52g
100/x = 44/3.52，x=8g
质量分数 = 8/10×100% = 80%

**例题2**：将50g10%的NaOH溶液与50g10%的HCl溶液混合，求所得溶液的pH。
**解**：
NaOH质量 = 50×10% = 5g
HCl质量 = 50×10% = 5g
NaOH+HCl=NaCl+H₂O
40    36.5
5g    5g
40/5 = 36.5/4.575，HCl过量
剩余HCl = 5-4.575 = 0.425g
溶液呈酸性，pH<7

## 易错点提醒

### 易错点1：用不纯物质质量直接代入计算
**正确**：必须先用纯度换算成纯净物质量

### 易错点2：化学方程式未配平
**正确**：计算前必须先配平化学方程式

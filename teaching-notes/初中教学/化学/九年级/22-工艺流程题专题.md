# 工艺流程题专题

> 中考高频考点

## 知识内容

### 1. 工艺流程题解题步骤

1. **读题干**：了解流程目的、原料、产品
2. **析流程**：分析每一步操作的目的
3. **找原理**：写出相关化学方程式
4. **答问题**：结合问题准确作答

### 2. 常见操作及目的

| 操作 | 目的 |
|------|------|
| 粉碎/研磨 | 增大接触面积，加快反应速率 |
| 搅拌 | 使反应物充分接触 |
| 加热 | 加快反应速率、促进反应进行 |
| 冷却结晶 | 使溶质结晶析出 |
| 过滤 | 分离固体和液体 |
| 洗涤 | 除去表面杂质 |
| 干燥 | 除去水分 |
| 蒸发浓缩 | 使溶液达到饱和 |

### 3. 常见物质转化

**金属冶炼**：
- 炼铁：Fe₂O₃+3CO 高温 2Fe+3CO₂
- 炼铜：CuO+CO △ Cu+CO₂

**海水提镁**：
- MgCl₂+Ca(OH)₂=Mg(OH)₂↓+CaCl₂
- Mg(OH)₂+2HCl=MgCl₂+2H₂O
- MgCl₂ 通电 Mg+Cl₂↑

**工业制纯碱**：
- NaCl+H₂O+NH₃+CO₂=NaHCO₃↓+NH₄Cl
- 2NaHCO₃ △ Na₂CO₃+H₂O+CO₂↑

### 4. 循环物质与副产物

- **循环物质**：流程中既是反应物又是生成物的物质
- **副产物**：主反应之外产生的物质
- **尾气处理**：防止污染，如CO燃烧、SO₂吸收

### 5. 环保与绿色化学

- 原子利用率=目标产物质量/所有产物质量×100%
- 减少污染排放
- 循环利用资源

## 典型例题

**例题1**：工业上用石灰石（主要成分CaCO₃）制取二氧化碳，同时得到生石灰。
(1) 写出反应的化学方程式；
(2) 若加热100g石灰石，得到56g生石灰，求石灰石中CaCO₃的质量分数。

**解**：
(1) CaCO₃ 高温 CaO+CO₂↑
(2) 设CaCO₃质量为x
    CaCO₃→CaO
    100    56
    x      56g
    100/x=56/56，x=100g
    质量分数=100/100×100%=100%

**例题2**：从含Cu、Fe的废旧电器中回收铜和硫酸亚铁。
流程：废旧电器→粉碎→加过量稀硫酸→过滤→滤液A→……→滤渣B→……→铜
(1) 滤渣B的成分是____；
(2) 滤液A中含有的溶质是____；
(3) 加入过量稀硫酸的目的是____。

**答案**：
(1) Cu
(2) FeSO₄、H₂SO₄
(3) 使铁完全反应

## 易错点提醒

### 易错点1：忽略操作步骤的目的
**正确**：每一步操作都有其目的，要结合化学原理分析

### 易错点2：化学方程式未配平
**正确**：工艺流程中涉及的化学方程式必须配平

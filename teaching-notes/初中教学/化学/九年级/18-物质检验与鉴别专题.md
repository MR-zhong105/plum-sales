# 物质检验与鉴别专题

> 中考高频考点

## 知识内容

### 1. 常见气体的检验

| 气体 | 检验方法 | 现象 |
|------|---------|------|
| O₂ | 带火星木条 | 复燃 |
| CO₂ | 澄清石灰水 | 变浑浊 |
| H₂ | 点燃，干冷烧杯罩上方 | 有水雾，淡蓝色火焰 |
| CO | 点燃，产物通入石灰水 | 火焰蓝色，石灰水变浑 |
| HCl | 湿润蓝色石蕊试纸 | 变红，白雾 |
| NH₃ | 湿润红色石蕊试纸 | 变蓝，刺激性气味 |
| SO₂ | 品红溶液 | 褪色，加热恢复红色 |
| 水蒸气 | 无水CuSO₄ | 变蓝 |

### 2. 常见离子的检验

| 离子 | 检验方法 | 现象 |
|------|---------|------|
| H⁺ | 紫色石蕊试液 | 变红 |
| H⁺ | pH试纸 | pH<7 |
| OH⁻ | 无色酚酞试液 | 变红 |
| OH⁻ | 紫色石蕊试液 | 变蓝 |
| Cl⁻ | AgNO₃+稀HNO₃ | 白色沉淀 |
| SO₄²⁻ | BaCl₂+稀HNO₃ | 白色沉淀 |
| CO₃²⁻ | 稀盐酸+石灰水 | 产生气泡，石灰水变浑 |
| NH₄⁺ | NaOH溶液加热 | 产生刺激性气味气体，使红色石蕊试纸变蓝 |
| Ca²⁺ | 碳酸钠溶液 | 白色沉淀 |
| Cu²⁺ | NaOH溶液 | 蓝色沉淀 |
| Fe²⁺ | NaOH溶液 | 白色沉淀→灰绿→红褐色 |
| Fe³⁺ | NaOH溶液 | 红褐色沉淀 |
| Fe³⁺ | KSCN溶液 | 血红色溶液 |

### 3. 常见物质的鉴别

| 物质对 | 鉴别方法 |
|--------|---------|
| 水与双氧水 | 加入MnO₂，有气泡的是双氧水 |
| 空气与氧气 | 带火星木条，复燃的是氧气 |
| 二氧化碳与氮气 | 澄清石灰水，变浑的是CO₂ |
| 硬水与软水 | 加肥皂水，泡沫多的是软水 |
| 氧气与二氧化碳 | 带火星木条/石灰水 |
| 氢氧化钠与碳酸钠 | 加CaCl₂溶液，有沉淀的是碳酸钠 |
| 氯化钠与碳酸钠 | 加稀盐酸，有气泡的是碳酸钠 |
| 氢氧化钠与硝酸铵 | 加水，温度升高的是NaOH |

### 4. 除杂原则

- 不增（不引入新杂质）
- 不减（不减少被提纯物质）
- 易分（操作简单，易分离）
- 复原（被提纯物质恢复原状）

### 5. 常见除杂方法

| 杂质 | 除杂试剂 | 方法 |
|------|---------|------|
| CO₂(CO) | 灼热CuO | 通过 |
| CO(CO₂) | NaOH溶液 | 通过 |
| O₂(H₂O) | 浓H₂SO₄ | 通过 |
| N₂(O₂) | 灼热Cu网 | 通过 |
| CaO(CaCO₃) | 高温煅烧 | - |
| CaCO₃(CaO) | 加水溶解过滤 | 过滤 |
| NaCl(Na₂CO₃) | 稀HCl | 蒸发结晶 |
| Cu(CuO) | 稀H₂SO₄ | 过滤洗涤 |
| CuSO₄(H₂SO₄) | CuO/Cu(OH)₂ | 过滤 |
| FeSO₄(CuSO₄) | Fe粉 | 过滤 |

## 典型例题

**例题1**：（中考题）下列各组物质的鉴别方法中，不可行的是（）
A. 硬水和软水——加肥皂水
B. 氧气和二氧化碳——带火星木条
C. 氢氧化钠和硝酸铵——加水测温度
D. 氯化钠和碳酸钠——加稀硫酸
**答案**：D（NaCl和Na₂CO₃加稀硫酸，Na₂CO₃有气泡，但应该用稀盐酸更合适，不过D也是可行的。正确答案应为不可行的，D中稀硫酸与碳酸钠反应也产生气泡，可以鉴别。此题需重新考虑）

**例题2**：鉴别空气、氧气、二氧化碳三瓶气体，最简单的方法是（）
A. 分别倒入澄清石灰水
B. 分别插入燃着的木条
C. 分别插入带火星的木条
D. 闻气味
**答案**：B

## 易错点提醒

### 易错点1：检验Cl⁻和SO₄²⁻时顺序颠倒
**正确**：先加Ba(NO₃)₂检验SO₄²⁻，再加AgNO₃检验Cl⁻，避免干扰

### 易错点2：除杂时引入新杂质
**正确**：除杂试剂要适量，过量部分要除去

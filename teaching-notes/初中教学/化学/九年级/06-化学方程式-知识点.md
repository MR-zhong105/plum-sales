# 化学方程式 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第四单元 自然界的水
- **重要程度**: 重点

## 知识内容

### 1. 质量守恒定律

**内容**：参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和

**微观解释**：化学反应前后，原子的种类、数目、质量都不变

**应用**：
1. 解释一些化学现象
2. 推断物质的组成
3. 进行有关计算

**注意事项**：
- 质量守恒定律只适用于化学变化
- 气体参加或生成时，要在密闭容器中进行
- 计算时要包括所有反应物和生成物

### 2. 化学方程式

**定义**：用化学式来表示化学反应的式子

**表示意义**：
1. 表示反应物、生成物和反应条件
2. 表示各物质之间的质量比
3. 表示各物质之间的粒子个数比

**书写步骤**：
1. 写：写出反应物和生成物的化学式
2. 配：配平化学方程式
3. 注：注明反应条件和生成物状态
4. 等：将短线改为等号

**配平方法**：
- 最小公倍数法
- 观察法
- 奇数配偶法

### 3. 有关化学方程式的计算

**解题步骤**：
1. 设未知数
2. 写出化学方程式
3. 写出已知量和未知量的质量关系
4. 列比例式求解
5. 写出答案

**注意**：
- 只有纯物质的质量才能代入计算
- 气体体积要换算成质量

## 典型例题

**例题1**：在化学反应A + B = C + D中，10g A与足量B反应生成8g C和4g D，则参加反应的B的质量是（  ）
A. 2g    B. 6g    C. 8g    D. 12g

**答案**：B

**解析**：根据质量守恒定律，m(A) + m(B) = m(C) + m(D)
10g + m(B) = 8g + 4g
m(B) = 2g

**例题2**：写出下列反应的化学方程式：
(1) 铁丝在氧气中燃烧
(2) 加热高锰酸钾制氧气
(3) 电解水

**答案**：
(1) 3Fe + 2O₂ → Fe₃O₄（点燃）
(2) 2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑（加热）
(3) 2H₂O → 2H₂↑ + O₂↑（通电）

**例题3**：加热分解6.3g高锰酸钾，可以得到多少克氧气？

**解**：
设生成氧气的质量为x
```
2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑
316              32
6.3g             x

316/6.3g = 32/x
x = 6.3g × 32/316 ≈ 0.64g
```
答：可以得到0.64g氧气。

## 易错点提醒

### 易错点1：质量守恒定律适用范围
**错误**：质量守恒定律适用于所有变化
**正确**：只适用于化学变化

### 易错点2：化学方程式未配平
**错误**：H₂ + O₂ → H₂O
**正确**：2H₂ + O₂ → 2H₂O

### 易错点3：计算时未用纯物质质量
**错误**：直接用溶液质量计算
**正确**：要用纯溶质的质量

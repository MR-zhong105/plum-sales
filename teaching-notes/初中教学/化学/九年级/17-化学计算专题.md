# 化学计算专题

> 九年级化学中考核心计算题型

## 知识内容

### 1. 根据化学式计算

**相对分子质量**：Mr = 各原子相对原子质量×原子个数之和

**元素质量分数**：
ω = (该元素相对原子质量×原子个数 / 相对分子质量) × 100%

**化合物中某元素质量**：
m(元素) = m(化合物) × ω(元素)

### 2. 根据化学方程式计算

**基本步骤**：
1. 设未知数
2. 写出化学方程式
3. 标出已知量和未知量
4. 列比例式求解
5. 写出答案

**注意**：
- 化学方程式必须配平
- 已知量必须是纯净物的质量
- 单位要统一

### 3. 含杂质物质的计算

**公式**：
- 纯净物质量 = 混合物质量 × 纯度
- 纯度 = 纯净物质量 / 混合物质量 × 100%

### 4. 溶液计算

**溶质质量分数**：ω = m(溶质)/m(溶液) × 100%

**稀释问题**：m(浓)×ω(浓) = m(稀)×ω(稀)

**溶液混合**：m(总)=m(1)+m(2)，m(溶质总)=m(溶质1)+m(溶质2)

### 5. 综合计算题型

**题型1**：不纯物质参与反应
**题型2**：溶液参与反应
**题型3**：多次反应计算
**题型4**：表格数据分析

## 典型例题

**例题1**：（中考题）加热10g高锰酸钾制取氧气，完全反应后剩余固体质量为9.36g，求生成氧气的质量和原高锰酸钾中锰元素的质量分数。
**解**：
生成氧气质量 = 10-9.36 = 0.64g
设参加反应的高锰酸钾质量为x
2KMnO₄ → K₂MnO₄+MnO₂+O₂↑
316                    32
x                      0.64g
316/x = 32/0.64，x = 6.32g

原样品中高锰酸钾质量分数 = 6.32/10 × 100% = 63.2%
锰元素质量 = 6.32 × (55/158) = 2.2g
锰元素质量分数 = 2.2/10 × 100% = 22%

**例题2**：将10g碳酸钙与足量稀盐酸反应，求生成二氧化碳的质量。
**解**：CaCO₃+2HCl=CaCl₂+H₂O+CO₂↑
    100              44
    10g              x
    100/10 = 44/x，x = 4.4g

## 易错点提醒

### 易错点1：用不纯物质质量直接代入计算
**正确**：必须先用纯度换算成纯净物质量

### 易错点2：化学方程式未配平
**正确**：计算前必须先配平化学方程式

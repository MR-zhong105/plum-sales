# 物质的变化和性质 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第一单元 走进化学世界
- **重要程度**: 重点

## 知识内容

### 1. 物理变化

**定义**：没有生成其他物质的变化

**本质**：分子本身没有改变，只是分子间的间隔或排列方式发生改变

**特征**：
- 形状、状态发生改变
- 没有新物质生成

**实例**：
| 变化类型 | 实例 |
|----------|------|
| 状态变化 | 水结冰、酒精挥发、碘升华 |
| 形状变化 | 玻璃破碎、铁丝弯曲、纸张撕碎 |
| 形状+状态 | 蜡烛熔化 |

**记忆技巧**：
> "三态变化"都是物理变化
> 形状改变也是物理变化

### 2. 化学变化

**定义**：生成其他物质的变化（又叫化学反应）

**本质**：分子分裂成原子，原子重新组合成新分子

**特征**：
- 有新物质生成（本质特征）
- 常伴随现象：发光、放热、颜色变化、生成气体、生成沉淀

**实例**：
| 变化 | 现象 | 新物质 |
|------|------|--------|
| 镁条燃烧 | 发出耀眼白光，放热 | 白色粉末(MgO) |
| 铁生锈 | 红色物质 | 铁锈(Fe₂O₃·xH₂O) |
| 食物腐烂 | 变色、变味 | 多种有机物 |
| 光合作用 | 释放氧气 | 葡萄糖和氧气 |
| 蜡烛燃烧 | 发光放热 | CO₂和H₂O |

**注意**：
- 发光放热不一定是化学变化（如灯泡发光）
- 有颜色变化不一定是化学变化（如氧气液化变淡蓝色）
- 有新物质生成才是化学变化的判断依据

### 3. 物理变化与化学变化的关系

**联系**：
1. 化学变化中一定伴随物理变化
2. 物理变化中不一定有化学变化

**区别**：
| 项目 | 物理变化 | 化学变化 |
|------|----------|----------|
| 定义 | 没有生成其他物质的变化 | 生成其他物质的变化 |
| 本质 | 分子本身不变 | 分子变成其他分子 |
| 现象 | 形状、状态改变 | 发光、放热、变色等 |
| 实例 | 水结冰 | 木柴燃烧 |

**判断方法**：
- 看是否有新物质生成
- 有新物质生成 → 化学变化
- 没有新物质生成 → 物理变化

### 4. 物理性质

**定义**：物质不需要发生化学变化就表现出来的性质

**内容**：
| 性质 | 示例 |
|------|------|
| 颜色 | 铜是红色，硫是淡黄色 |
| 状态 | 常温下水是液体 |
| 气味 | 氨气有刺激性气味 |
| 熔点 | 冰的熔点是0℃ |
| 沸点 | 水的沸点是100℃ |
| 硬度 | 金刚石是天然最硬的物质 |
| 密度 | 铁的密度比铝大 |
| 导电性 | 铜能导电 |
| 导热性 | 铁锅导热 |
| 延展性 | 金可以打成金箔 |
| 挥发性 | 酒精易挥发 |
| 溶解性 | 食盐易溶于水 |

**描述方式**：
- "某某是……"
- "某某具有……"
- 如："铜是红色固体"

### 5. 化学性质

**定义**：物质在化学变化中表现出来的性质

**内容**：
| 性质 | 示例 |
|------|------|
| 可燃性 | 木柴可以燃烧 |
| 助燃性 | 氧气能支持燃烧 |
| 稳定性 | 黄金化学性质稳定 |
| 氧化性 | 氧气具有氧化性 |
| 还原性 | 氢气具有还原性 |
| 酸性 | 盐酸能使石蕊变红 |
| 碱性 | 氢氧化钠能使酚酞变红 |
| 毒性 | 一氧化碳有毒 |
| 腐蚀性 | 浓硫酸有腐蚀性 |

**描述方式**：
- "某某能（可以、易、会）……"
- 如："木柴能燃烧"

### 6. 性质与变化的区别

**核心区别**：
- **变化**：描述的是过程（已经发生或正在发生）
- **性质**：描述的是能力（能够发生什么变化）

**判断技巧**：
| 类型 | 关键词 | 示例 |
|------|--------|------|
| 变化 | 描述过程 | 铁生锈、木材燃烧 |
| 性质 | 能、可以、易、会、需 | 铁易生锈、木材能燃烧 |

**易混示例**：
| 句子 | 类型 | 原因 |
|------|------|------|
| 铁生锈 | 变化 | 描述已经发生的过程 |
| 铁易生锈 | 性质 | "易"表示能力 |
| 蜡烛燃烧 | 变化 | 描述过程 |
| 蜡烛能燃烧 | 性质 | "能"表示能力 |
| 水结冰 | 变化 | 描述过程 |
| 水在0℃结冰 | 性质 | 描述在特定条件下会发生 |

**记忆口诀**：
> 性质是能力，变化是过程
> 能、可、易、会——看性质
> 已经、正在——看变化

## 典型例题

**例题1**：下列变化属于化学变化的是（  ）
A. 汽油挥发
B. 木柴燃烧
C. 瓷碗破碎
D. 矿石粉碎

**答案**：B

**解析**：
- A：汽油挥发只是状态变化，无新物质
- B：木柴燃烧生成CO₂和H₂O，有新物质
- C：瓷碗破碎只是形状变化
- D：矿石粉碎只是形状变化

**例题2**：下列描述属于物理性质的是（  ）
A. 铁在潮湿空气中易生锈
B. 水是无色无味的液体
C. 木柴能燃烧
D. 食物容易腐败

**答案**：B

**解析**：
- A："易生锈"是化学性质
- B：颜色、状态是物理性质，正确
- C："能燃烧"是化学性质
- D："容易腐败"是化学性质

**例题3**：判断下列说法正确的是（  ）
A. 物理变化中一定没有化学变化
B. 化学变化中一定伴随物理变化
C. 有发光放热现象的变化一定是化学变化
D. 化学变化和物理变化同时发生

**答案**：B

**解析**：
- A：错误，物理变化中可能有化学变化（如蜡烛熔化同时燃烧）
- B：正确，化学变化中一定伴随物理变化
- C：错误，灯泡发光放热是物理变化
- D：不准确，两者可以独立发生

## 易错点提醒

### 易错点1：混淆性质与变化
**错误**："铁生锈"是化学性质
**正确**："铁生锈"是化学变化，"铁易生锈"是化学性质

**技巧**：看关键词——"能、易、会"是性质，描述过程是变化

### 易错点2：现象判断错误
**错误**：有发光放热的一定是化学变化
**正确**：灯泡发光放热是物理变化

**技巧**：判断依据是新物质生成，不是现象

### 易错点3：忽略了本质特征
**错误**：颜色变化一定是化学变化
**正确**：氧气液化变淡蓝色是物理变化

**技巧**：有新物质生成本质，现象只是辅助判断

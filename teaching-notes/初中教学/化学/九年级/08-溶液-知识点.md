# 溶液 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第九单元 溶液
- **重要程度**: 重点

## 知识内容

### 1. 溶液的概念

**定义**：一种或几种物质分散到另一种物质里，形成均一的、稳定的混合物叫做溶液

**组成**：
- 溶液 = 溶质 + 溶剂
- 能溶解其他物质的物质叫做溶剂
- 被溶解的物质叫做溶质

**特征**：
- 均一性：各部分性质相同
- 稳定性：条件不变时，溶质不会分离出来

**常见溶液**：
| 溶液 | 溶质 | 溶剂 |
|------|------|------|
| 食盐水 | 氯化钠 | 水 |
| 碘酒 | 碘 | 酒精 |
| 糖水 | 糖 | 水 |
| 石灰水 | 氢氧化钙 | 水 |

### 2. 溶解过程

**能量变化**：
- 溶于水放热：NaOH、浓H₂SO₄
- 溶于水吸热：NH₄NO₃
- 温度基本不变：NaCl

### 3. 饱和溶液与不饱和溶液

**定义**：
- 饱和溶液：在一定温度下，一定量的溶剂里，不能再溶解某种溶质的溶液
- 不饱和溶液：还能继续溶解某种溶质的溶液

**转化方法**：
| 饱和 → 不饱和 | 不饱和 → 饱和 |
|---------------|---------------|
| 增加溶剂 | 增加溶质 |
| 升高温度（大多数物质） | 蒸发溶剂 |
| | 降低温度（大多数物质） |

**注意**：饱和溶液不一定是浓溶液，不饱和溶液不一定是稀溶液

### 4. 溶解度

**定义**：在一定温度下，某固态物质在100g溶剂里达到饱和状态时所溶解的质量

**四要素**：
1. 一定温度
2. 100g溶剂
3. 饱和状态
4. 单位：克

**溶解度曲线**：
- 横坐标：温度
- 纵坐标：溶解度
- 曲线上的点：该温度下的饱和溶液
- 曲线下方的点：不饱和溶液
- 曲线上方的点：过饱和溶液（有晶体析出）

**溶解度分类**：
| 溶解度(S) | 分类 |
|-----------|------|
| S > 10g | 易溶 |
| 1g < S < 10g | 可溶 |
| 0.01g < S < 1g | 微溶 |
| S < 0.01g | 难溶 |

### 5. 溶质的质量分数

**公式**：
```
溶质质量分数 = 溶质质量 / 溶液质量 × 100%
             = 溶质质量 / (溶质质量 + 溶剂质量) × 100%
```

**稀释问题**：
```
浓溶液质量 × 浓溶液质量分数 = 稀溶液质量 × 稀溶液质量分数
```

### 6. 结晶

**方法**：
1. 蒸发结晶：适用于溶解度受温度影响较小的物质（如NaCl）
2. 降温结晶：适用于溶解度受温度影响较大的物质（如KNO₃）

## 典型例题

**例题1**：下列关于溶液的说法正确的是（  ）
A. 溶液都是无色的
B. 溶液中各部分的性质相同
C. 溶液中只能有一种溶质
D. 溶液中的溶质一定是固体

**答案**：B

**例题2**：t℃时，向盛有10g水的试管中加入2g NaCl，充分溶解后，试管底部有少量NaCl固体。下列说法正确的是（  ）
A. 此时溶液是不饱和溶液
B. 升高温度，试管底部的固体可能减少
C. 加入10g水，试管底部的固体一定减少
D. 该温度下，NaCl的溶解度是20g

**答案**：B

**例题3**：将50g溶质质量分数为98%的浓硫酸稀释成10%的稀硫酸，需要加水多少克？

**解**：
设需要加水x克
```
50g × 98% = (50g + x) × 10%
49g = 5g + 0.1x
0.1x = 44
x = 440g
```
答：需要加水440克。

## 易错点提醒

### 易错点1：饱和溶液一定是浓溶液
**错误**：饱和溶液一定是浓溶液
**正确**：饱和溶液不一定是浓溶液，如氢氧化钙的饱和溶液就很稀

### 易错点2：溶解度与温度无关
**错误**：溶解度与温度无关
**正确**：大多数固体物质的溶解度随温度升高而增大

### 易错点3：稀释时溶质质量改变
**错误**：稀释时溶质质量改变
**正确**：稀释时溶质质量不变，只改变溶剂质量

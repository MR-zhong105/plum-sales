# 酸和碱 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第十单元 酸和碱
- **重要程度**: 重点

## 知识内容

### 1. 常见的酸

#### （1）盐酸（HCl）
- 物理性质：无色液体，有刺激性气味，易挥发
- 用途：除铁锈、制药

#### （2）硫酸（H₂SO₄）
- 物理性质：无色黏稠液体，难挥发
- 特性：
  - 吸水性：可作干燥剂
  - 脱水性：能将有机物中的H、O按水的比例脱去
- 稀释：将浓硫酸沿器壁慢慢倒入水中，并不断搅拌

#### （3）酸的通性
| 性质 | 方程式 |
|------|--------|
| 与指示剂反应 | 使紫色石蕊变红，无色酚酞不变色 |
| 与活泼金属反应 | Zn + H₂SO₄ → ZnSO₄ + H₂↑ |
| 与金属氧化物反应 | Fe₂O₃ + 3H₂SO₄ → Fe₂(SO₄)₃ + 3H₂O |
| 与碱反应 | HCl + NaOH → NaCl + H₂O |
| 与盐反应 | CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ |

### 2. 常见的碱

#### （1）氢氧化钠（NaOH）
- 俗称：烧碱、火碱、苛性钠
- 物理性质：白色固体，易潮解，易溶于水并放热
- 用途：造纸、肥皂、石油、纺织

#### （2）氢氧化钙（Ca(OH)₂）
- 俗称：熟石灰、消石灰
- 物理性质：白色粉末，微溶于水
- 用途：改良酸性土壤、配制波尔多液

#### （3）碱的通性
| 性质 | 方程式 |
|------|--------|
| 与指示剂反应 | 使紫色石蕊变蓝，无色酚酞变红 |
| 与非金属氧化物反应 | 2NaOH + CO₂ → Na₂CO₃ + H₂O |
| 与酸反应 | HCl + NaOH → NaCl + H₂O |
| 与盐反应 | 2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄ |

### 3. 中和反应

**定义**：酸和碱作用生成盐和水的反应

**实质**：H⁺ + OH⁻ → H₂O

**应用**：
- 改良酸性土壤
- 处理工厂废水
- 服用胃酸过多药物
- 被蚊虫叮咬涂肥皂水

### 4. pH值

**定义**：表示溶液酸碱性强弱的程度

| pH范围 | 酸碱性 |
|--------|--------|
| pH < 7 | 酸性，pH越小酸性越强 |
| pH = 7 | 中性 |
| pH > 7 | 碱性，pH越大碱性越强 |

**测定方法**：pH试纸

**注意**：不能将pH试纸润湿，不能直接伸入溶液中

### 5. 盐

**定义**：由金属离子（或铵根离子）和酸根离子构成的化合物

**常见的盐**：
| 盐 | 化学式 | 用途 |
|----|--------|------|
| 氯化钠 | NaCl | 调味品、融雪剂 |
| 碳酸钠 | Na₂CO₃ | 洗涤剂、玻璃 |
| 碳酸氢钠 | NaHCO₃ | 发酵粉、治疗胃酸 |
| 碳酸钙 | CaCO₃ | 建筑材料、补钙剂 |
| 硫酸铜 | CuSO₄ | 杀菌剂、电镀 |

## 典型例题

**例题1**：下列物质中，属于碱的是（  ）
A. NaCl    B. H₂SO₄    C. NaOH    D. CO₂

**答案**：C

**例题2**：稀盐酸和稀硫酸具有相似的化学性质，其本质原因是（  ）
A. 都含有氢元素
B. 都能使指示剂变色
C. 溶液中都有H⁺
D. 溶液中都有酸根离子

**答案**：C

**例题3**：用pH试纸测定某溶液的pH时，先将试纸润湿，则测定结果（  ）
A. 偏大    B. 偏小    C. 无影响    D. 无法确定

**答案**：D

**解析**：
- 若溶液呈酸性，润湿后酸性减弱，pH偏大
- 若溶液呈碱性，润湿后碱性减弱，pH偏小
- 若溶液呈中性，无影响
- 所以无法确定

## 易错点提醒

### 易错点1：浓硫酸稀释方法错误
**错误**：将水倒入浓硫酸中
**正确**：将浓硫酸沿器壁慢慢倒入水中，并不断搅拌

### 易错点2：pH试纸润湿
**错误**：用蒸馏水润湿pH试纸
**正确**：pH试纸不能润湿，直接蘸取待测液

### 易错点3：中和反应是复分解反应
**错误**：中和反应不一定是复分解反应
**正确**：中和反应是酸和碱生成盐和水的反应，属于复分解反应

# 金属和金属材料 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第八单元 金属和金属材料
- **重要程度**: 重点

## 知识内容

### 1. 金属的物理性质

**共性**：
- 有金属光泽
- 良好的导电性、导热性
- 良好的延展性
- 熔点较高、硬度较大
- 密度较大

**特性**：
| 金属 | 特性 | 用途 |
|------|------|------|
| 钨 | 熔点最高 | 灯丝 |
| 汞 | 常温液态 | 温度计 |
| 金 | 黄色 | 装饰品 |
| 铜 | 红色 | 导线 |
| 铝 | 银白色、密度小 | 飞机制造 |

### 2. 合金

**定义**：在金属中加热熔合某些金属或非金属，制得的具有金属特征的物质

**特性**：
- 硬度比纯金属大
- 熔点比纯金属低
- 抗腐蚀性更好
- 颜色更鲜艳

**常见合金**：
| 合金 | 组成 | 用途 |
|------|------|------|
| 生铁 | 铁、碳 | 机器零件 |
| 钢 | 铁、碳 | 建筑、桥梁 |
| 黄铜 | 铜、锌 | 乐器 |
| 青铜 | 铜、锡 | 艺术制品 |
| 焊锡 | 锡、铅 | 焊接 |
| 硬铝 | 铝、铜、镁 | 飞机制造 |

### 3. 金属的化学性质

#### （1）与氧气反应
```
2Mg + O₂ → 2MgO（剧烈燃烧，发出耀眼白光）
3Fe + 2O₂ → Fe₃O₄（剧烈燃烧，火星四射）
2Cu + O₂ → 2CuO（加热变黑）
```

#### （2）与酸反应
```
Zn + H₂SO₄ → ZnSO₄ + H₂↑
Fe + H₂SO₄ → FeSO₄ + H₂↑
Mg + 2HCl → MgCl₂ + H₂↑
```

**规律**：在金属活动性顺序中，排在氢前面的金属能置换出酸中的氢

#### （3）与盐溶液反应
```
Fe + CuSO₄ → FeSO₄ + Cu
Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag
```

**规律**：在金属活动性顺序中，排在前面的金属能把后面的金属从其盐溶液中置换出来

### 4. 金属活动性顺序

**顺序**：K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au

**应用**：
1. 判断金属活动性强弱
2. 判断金属与酸能否反应
3. 判断金属与盐溶液能否反应

**记忆口诀**：
> 钾钙钠镁铝，锌铁锡铅(氢)，铜汞银铂金

### 5. 金属资源的利用和保护

**铁矿石**：
| 矿石 | 主要成分 | 颜色 |
|------|----------|------|
| 赤铁矿 | Fe₂O₃ | 红棕色 |
| 磁铁矿 | Fe₃O₄ | 黑色 |
| 菱铁矿 | FeCO₃ | 褐黄色 |
| 黄铁矿 | FeS₂ | 黄白色 |

**炼铁原理**：
```
Fe₂O₃ + 3CO → 2Fe + 3CO₂（高温）
```

**保护金属资源途径**：
1. 防止金属腐蚀
2. 回收利用废旧金属
3. 有计划、合理地开采矿物
4. 寻找金属替代品

## 典型例题

**例题1**：下列关于金属的说法正确的是（  ）
A.  all metals are solid at room temperature
B. 铝比铁活泼，所以铝比铁更容易生锈
C. 合金的硬度一般比各成分金属大
D. 真金不怕火炼说明金的熔点高

**答案**：C

**例题2**：下列反应中，属于置换反应的是（  ）
A. C + O₂ → CO₂
B. Fe + CuSO�4 → FeSO₄ + Cu
C. CaCO₃ → CaO + CO₂
D. HCl + NaOH → NaCl + H₂O

**答案**：B

**例题3**：将铁片分别放入下列溶液中，溶液质量会增加的是（  ）
A. CuSO₄溶液
B. AgNO₃溶液
C. H₂SO₄溶液
D. NaCl溶液

**答案**：C

**解析**：
A. Fe + CuSO₄ → FeSO₄ + Cu，每56份质量的Fe置换出64份质量的Cu，溶液质量减小
B. Fe + 2AgNO₃ → Fe(NO₃)₂ + 2Ag，每56份质量的Fe置换出216份质量的Ag，溶液质量减小
C. Fe + H₂SO₄ → FeSO₄ + H₂↑，每56份质量的Fe置换出2份质量的H₂，溶液质量增加
D. Fe与NaCl不反应，溶液质量不变

## 易错点提醒

### 易错点1：铝比铁活泼所以更容易生锈
**错误**：铝比铁活泼，所以铝比铁更容易生锈
**正确**：铝表面形成致密氧化膜，阻止进一步氧化

### 易错点2：金属活动性顺序记错
**错误**：K Ca Na Mg Al Fe Zn...
**正确**：K Ca Na Mg Al Zn Fe...

### 易错点3：置换反应判断错误
**错误**：CO + CuO → Cu + CO₂是置换反应
**正确**：置换反应是一种单质和一种化合物反应生成另一种单质和另一种化合物

# 空气 知识点

## 基本信息

- **学科**: 化学
- **年级**: 九年级
- **所属单元**: 第二单元 我们周围的空气
- **重要程度**: 重点

## 知识内容

### 1. 空气的组成

**测定实验**：拉瓦锡实验

**现代测定**：红磷燃烧法

**实验原理**：
```
红磷 + 氧气 → 五氧化二磷
   点燃
```

**实验现象**：
1. 红磷燃烧，产生大量白烟
2. 冷却后打开止水夹，水进入集气瓶，约占瓶内空气体积的1/5

**实验成功关键**：
1. 装置气密性良好
2. 红磷要过量
3. 冷却后再打开止水夹
4. 点燃后要迅速伸入集气瓶并塞紧

**误差分析**：
- 结果偏小：红磷不足、装置漏气、未冷却就打开止水夹
- 结果偏大：点燃后伸入过慢、止水夹未夹紧

**结论**：空气主要由氮气和氧气组成

| 气体 | 体积分数 | 性质 | 用途 |
|------|----------|------|------|
| 氮气(N₂) | 78% | 无色无味，不易溶于水，化学性质不活泼 | 保护气、制硝酸和化肥 |
| 氧气(O₂) | 21% | 无色无味，不易溶于水，化学性质较活泼 | 供给呼吸、支持燃烧 |
| 稀有气体 | 0.94% | 无色无味，化学性质很不活泼 | 保护气、霓虹灯、激光技术 |
| 二氧化碳(CO₂) | 0.03% | 无色无味，能溶于水 | 灭火、光合作用、化工原料 |
| 其他 | 0.03% | - | - |

### 2. 氧气

**物理性质**：
- 无色、无味气体
- 密度比空气略大
- 不易溶于水
- 三态变化：无色液体→淡蓝色液体→淡蓝色雪花状固体

**化学性质**：比较活泼，能支持燃烧

**与物质反应**：
| 物质 | 现象 | 化学方程式 |
|------|------|------------|
| 木炭 | 发出白光，生成使澄清石灰水变浑浊的气体 | C + O₂ → CO₂ |
| 硫 | 发出蓝紫色火焰，生成有刺激性气味的气体 | S + O₂ → SO₂ |
| 磷 | 产生大量白烟 | 4P + 5O₂ → 2P₂O₅ |
| 铁 | 剧烈燃烧，火星四射，生成黑色固体 | 3Fe + 2O₂ → Fe₃O₄ |
| 铝 | 剧烈燃烧，发出耀眼白光 | 4Al + 3O₂ → 2Al₂O₃ |
| 铜 | 红色固体变黑 | 2Cu + O₂ → 2CuO |
| 镁 | 发出耀眼白光，生成白色固体 | 2Mg + O₂ → 2MgO |
| 石蜡 | 发出白光，瓶壁有水雾，生成使石灰水变浑浊的气体 | - |

**注意**：
- 铁丝燃烧要在集气瓶底部放少量水或细沙
- 硫燃烧要在集气瓶底部放少量水（吸收SO₂，防止污染）

### 3. 空气的污染与保护

**主要污染物**：
- 有害气体：SO₂、NO₂、CO
- 烟尘：可吸入颗粒物

**污染来源**：
- 化石燃料燃烧
- 工业废气
- 汽车尾气

**防护措施**：
1. 加强大气质量监测
2. 使用清洁能源
3. 植树造林
4. 工业废气处理后排放

**空气污染指数(API)**：
- 污染物：SO₂、NO₂、CO、O₃、可吸入颗粒物
- 分数越大，污染越严重，空气质量越差

## 典型例题

**例题1**：下列关于空气的说法正确的是（  ）
A. 空气是由空气分子构成的
B. 空气中氧气的质量分数约为21%
C. 稀有气体化学性质很不活泼，不能与任何物质反应
D. 氮气化学性质不活泼，可用作保护气

**答案**：D

**例题2**：测定空气中氧气含量的实验中，下列说法错误的是（  ）
A. 红磷要过量
B. 实验前要先检查装置气密性
C. 点燃红磷后迅速伸入集气瓶
D. 冷却后打开止水夹，水约占集气瓶容积的4/5

**答案**：D（水约占1/5）

**例题3**：下列关于氧气的说法正确的是（  ）
A. 氧气能支持燃烧，可用作燃料
B. 氧气约占总质量的21%
C. 鱼类能在水中生存，说明氧气易溶于水
D. 物质与氧气发生的反应都是氧化反应

**答案**：D

## 易错点提醒

### 易错点1：空气是纯净物
**错误**：空气是纯净物
**正确**：空气是混合物

### 易错点2：氧气是燃料
**错误**：氧气可以作燃料
**正确**：氧气能支持燃烧，但本身不能燃烧

### 易错点3：氧气易溶于水
**错误**：氧气易溶于水
**正确**：氧气不易溶于水

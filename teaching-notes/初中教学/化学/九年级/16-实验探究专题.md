# 化学实验探究专题

> 中考高频考点

## 知识内容

### 1. 常见气体制备

| 气体 | 药品 | 装置 | 收集方法 | 验满/检验 |
|------|------|------|---------|----------|
| O₂ | KMnO₄或H₂O₂+MnO₂ | 固体加热/固液常温 | 排水/向上排空气 | 带火星木条 |
| CO₂ | CaCO₃+稀HCl | 固液常温 | 向上排空气 | 燃着木条 |
| H₂ | Zn+稀H₂SO₄ | 固液常温 | 排水/向下排空气 | 点燃听声 |

### 2. 常见物质检验

| 物质 | 检验方法 | 现象 |
|------|---------|------|
| O₂ | 带火星木条 | 复燃 |
| CO₂ | 澄清石灰水 | 变浑浊 |
| H₂ | 点燃，干冷烧杯罩上方 | 有水雾 |
| 水蒸气 | 无水CuSO₄ | 变蓝 |
| NH₃ | 湿润红色石蕊试纸 | 变蓝 |
| 碳酸盐 | 加稀盐酸，通入石灰水 | 产生气泡，石灰水变浑 |
| Cl⁻ | AgNO₃+稀HNO₃ | 白色沉淀 |
| SO₄²⁻ | BaCl₂+稀HNO₃ | 白色沉淀 |
| NH₄⁺ | NaOH溶液加热 | 产生刺激性气味气体 |

### 3. 实验注意事项

| 操作 | 注意事项 |
|------|---------|
| 加热固体 | 试管口略向下倾斜 |
| 加热液体 | 试管口向上45°，液体不超过1/3 |
| 称量 | 左物右码，潮湿药品用玻璃器皿 |
| 过滤 | 一贴二低三靠 |
| 蒸发 | 用玻璃棒搅拌，大量固体时停止加热 |
| 稀释浓硫酸 | 酸入水，沿器壁，不断搅拌 |
| 闻气体 | 扇闻，不能凑近 |

### 4. 常见实验错误分析

- 试管口未向下倾斜→冷凝水倒流炸裂试管
- 先撤酒精灯后撤导管→水倒吸炸裂试管
- 用燃着的酒精灯引燃另一盏→失火
- 加热时试管外壁有水→炸裂

## 典型例题

**例题1**：设计实验证明某气体是CO₂
**答案**：将气体通入澄清石灰水，若石灰水变浑浊，则该气体是CO₂

**例题2**：实验室用大理石和稀盐酸制取CO₂，选择什么发生装置？如何验满？
**答案**：固液常温型装置；将燃着的木条放在集气瓶口，若木条熄灭则已满

## 易错点提醒

### 易错点1：BaSO₄和AgCl的鉴别
**正确**：两者都不溶于稀硝酸，但AgCl不溶于稀硝酸，BaSO₄也不溶，需结合其他离子判断

### 易错点2：CO₂验满 vs 检验
**正确**：验满用燃着木条放瓶口；检验用澄清石灰水

# 推断题综合专题

> 中考高频考点

## 知识内容

### 1. 推断题解题步骤

1. **审题**：仔细阅读题目，找出已知条件和未知量
2. **找突破口**：从颜色、沉淀、气体、特殊反应入手
3. **顺推逆推**：从已知条件正向推导，从结论反向验证
4. **代入检验**：将推断结果代入原题验证

### 2. 常见突破口

**颜色突破口**：
- 蓝色溶液：Cu²⁺
- 浅绿色溶液：Fe²⁺
- 黄色溶液：Fe³⁺
- 红色固体：Cu、Fe₂O₃
- 黑色固体：C、CuO、Fe₃O₄、MnO₂、Fe粉
- 白色沉淀：CaCO₃、BaCO₃、AgCl、BaSO₄、Ca(OH)₂
- 蓝色沉淀：Cu(OH)₂
- 红褐色沉淀：Fe(OH)₃

**气体突破口**：
- CO₂：使澄清石灰水变浑浊
- O₂：使带火星木条复燃
- H₂：点燃有淡蓝色火焰
- HCl：白雾，使蓝色石蕊试纸变红
- NH₃：使湿润红色石蕊试纸变蓝
- SO₂：使品红溶液褪色

**沉淀突破口**：
- 白色沉淀溶于酸：CaCO₃、BaCO₃
- 白色沉淀不溶于酸：AgCl、BaSO₄
- 蓝色沉淀：Cu(OH)₂
- 红褐色沉淀：Fe(OH)₃

### 3. 常见物质转化关系

```
C → CO → CO₂
CaCO₃ → CaO → Ca(OH)₂ → CaCO₃
H₂O₂ → H₂O → O₂
Fe → Fe₃O₄ → Fe
Cu → CuO → CuSO₄ → Cu
```

### 4. 推断题常见模型

**框图型**：给出物质转化框图
**表格型**：给出实验现象表格
**叙述型**：给出文字描述

## 典型例题

**例题1**：A-F是初中化学常见物质，A是最常用的溶剂，B是红棕色粉末，C是蓝色溶液，D是浅绿色溶液，E是红色固体，F是白色沉淀。
推断：A=H₂O，B=Fe₂O₃，C=CuSO₄，D=FeSO₄，E=Cu，F=BaSO₄

**例题2**：A-E是初中化学常见物质，A是大理石主要成分，B是胃酸主要成分，C是气体，D是白色沉淀，E是蓝色沉淀。
推断：A=CaCO₃，B=HCl，C=CO₂，D=CaCO₃，E=Cu(OH)₂

## 易错点提醒

### 易错点1：沉淀颜色记错
**正确**：AgCl和BaSO₄都是白色且不溶于酸

### 易错点2：推断时不考虑所有条件
**正确**：要将所有条件代入验证

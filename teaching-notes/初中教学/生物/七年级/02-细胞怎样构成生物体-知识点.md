# 细胞怎样构成生物体

> 七年级生物核心知识点

## 知识内容

### 1. 细胞分裂

**过程**：
1. 细胞核先分裂（染色体复制后均分）
2. 细胞质分裂
3. 形成新的细胞膜（植物还形成细胞壁）

**意义**：细胞数目增加

**染色体变化**：分裂前染色体复制→分裂时均分到两个子细胞→子细胞染色体数目与母细胞相同

### 2. 细胞分化

**定义**：细胞在形态、结构和功能上发生差异性的变化

**结果**：形成不同的**组织**

**过程**：细胞分裂→细胞生长→细胞分化→组织

### 3. 动物体的结构层次

细胞 → 组织 → 器官 → 系统 → 动物体

**四大组织**：
| 组织 | 特点 | 功能 | 示例 |
|------|------|------|------|
| 上皮组织 | 细胞排列紧密 | 保护、分泌 | 皮肤上皮、消化道内壁 |
| 肌肉组织 | 肌细胞构成 | 收缩和舒张 | 心肌、骨骼肌、平滑肌 |
| 神经组织 | 神经元构成 | 感受刺激、传导兴奋 | 大脑、脊髓 |
| 结缔组织 | 细胞间隙大 | 支持、连接、保护、营养 | 骨、血液、脂肪 |

### 4. 植物体的结构层次

细胞 → 组织 → 器官 → 植物体（无系统）

**六大器官**：
- 营养器官：根、茎、叶
- 生殖器官：花、果实、种子

**四大组织**：
| 组织 | 功能 |
|------|------|
| 保护组织 | 保护内部结构 |
| 营养组织 | 储存营养物质 |
| 输导组织 | 运输水、无机盐、有机物 |
| 分生组织 | 分裂产生新细胞 |

### 5. 细胞分裂 vs 细胞分化

| 对比项 | 细胞分裂 | 细胞分化 |
|--------|---------|---------|
| 结果 | 细胞数目增多 | 形成不同组织 |
| 染色体变化 | 复制后均分 | 不变 |
| 本质 | 细胞数量增加 | 细胞形态功能特化 |

## 典型例题

**例题1**：（中考题）细胞分裂过程中，变化最明显的结构是（）
A. 细胞壁  B. 细胞膜  C. 细胞质  D. 染色体
**答案**：D

**例题2**：人体的结构层次从微观到宏观正确的是（）
A. 细胞→组织→器官→系统→人体
B. 细胞→器官→组织→系统→人体
C. 细胞→组织→系统→器官→人体
D. 细胞→器官→系统→组织→人体
**答案**：A

**例题3**：植物体没有的结构层次是（）
A. 细胞  B. 组织  C. 器官  D. 系统
**答案**：D

## 易错点提醒

### 易错点1：植物有系统
**错误**：植物体有系统这一结构层次
**正确**：植物体无系统，直接由器官构成植物体

### 易错点2：细胞分化后染色体改变
**错误**：细胞分化后染色体数目减半
**正确**：细胞分化过程中染色体数目不变，只是基因选择性表达

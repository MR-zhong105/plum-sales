# 细胞是生命活动的基本单位

> 七年级生物核心知识点

## 知识内容

### 1. 细胞发现史

- 1665年，英国科学家**罗伯特·胡克**用显微镜观察软木薄片，发现蜂窝状小室，命名为"cell"（细胞）
- 17世纪，**列文虎克**首次观察到活细胞（细菌、红细胞等）
- 19世纪，**施莱登和施旺**提出细胞学说：一切动植物都是由细胞构成的

### 2. 细胞的基本结构

**植物细胞**（特有结构用绿色标注）：

| 结构 | 功能 |
|------|------|
| **细胞壁** | 保护和支持细胞 |
| **细胞膜** | 控制物质进出 |
| **细胞质** | 生命活动的主要场所 |
| **细胞核** | 含有遗传物质，控制生命活动 |
| **液泡** | 含细胞液，溶解多种物质 |
| **叶绿体** | 光合作用场所（绿色部分） |
| **线粒体** | 呼吸作用场所，提供能量 |

**动物细胞**：细胞膜、细胞质、细胞核、线粒体（无细胞壁、液泡、叶绿体）

### 3. 动植物细胞对比

| 对比项 | 植物细胞 | 动物细胞 |
|--------|---------|---------|
| 细胞壁 | ✅ | ❌ |
| 细胞膜 | ✅ | ✅ |
| 细胞质 | ✅ | ✅ |
| 细胞核 | ✅ | ✅ |
| 液泡 | ✅（大） | ❌（小或无） |
| 叶绿体 | ✅（绿色部分） | ❌ |
| 线粒体 | ✅ | ✅ |

### 4. 细胞核的功能

- 含有**染色体**（由DNA和蛋白质组成）
- DNA是遗传物质，携带遗传信息
- 细胞核是细胞生命活动的控制中心

## 典型例题

**例题1**：洋葱表皮细胞和人体口腔上皮细胞都具有的结构是（）
A. 细胞壁、细胞膜、细胞质
B. 细胞膜、细胞质、细胞核
C. 细胞壁、液泡、叶绿体
D. 细胞膜、液泡、细胞核
**答案**：B

**例题2**：（中考题）细胞结构中，控制物质进出细胞的是（）
A. 细胞壁  B. 细胞膜  C. 细胞质  D. 细胞核
**答案**：B

**例题3**：植物细胞特有的能量转换器是（）
A. 线粒体  B. 叶绿体  C. 液泡  D. 细胞核
**答案**：B（叶绿体是植物特有，线粒体动植物都有）

## 易错点提醒

### 易错点1：动物细胞有细胞壁
**错误**：动物细胞有细胞壁
**正确**：动物细胞无细胞壁，只有植物细胞有

### 易错点2：所有植物细胞都有叶绿体
**错误**：植物细胞都有叶绿体
**正确**：只有植物绿色部分的细胞才有叶绿体（如根细胞无叶绿体）

### 易错点3：线粒体和叶绿体功能混淆
- **线粒体**：呼吸作用，分解有机物释放能量（动植物都有）
- **叶绿体**：光合作用，合成有机物储存能量（植物特有）

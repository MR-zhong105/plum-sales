# 生物的多样性

> 九年级生物中考核心考点

## 知识内容

### 1. 生物的分类

**分类单位**（从大到小）：界、门、纲、目、科、属、种

**种**是最基本的分类单位

**分类依据**：形态结构、生理功能、遗传特征

### 2. 生物类群

**植物类群**：
| 类群 | 特征 | 代表植物 |
|------|------|---------|
| 藻类植物 | 无根茎叶分化，大多水生 | 海带、水绵 |
| 苔藓植物 | 有茎叶，无真根，叶只有一层细胞 | 葫芦藓 |
| 蕨类植物 | 有根茎叶，有输导组织 | 肾蕨、桫椤 |
| 裸子植物 | 种子裸露，无果皮包被 | 松、柏、银杏 |
| 被子植物 | 种子有果皮包被，种类最多 | 水稻、桃树 |

**动物类群**：
| 类群 | 特征 | 代表动物 |
|------|------|---------|
| 腔肠动物 | 有口无肛门，辐射对称 | 水螅、水母 |
| 扁形动物 | 身体扁平，有口无肛门 | 涡虫、猪肉绦虫 |
| 线形动物 | 身体细长，有口有肛门 | 蛔虫 |
| 环节动物 | 身体由许多体节组成 | 蚯蚓 |
| 软体动物 | 身体柔软，有贝壳 | 蜗牛、河蚌 |
| 节肢动物 | 身体分节，有外骨骼 | 昆虫、蜘蛛、虾 |
| 鱼类 | 用鳃呼吸，用鳍游泳 | 鲫鱼 |
| 两栖类 | 幼体用鳃，成体用肺和皮肤 | 青蛙 |
| 爬行类 | 体表有鳞片，用肺呼吸 | 蜥蜴、龟 |
| 鸟类 | 体表覆羽，前肢变成翼 | 麻雀 |
| 哺乳类 | 胎生哺乳，体表被毛 | 家兔 |

### 3. 病毒

- 无细胞结构，由蛋白质外壳和内部遗传物质组成
- 寄生生活，不能独立生存
- 分类：动物病毒、植物病毒、细菌病毒（噬菌体）

## 典型例题

**例题1**：（中考题）生物分类的基本单位是（）
A. 界  B. 门  C. 种  D. 属
**答案**：C

**例题2**：下列动物中，属于节肢动物的是（）
A. 水螅  B. 涡虫  C. 蝗虫  D. 蚯蚓
**答案**：C

**例题3**：关于病毒的说法正确的是（）
A. 有细胞结构  B. 能独立生活  C. 由蛋白质外壳和内部遗传物质组成  D. 属于原核生物
**答案**：C

## 易错点提醒

### 易错点1：植物分类顺序
**正确顺序**：藻类→苔藓→蕨类→裸子→被子（从简单到复杂）

### 易错点2：节肢动物 vs 环节动物
**区别**：节肢动物有外骨骼和分节的附肢，环节动物体节相似

# 被动语态

> 九年级英语核心语法，中考必考

## 知识内容

### 1. 定义

当主语是动作的承受者时使用被动语态。

### 2. 基本结构

**一般现在时**：am/is/are + done
**一般过去时**：was/were + done
**一般将来时**：will be + done
**含情态动词**：can/must/should + be + done

### 3. 各时态被动语态

| 时态 | 主动语态 | 被动语态 |
|------|----------|----------|
| 一般现在时 | I clean the room. | The room is cleaned (by me). |
| 一般过去时 | I cleaned the room. | The room was cleaned (by me). |
| 一般将来时 | I will clean the room. | The room will be cleaned (by me). |
| 现在进行时 | I am cleaning the room. | The room is being cleaned. |
| 过去进行时 | I was cleaning the room. | The room was being cleaned. |
| 现在完成时 | I have cleaned the room. | The room has been cleaned. |
| 含情态动词 | I can clean the room. | The room can be cleaned. |

### 4. 主动变被动步骤

1. 将宾语变为主语
2. 动词改为"be + 过去分词"形式（be随新主语和时态变化）
3. 原主语变为by短语（可省略）
4. 注意：不及物动词无被动语态

### 5. 常考被动语态句型

- It is said that...（据说...）
- Something must be done to...（必须做某事来...）
- So far, many trees have been planted.（到目前为止，许多树已经被种了。）
- The Great Wall is known all over the world.（长城闻名世界。）

### 6. 不及物动词无被动语态

happen, take place, occur, break out, die, reach, arrive, appear, disappear, exist, last, begin, start, finish

## 典型例题

**例题1**：将下列句子改为被动语态
1. They build this bridge in 2020.
2. People should protect the environment.
3. Someone has stolen my bike.

**答案**：
1. This bridge was built in 2020.
2. The environment should be protected.
3. My bike has been stolen.

**例题2**：（中考题）The Great Wall ___ by people all over the world every year.
A. visits  B. is visited  C. visited  D. was visited
**答案**：B

**例题3**：选择正确答案
(  ) — When ___ the bridge ___? — Last year.
A. did; build  B. was; built  C. has; built  D. do; build
**答案**：B

## 易错点提醒

### 易错点1：be动词形式错误
**错误**：The book write by Lu Xun.
**正确**：The book **was** written by Lu Xun.

### 易错点2：不及物动词用被动
**错误**：The accident was happened yesterday.
**正确**：The accident happened yesterday.（happen无被动）

### 易错点3：现在完成时被动语态
**错误**：The work has been done already.（时态判断错误）
**正确**：So far, the work **has been done**.（already是过去时标志）

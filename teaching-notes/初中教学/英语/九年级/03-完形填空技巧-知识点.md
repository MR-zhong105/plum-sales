# 完形填空技巧

> 初中英语完形填空核心方法

## 知识内容

### 1. 解题步骤

1. **通读全文**：跳过空格，理解文章大意
2. **逐题分析**：结合上下文和语法判断
3. **复查验证**：代入答案，检查是否通顺

### 2. 常见考点类型

| 考点 | 示例 |
|------|------|
| 动词辨析 | go/come, take/bring |
| 名词辨析 | question/problem, friend/enemy |
| 形容词辨析 | happy/glad, big/large |
| 副词辨析 | already/yet, still/already |
| 连词辨析 | but/and, although/though |
| 介词辨析 | in/on/at, by/with |
| 固定搭配 | look forward to, be interested in |
| 上下文逻辑 | 因果、转折、并列、递进 |

### 3. 解题技巧

**上下文提示法**：
- 前文找线索：代词指代、同义词复现
- 后文找答案：转折词后、解释说明

**语法分析法**：
- 时态一致：全文时态保持一致
- 主谓一致：主语和谓语保持数的一致
- 固定搭配：记住常见短语搭配

**逻辑推理法**：
- 因果关系：because, so, therefore
- 转折关系：but, however, although
- 并列关系：and, or, neither...nor

### 4. 易错点

- 只看空格所在句，忽略上下文
- 词义辨析不清
- 固定搭配记忆不牢
- 时态判断错误

## 典型例题

**例题**：I was ___ to hear the good news.
A. excited  B. exciting  C. excite  D. excitement
**答案**：A（人作主语用-ed形容词）

## 易错点提醒

### 易错点1：词义辨析错误
**正确**：注意近义词的细微差别

### 易错点2：时态不一致
**正确**：全文时态保持一致，注意时间状语

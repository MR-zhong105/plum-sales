# 文言文对比阅读专题

> 中考文言文阅读核心题型

## 知识内容

### 1. 对比阅读常见题型

| 题型 | 考查内容 | 答题要点 |
|------|---------|---------|
| 内容概括 | 两文主要内容 | 分别概括，注意异同 |
| 人物比较 | 人物形象异同 | 结合具体语句分析 |
| 观点比较 | 作者观点异同 | 找出中心句比较 |
| 手法比较 | 写作手法异同 | 对比修辞、表现手法 |
| 词语比较 | 同一词语在不同语境中的含义 | 结合上下文解释 |
| 句子翻译 | 关键句子翻译 | 直译为主，意译为辅 |

### 2. 常用对比篇目

| 主题 | 推荐对比篇目 |
|------|-------------|
| 忧国忧民 | 《岳阳楼记》vs《醉翁亭记》 |
| 政治理想 | 《出师表》vs《岳阳楼记》 |
| 生活态度 | 《桃花源记》vs《小石潭记》 |
| 学习态度 | 《送东阳马生序》vs《师说》 |
| 爱国情怀 | 《出师表》vs《满江红》 |
| 游记散文 | 《小石潭记》vs《醉翁亭记》 |

### 3. 答题技巧

**人物形象比较**：
- 先分别概括人物形象
- 再比较相同点和不同点
- 结合具体语句分析

**观点比较**：
- 找出每篇文章的中心句
- 比较观点的相同点和不同点
- 分析产生不同观点的原因

**词语比较**：
- 先分别解释词语在两文中的含义
- 再比较异同
- 结合上下文说明原因

### 4. 常见答题模板

**内容概括题**：
"甲文主要写了……，表达了……。乙文主要写了……，表达了……"

**人物比较题**：
"甲文中的人物……，乙文中的人物……，两者都……，但甲文侧重……，乙文侧重……"

**观点比较题**：
"甲文认为……，乙文认为……，两者都……，但甲文侧重……，乙文侧重……"

## 典型例题

**例题1**：（中考题）比较《岳阳楼记》和《醉翁亭记》中作者的政治理想。
**答案**：
- 《岳阳楼记》：先天下之忧而忧，后天下之乐而乐
- 《醉翁亭记》：与民同乐
- 相同点：都体现了以民为本的思想
- 不同点：《岳阳楼记》侧重忧国忧民，《醉翁亭记》侧重与民同乐

**例题2**：比较《桃花源记》和《小石潭记》中作者的情感。
**答案**：
- 《桃花源记》：表达对理想社会的向往，对现实的不满
- 《小石潭记》：表达被贬后的孤凄悲凉之情
- 相同点：都借景抒情
- 不同点：《桃花源记》情感较积极，《小石潭记》情感较消极

## 易错点提醒

### 易错点1：只答一篇文章的内容
**正确**：必须两文都答，并指出异同

### 易错点2：脱离文本空谈
**正确**：必须结合具体语句分析

# 《桃花源记》知识点

> 陶渊明·东晋

## 基本信息

- **作者**: 陶渊明（约365-427），字元亮，又名潜，私谥"靖节"，世称靖节先生，东晋著名诗人
- **体裁**: 散文（游记）
- **写作背景**: 东晋末年，社会动荡，人民饱受战乱之苦，作者借桃花源表达对理想社会的向往

## 重点句子翻译

1. **忽逢桃花林，夹岸数百步，中无杂树，芳草鲜美，落英缤纷**
   忽然遇到一片桃花林，生长在溪水的两岸，长达几百步，中间没有别的树，芳草鲜嫩美丽，落花纷纷扬扬。

2. **土地平旷，屋舍俨然，有良田、美池、桑竹之属**
   土地平坦开阔，房屋整齐，有肥沃的田地、美丽的池塘和桑树竹林之类。

3. **黄发垂髫，并怡然自乐**
   老人和小孩都安适愉快，自得其乐。

4. **问今是何世，乃不知有汉，无论魏晋**
   （他们）问现在是什么朝代，竟然不知道有过汉朝，更不必说魏晋了。

5. **此人一一为具言所闻，皆叹惋**
   这个人一一给（他们）详细地说出自己听所见闻的事，（他们）都叹息惊讶。

6. **不足为外人道也**
   不值得对外面的人说啊。

## 文章结构

```
第一段：发现桃花源（逢桃林→入桃源）
第二段：访问桃花源（见闻→交谈）
第三段：辞别桃花源（出桃源→报告太守）
第四段：再寻桃花源（寻而不得→后人寻访）
```

## 主旨

本文通过虚构的桃花源景象，反映了作者对美好生活的向往，对黑暗现实的不满，也表达了广大人民反对剥削压迫、反对战争的美好愿望。

## 写作手法

1. **虚实结合**：渔人捕鱼偶入桃源，桃源终不可复寻
2. **对比手法**：桃源美好 vs 现实黑暗
3. **白描手法**：简洁生动地描绘景物
4. **悬念设置**：处处志之→遂迷，不复得路

## 名句默写

1. 描写桃花林美景的句子：**忽逢桃花林，夹岸数百步，中无杂树，芳草鲜美，落英缤纷**
2. 描写桃源人生活状况的句子：**黄发垂髫，并怡然自乐**
3. 表现桃源人热情好客的句子：**便要还家，设酒杀鸡作食**

## 易错点提醒

### 易错点1："妻子"古今异义
**古义**：妻子和儿女；**今义**：男子的配偶

### 易错点2："无论"古今异义
**古义**：不要说，更不必说；**今义**：表示条件关系的连词

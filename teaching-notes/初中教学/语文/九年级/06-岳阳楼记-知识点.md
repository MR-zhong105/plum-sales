# 《岳阳楼记》知识点

> 范仲淹·北宋

## 基本信息

- **作者**: 范仲淹（989-1052），字希文，北宋政治家、文学家
- **体裁**: 散文（记）
- **写作背景**: 庆历五年（1045年），范仲淹被贬邓州，应好友滕子京之请而作

## 重点文言词语

| 词语 | 释义 | 例句 |
|------|------|------|
| 谪 | 贬官 | 滕子京谪守巴陵郡 |
| 属 | 通"嘱"，嘱托 | 属予作文以记之 |
| 横无际涯 | 广阔无边 | 浩浩汤汤，横无际涯 |
| 朝晖 | 早晨的阳光 | 朝晖夕阴 |
| 大观 | 壮丽的景象 | 此则岳阳楼之大观也 |
| 去国 | 离开国都 | 去国怀乡 |
| 忧谗 | 担心被谗言中伤 | 忧谗畏讥 |
| 潜形 | 隐没形体 | 静影沉璧，渔歌互答 |
| 斯人 | 这样的人 | 微斯人，吾谁与归 |

## 重点句子翻译

1. **衔远山，吞长江，浩浩汤汤，横无际涯**
   衔接远山，吞饮长江，水波浩荡，无边无际。

2. **览物之情，得无异乎**
   观赏自然景物而触发的感情，怎能不有所不同呢？

3. **不以物喜，不以己悲**
   不因外物的好坏和自己的得失而或喜或悲。

4. **先天下之忧而忧，后天下之乐而乐**
   在天下人忧愁之前先忧愁，在天下人快乐之后才快乐。

## 文章结构

```
第一段：叙事——重修岳阳楼，属予作文
第二段：写景——洞庭湖全景
第三段：悲景——阴雨天气，迁客骚人多会于此，览物之情得无异乎
第四段：乐景——春光明媚，览物之情
第五段：议论——古仁人之心，不以物喜不以己悲
第六段：抒情——先忧后乐，微斯人吾谁与归
```

## 主旨句

**先天下之忧而忧，后天下之乐而乐**
- 表现作者旷达胸襟和远大政治抱负
- 成为后世仁人志士的人生准则

## 写作手法

1. **叙事简练**：第一段仅63字，交代写作缘由
2. **对比鲜明**：悲景与乐景对比，迁客骚人与古仁人对比
3. **骈散结合**：大量使用四六句式，音韵和谐
4. **借景抒情**：通过景物描写抒发情感

## 名句默写

1. 描写洞庭湖壮阔景象的句子：**衔远山，吞长江，浩浩汤汤，横无际涯**
2. 表现作者旷达胸襟的句子：**不以物喜，不以己悲**
3. 表达作者政治抱负的句子：**先天下之忧而忧，后天下之乐而乐**
4. 表现作者忧国忧民情怀的句子：**居庙堂之高则忧其民，处江湖之远则忧其君**

## 易错点提醒

### 易错点1："是进亦忧，退亦忧"中的"进""退"
**正确**：进指在朝廷做官，退指在江湖为民

### 易错点2："微斯人，吾谁与归"的语气
**正确**：这是反问句，意思是"如果没有这样的人，我和谁一道呢？"

# 九年级文言文阅读方法

> 中考文言文阅读核心方法

## 知识内容

### 1. 九年级必背文言文篇目

- 《桃花源记》陶渊明
- 《小石潭记》柳宗元
- 《岳阳楼记》范仲淹
- 《醉翁亭记》欧阳修
- 《湖心亭看雪》张岱
- 《送东阳马生序》宋濂
- 《出师表》诸葛亮
- 《诗词曲五首》

### 2. 重点实词

| 词语 | 释义 | 示例 |
|------|------|------|
| 之 | ①的 ②代词 ③取消句子独立性 | 前人之述备矣 |
| 以 | ①用 ②因为 ③来 | 以中有足乐者 |
| 而 | ①表转折 ②表顺承 ③表修饰 | 学而不思则罔 |
| 于 | ①在 ②从 ③比 ④对 | 苛政猛于虎也 |
| 为 | ①是 ②做 ③被 ④因为 | 为乡里所患 |
| 其 | ①他的 ②那 ③表推测 | 其真无马邪 |
| 安 | 哪里 怎么 | 安求其能千里也 |
| 若 | ①如果 ②像 ③你 | 若为佣耕 |

### 3. 重点虚词用法

**之**：
- 助词"的"：古之学者必有师
- 取消句子独立性：臣之妻私臣
- 宾语前置标志：何陋之有
- 代词：学而时习之

**以**：
- 介词"用"：以刀劈狼首
- 介词"因为"：以中有足乐者
- 连词"来"：属予作文以记之

### 4. 重点句式

- **判断句**：……者，……也 / ……也
  - 示例：环滁皆山也
- **倒装句**：宾语前置（何陋之有）、状语后置（战于长勺）
- **省略句**：省略主语/宾语
- **被动句**：为……所…… / 见……

### 5. 文言文翻译技巧

- 留（专名不译）、换（古今异义词）、调（倒装句序）、补（省略成分）、删（虚词）、贯（贯通文意）
- 直译为主，意译为辅
- 字字落实，逐字翻译

## 典型例题

**例题1**：翻译"不以物喜，不以己悲"
**答案**：不因外物的好坏和自己的得失而或喜或悲

**例题2**：（中考题）下列加点词意思相同的一项是（）
A. 忘路之远近 / 渔人甚异之
B. 不足为外人道也 / 扶苏以数谏故
C. 乃记之而去 / 乃诈称公子扶苏
D. 或置酒而招之 / 或异二者之为
**答案**：C（都是"于是、就"的意思）

## 易错点提醒

### 易错点1：一词多义不结合语境
**正确**：结合上下文判断词义

### 易错点2：倒装句不调整语序
**正确**：翻译时调整为现代汉语语序

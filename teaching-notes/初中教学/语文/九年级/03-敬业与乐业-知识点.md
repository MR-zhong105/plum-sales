# 《敬业与乐业》知识点

## 基本信息

- **学科**: 语文
- **年级**: 九年级
- **所属单元**: 第三单元
- **课题**: 梁启超《敬业与乐业》
- **课时**: 1课时

## 作者简介

**梁启超**（1873-1929）：
- 字卓如，号任公
- 广东新会人
- 近代思想家、政治家、教育家、史学家、文学家
- 维新派代表人物
- 代表作：《饮冰室合集》

## 写作背景

本文是1922年在上海中华职业学校做的演讲。当时社会动荡，许多人对待工作敷衍塞责，梁启超以此文劝勉人们要敬业乐业。

## 文章结构

```
提出论点：敬业乐业（第1段）
    ↓
论证过程
    ├── 有业之必要（第2段）
    ├── 敬业之重要（第3-6段）
    └── 乐业之重要（第7-9段）
    ↓
总结全篇（第10段）
```

## 中心论点

**敬业乐业**四个字，是人类生活的不二法门。

## 分论点

| 分论点 | 内容 |
|--------|------|
| 有业之必要 | 百行业为先，万恶懒为首 |
| 敬业之重要 | 亘亘专一，敬字为本 |
| 乐业之重要 | 知足保和，乐字为要 |

## 论证方法

### 1. 引用论证

| 引用内容 | 出处 | 作用 |
|----------|------|------|
| "主一无适便是敬" | 朱子 | 解释什么是敬 |
| "当大总统是一件事，拉黄包车也是一件事" | 孔子 | 说明职业无分贵贱 |
| "凡做一件事，便忠于一件事" | 曾文正 | 说明敬业的重要性 |

### 2. 举例论证

- 佝偻丈人承蜩——专心致志
- 当大总统与拉黄包车——职业无贵贱

### 3. 对比论证

- 无业游民与有业之人对比
- 厌职者与敬业者对比

## 重点段落解析

### 一、有业之必要（第2段）

**核心观点**：百行业为先，万恶懒为首

**论证方法**：引用+举例

**目的**：反驳无业游民，强调有业的重要性

### 二、敬业之重要（第3-6段）

**核心观点**：凡做一件事，便忠于一件事，将全副精力集中到这事上头，一点不旁骛，便是敬。

**论证方法**：引用+举例+对比

**关键句子**：
> "用志不分，乃凝于神。"

**赏析**：专心致志，精神集中，才能把事情做好。

### 三、乐业之重要（第7-9段）

**核心观点**：凡职业都是有趣味的，只要你肯继续做下去，趣味自然会发生。

**论证方法**：分析+举例

**四个趣味来源**：
1. 奋斗过程有成就感
2.  competiton有进步
3.  同辈竞争
4.  专心工作，排除杂念

**关键句子**：
> "人生能从自己职业中领略出趣味，生活才有价值。"

## 主题思想

本文阐述了"敬业乐业"的重要性，劝勉人们要有责任心，热爱自己的工作，从中寻找乐趣，实现人生价值。

## 写作特点

1. **结构严谨**：总-分-总结构，层次分明
2. **论证充分**：引用、举例、对比多种方法并用
3. **语言生动**：引用古籍名言，通俗易懂
4. **说服力强**：逻辑严密，理据充分

## 名句赏析

1. **"敬业乐群"**
   - 出处：《礼记·学记》
   - 含义：专心学业，乐于与朋友相处

2. **"主一无适便是敬"**
   - 出处：朱子
   - 含义：专心致志，不三心二意就是敬

3. **"用志不分，乃凝于神"**
   - 出处：《庄子》
   - 含义：专心致志，精神才能集中

4. **"知之者不如好之者，好之者不如乐之者"**
   - 出处：《论语》
   - 含义：懂得它不如爱好它，爱好它不如以它为乐

## 易错点提醒

### 易错点1：中心论点找错
**错误**：有业之必要
**正确**：敬业乐业

### 易错点2：论证方法混淆
**错误**：所有引用都是引用论证
**正确**：引用论证+举例论证+对比论证综合运用

### 易错点3：乐业理解错误
**错误**：乐业就是贪图享乐
**正确**：乐业是从工作中发现趣味，是积极的工作态度

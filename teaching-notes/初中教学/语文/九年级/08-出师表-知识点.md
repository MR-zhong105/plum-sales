# 《出师表》知识点

> 诸葛亮·三国

## 基本信息

- **作者**: 诸葛亮（181-234），字孔明，号卧龙，三国时期蜀汉丞相
- **体裁**: 表（古代臣子向帝王上书陈情言事的一种文体）
- **写作背景**: 建兴五年（227年），诸葛亮准备北伐曹魏，临行前上表后主刘禅

## 重点句子翻译

1. **诚宜开张圣听，以光先帝遗德，恢弘志士之气**
   确实应该广泛听取意见，来发扬光大先帝遗留的美德，振奋志士们的勇气。

2. **不宜妄自菲薄，引喻失义，以塞忠谏之路也**
   不应该随便看轻自己，说话不恰当，从而堵塞了忠臣进谏的道路。

3. **亲贤臣，远小人，此先汉所以兴隆也；亲小人，远贤臣，此后汉所以倾颓也**
   亲近贤臣，疏远小人，这是西汉之所以兴盛的原因；亲近小人，疏远贤臣，这是东汉之所以衰败的原因。

4. **苟全性命于乱世，不求闻达于诸侯**
   在乱世中只求保全性命，不希求在诸侯中闻名显达。

5. **受任于败军之际，奉命于危难之间**
   在战败的时候接受重任，在危难的时候奉命出使。

6. **陛下亦宜自谋，以咨诹善道，察纳雅言**
   陛下也应当自己谋划，询问（治国）的好方法，明察并采纳正确的言论。

## 文章结构

```
第一部分（第1-5段）：分析当前形势，提出三条建议
  - 开张圣听（广开言路）
  - 陟罚臧否（赏罚分明）
  - 亲贤远佞（亲贤臣远小人）

第二部分（第6-7段）：叙述个人经历，表达北伐决心
  - 三顾茅庐
  - 临危受命
  - 白帝城托孤

第三部分（第8-9段）：明确各方职责，表达忠诚
  - 自身职责：攘除奸凶，兴复汉室
  - 对后主期望：咨诹善道，察纳雅言
```

## 主旨

文章以恳切的言辞劝说后主刘禅继承先帝遗志，广开言路，严明赏罚，亲贤远佞，以修明政治，完成兴复汉室的大业，表达了诸葛亮"鞠躬尽瘁，死而后已"的忠贞感情。

## 易错点提醒

### 易错点1："表"的文体特点
**正确**：表是古代臣子向帝王上书陈情言事的一种文体，言辞恳切

### 易错点2：三顾茅庐的时间
**正确**：建安十二年（207年），刘备三顾茅庐请诸葛亮出山

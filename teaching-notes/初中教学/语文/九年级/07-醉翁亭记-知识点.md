# 《醉翁亭记》知识点

> 欧阳修·北宋

## 基本信息

- **作者**: 欧阳修（1007-1072），字永叔，号醉翁，又号六一居士，北宋文学家，"唐宋八大家"之一
- **体裁**: 散文（记）
- **写作背景**: 庆历五年（1045年），欧阳修因支持范仲淹改革被贬滁州知州，故作此记

## 重点句子翻译

1. **环滁皆山也。其西南诸峰，林壑尤美**
   环绕滁州的都是山。那西南的几座山峰，树林和山谷尤其优美。

2. **醉翁之意不在酒，在乎山水之间也**
   醉翁的情趣不在酒上，而在山水之间。

3. **山水之乐，得之心而寓之酒也**
   欣赏山水的乐趣，领会在心里，寄托在酒上。

4. **野芳发而幽香，佳木秀而繁阴**
   野花开放，散发出清幽的香气；美好的树木枝叶繁茂，形成浓郁的绿荫。

5. **朝而往，暮而归，四时之景不同，而乐亦无穷也**
   早晨前往，傍晚回来，四季的景色不同，乐趣也是无穷无尽的。

6. **人知从太守游而乐，而不知太守之乐其乐也**
   人们只知道跟着太守游玩而快乐，却不知道太守以他们的快乐为快乐。

7. **醉能同其乐，醒能述以文者，太守也**
   喝醉了能和大家一起享受快乐，酒醒后能用文章记述这件事的人，是太守。

## 文章结构

```
第一段：交代醉翁亭的位置和命名由来
第二段：描写山间朝暮和四季的景色
第三段：描写滁人游和太守宴
第四段：描写宴罢归和点明主旨
```

## 主旨句

**醉能同其乐，醒能述以文者，太守也。**
**人知从太守游而乐，而不知太守之乐其乐也。**

- 表现作者与民同乐的政治理想
- 抒发被贬后的旷达情怀

## 写作手法

1. ** by name（命名）**: "醉翁"二字点明主旨
2. ** 情景交融**: 山水之乐与政治理想结合
3. ** 骈散结合**: 大量使用"也"字句，节奏舒缓
4. ** 层层设喻**: 由远及近，由面到点

## 名句默写

1. 点明全文主旨的句子：**醉翁之意不在酒，在乎山水之间也**
2. 描写山间朝暮景色的句子：**若夫日出而林霏开，云归而岩穴暝**
3. 描写山间四季景色的句子：**野芳发而幽香，佳木秀而繁阴，风霜高洁，水落而石出者**
4. 表现与民同乐的句子：**醉能同其乐，醒能述以文者，太守也**

## 易错点提醒

### 易错点1："醉翁之意不在酒"的理解
**正确**：本意是不在喝酒，而在于欣赏山水。后比喻本意不在此，而在别的方面。

### 易错点2："乐"的多重含义
- 山水之乐：自然之乐
- 宴之乐：宴饮之乐
- 乐其乐：以百姓之乐为乐（与民同乐）

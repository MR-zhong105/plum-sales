# 《邹忌讽齐王纳谏》知识点

> 《战国策》· 战国

## 基本信息

- **出处**: 《战国策·齐策一》
- **作者**: 刘向（西汉），整理编订
- **体裁**: 史传散文
- **写作背景**: 战国时期，齐威王任用邹忌为相，邹忌以自身经历讽谏齐王广开言路

## 重点句子翻译

1. **吾妻之美我者，私我也；妾之美我者，畏我也；客之美我者，欲有求于我也**
   我的妻子认为我美，是偏爱我；妾认为我美，是害怕我；客人认为我美，是有求于我。

2. **宫妇左右莫不私王，朝廷之臣莫不畏王，四境之内莫不有求于王**
   宫里的妃子和左右侍从没有不偏爱大王的，朝中的大臣没有不害怕大王的，全国的人没有不有求于大王的。

3. **由此观之，王之蔽甚矣**
   由此看来，大王您受蒙蔽很深了！

4. **群臣吏民能面刺寡人之过者，受上赏**
   大小官吏百姓能够当面指责我的过错的，受上等奖赏。

5. **此所谓战胜于朝廷**
   这就是所说的在朝廷上战胜（别国）。

## 文章结构

```
第一段：写邹忌与徐公比美，不自信，询问妻、妾、客
第二段：写邹忌暮寝而思之，悟出道理
第三段：写邹忌讽齐王纳谏
第四段：写齐王纳谏及成效
```

## 写作手法

1. **类比推理**：由家事推到国事，由小见大
2. **设喻说理**：以比美设喻，委婉劝谏
3. **层层推进**：由己及人，由人及君

## 主旨

通过邹忌讽齐王纳谏的故事，说明了统治者只有广开言路、虚心纳谏，才能修明政治，取得胜利。

# 作文写作方法

> 初中语文核心写作方法

## 知识内容

### 1. 记叙文写作要点

**审题**：
- 审清题目要求（文体、字数、内容范围）
- 找出关键词，确定立意

**选材**：
- 真实性：从生活中取材
- 典型性：选择有代表性的材料
- 新颖性：避免陈旧素材

**结构**：
- 开头：点题、设悬念、引出下文
- 中间：详略得当，叙事完整
- 结尾：点题、升华主题、呼应开头

### 2. 开头方法

| 方法 | 示例 |
|------|------|
| 开门见山 | 直接点题，简洁明了 |
| 设置悬念 | 引起读者好奇 |
| 引用名言 | 增加文采 |
| 环境描写 | 烘托气氛 |
| 倒叙开头 | 制造悬念 |

### 3. 结尾方法

| 方法 | 作用 |
|------|------|
| 首尾呼应 | 结构严谨 |
| 升华主题 | 深化主旨 |
| 自然收束 | 水到渠成 |
| 引用名言 | 增强说服力 |
| 发出号召 | 富有感染力 |

### 4. 常见题材

- 成长类：挫折、勇气、坚持
- 亲情类：父母之爱、家庭温暖
- 友情类：友谊、互助
- 校园类：师生情、同学情
- 社会类：文明、环保、责任

### 5. 修辞手法运用

比喻、拟人、排比、夸张、对偶等，使语言生动形象

## 典型例题

**例题1**：以"那一次，我长大了"为题，写一篇600字左右的记叙文
**要点**：选取一件具体事件，写出心理变化过程，体现成长主题

**例题2**：以"温暖"为话题，自拟题目写作
**要点**：可以从亲情、友情、师生情等角度切入，用具体事例表现"温暖"

## 易错点提醒

### 易错点1：跑题
**正确**：始终围绕主题，不偏离题目要求

### 易错点2：空洞无物
**正确**：用具体细节和事例支撑，避免空话套话

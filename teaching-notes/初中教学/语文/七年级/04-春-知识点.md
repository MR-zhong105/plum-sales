# 《春》知识点

## 基本信息

- **学科**: 语文
- **年级**: 七年级
- **所属单元**: 第一单元
- **重要程度**: 重点

## 作者简介

**朱自清**（1898-1948）：
- 原名朱自华，字佩弦
- 江苏扬州人
- 现代著名散文家、诗人、学者、民主战士
- 代表作：《背影》《荷塘月色》《春》《匆匆》
- 风格：语言清新、感情真挚、意境优美

## 写作背景

本文写于1928年，作者经过长期积淀，对春天有深刻感受，文章充满对春天的赞美和热爱。

## 文章结构

```
        春
       /|\
      / | \
    盼春 绘春 颂春
      |    |    |
    第1段 2-7段 8-10段
```

### 一、盼春（第1段）
- 总领全文
- 表达期盼春天的急切心情
- 关键句："盼望着，盼望着，东风来了，春天的脚步近了。"

### 二、绘春（第2-7段）

| 段落 | 画面 | 景物 | 特点 |
|------|------|------|------|
| 第2段 | 春回大地图 | 山、水、太阳 | 欣欣然 |
| 第3段 | 春草图 | 小草 | 嫩、绿、多 |
| 第4段 | 春花图 | 桃、杏、梨、花下蜂蝶 | 艳、多、香 |
| 第5段 | 春风图 | 风、鸟鸣、流水、笛声 | 暖、润、和 |
| 第6段 | 春雨图 | 雨、树叶、草、人的活动 | 细、密、亮 |
| 第7段 | 迎春图 | 乡下人、孩子 | 充满活力 |

### 三、颂春（第8-10段）
三个比喻，层层递进：
1. **娃娃**：新（新生）
2. **小姑娘**：美（美丽）
3. **青年**：力（力量）

## 修辞手法

### 1. 比喻
- "红的像火，粉的像霞，白的像雪"——写花的色彩
- "像母亲的手抚摸着你"——写春风的温柔
- "春天像刚落地的娃娃"——写春天的新生

### 2. 拟人
- "小草偷偷地从土里钻出来"——写春草的生机
- "花下成千成百的蜜蜂嗡嗡地闹着"——写花的繁茂
- "桃树、杏树、梨树，你不让我，我不让你"——写花的争艳

### 3. 排比
- "盼望着，盼望着，东风来了，春天的脚步近了。"
- "春天像刚落地的娃娃……春天像小姑娘……春天像健壮的青年……"

### 4. 引用
- "吹面不寒杨柳风"——引用南宋志南和尚诗句

## 重点词语

| 词语 | 拼音 | 释义 |
|------|------|------|
| 酝酿 | yùn niàng | 文中指各种气息在空气里像发酵似的，越来越浓 |
| 宛转 | wǎn zhuǎn | 形容声音圆润柔和 |
| 烘托 | hōng tuō | 陪衬，使明显突出 |
| 抖擞 | dǒu sǒu | 振奋，振作 |
| 嘹亮 | liáo liàng | 声音清晰圆润，响亮 |
| 卖弄 | mài nong | 炫耀，文中是褒义，指尽情展示 |

## 写作特点

1. **抓住特征**：紧扣"春"的特征来写
2. **顺序清晰**：由物到人到春天，由景到情
3. **修辞丰富**：比喻、拟人、排比综合运用
4. **情景交融**：字里行间充满对春天的热爱
5. **五感并用**：视觉、听觉、嗅觉、触觉、味觉

## 名句赏析

### 1. "小草偷偷地从土里钻出来，嫩嫩的，绿绿的。"
- **手法**：拟人
- **效果**："偷偷地""钻"写出小草破土而出的挤劲，表现春草的顽强生命力
- **特点**：嫩、绿、多

### 2. "红的像火，粉的像霞，白的像雪。"
- **手法**：比喻、排比
- **效果**：写出花的色彩鲜艳，富有层次感
- **顺序**：由浓到淡

### 3. "吹面不寒杨柳风"，不错的，像母亲的手抚摸着你。
- **手法**：引用、比喻
- **效果**：写出春风的温暖和柔美
- **角度**：触觉

### 4. "春天像刚落地的娃娃，从头到脚都是新的，它生长着。"
- **手法**：比喻
- **效果**：突出春天的"新"
- **象征**：新生、希望

## 中心思想

本文通过描绘春草、春花、春风、春雨、迎春五幅图画，表达了作者对春天的赞美和热爱之情，激励人们珍惜春光，奋发向上。

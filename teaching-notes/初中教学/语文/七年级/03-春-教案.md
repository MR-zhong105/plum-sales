# 《春》教案

## 基本信息

- **学科**: 语文
- **年级**: 七年级
- **单元**: 第一单元
- **课题**: 朱自清《春》
- **课时**: 2课时

## 教学目标

### 知识与技能
- 积累重点字词，有感情地朗读课文
- 学习作者细致观察、抓住特征描写景物的方法
- 品味优美生动的语言，学习比喻、拟人等修辞手法

### 过程与方法
- 通过朗读感知课文内容
- 通过品析体会语言美感
- 通过仿写掌握写作方法

### 情感态度与价值观
- 感受春天的美好，培养热爱自然、热爱生活的情感
- 体会作者对春天的赞美和热爱之情

## 教学重难点

**重点**: 
- 有感情地朗读课文，感知内容
- 品味优美语言，学习写作手法

**难点**: 
- 学习作者抓住特征描写景物的方法
- 体会情景交融的写作特点

## 教学过程

### 第一课时

#### 一、导入新课（5分钟）

**导入语**：
春天是诗人赞美的对象，是画家描绘的题材，是音乐家谱写的内容。古往今来，无数文人墨客赞美过春天。今天我们一起学习朱自清先生的散文《春》，看看他是如何描绘春天的。

**板书课题**：春 —— 朱自清

#### 二、作者与背景（5分钟）

**朱自清**（1898-1948）：
- 原名朱自华，字佩弦
- 现代著名散文家、诗人、学者
- 代表作：《背影》《荷塘月色》《春》《匆匆》

**写作背景**：
本文写于1928年，作者经过长期积淀，对春天有深刻感受，文章充满对春天的赞美和热爱。

#### 三、朗读指导（10分钟）

**教师范读**，学生听读，注意：
1. 朗读节奏
2. 重音处理
3. 情感把握

**学生自由朗读**，要求：
- 读准字音
- 把握节奏
- 体会情感

**重点字词**：
| 字 | 拼音 | 释义 |
|----|------|------|
| 酝酿 | yùn niàng | 本义是造酒，文中指各种气息在空气里像发酵似的，越来越浓 |
| 宛转 | wǎn zhuǎn | 形容声音圆润柔和 |
| 烘托 | hōng tuō | 陪衬，使明显突出 |
| 抖擞 | dǒu sǒu | 振奋，振作 |

#### 四、整体感知（15分钟）

**思考**：文章围绕"春"写了哪些内容？

**明确**：
1. **盼春**（第1段）：盼望着，盼望着，东风来了，春天的脚步近了。
2. **绘春**（第2-7段）：
   - 春草图（第3段）
   - 春花图（第4段）
   - 春风图（第5段）
   - 春雨图（第6段）
   - 迎春图（第7段）
3. **颂春**（第8-10段）：春天像刚落地的娃娃……

**结构图**：
```
        春
       /|\
      / | \
    盼春 绘春 颂春
      |    |    |
    第1段 2-7段 8-10段
```

#### 五、作业布置（5分钟）

1. 背诵全文
2. 积累文中优美语句

### 第二课时

#### 一、复习导入（3分钟）

回顾上节课内容：文章结构（盼春-绘春-颂春），五幅画面。

#### 二、品析鉴赏（20分钟）

**1. 春草图赏析（第3段）**

> "小草偷偷地从土里钻出来，嫩嫩的，绿绿的。"

- **手法**：拟人
- **效果**："偷偷地""钻"写出小草破土而出的挤劲，表现春草的生命力
- **特点**：嫩、绿、多

**思考**："嫩嫩的，绿绿的"为什么放在句末？
- 强调春草的特点
- 符合语法习惯（后置定语）

**2. 春花图赏析（第4段）**

> "红的像火，粉的像霞，白的像雪。"

- **手法**：比喻、排比
- **效果**：写出花的色彩鲜艳，富有层次感

> "花下成千成百的蜜蜂嗡嗡地闹着，大小的蝴蝶飞来飞去。"

- **手法**：侧面描写
- **效果**：以蜜蜂、蝴蝶的热闹烘托花的繁茂

**3. 春风图赏析（第5段）**

> "吹面不寒杨柳风"，不错的，像母亲的手抚摸着你。

- **手法**：引用、比喻
- **效果**：写出春风的温暖和柔美

**思考**：作者从哪些感官角度描写春风？
- 触觉：像母亲的手抚摸着你
- 嗅觉：混着青草味儿，还有各种花的香
- 听觉：鸟鸣、流水、短笛

**4. 春雨图赏析（第6段）**

> "像牛毛，像花针，像细丝，密密麻麻地斜织着。"

- **手法**：排比、比喻
- **效果**：写出春雨细密、闪烁、绵长的特点

#### 三、写法探究（10分钟）

**1. 修辞手法**
- 比喻："红的像火，粉的像霞，白的像雪"
- 拟人："小草偷偷地从土里钻出来"
- 排比："春天像刚落地的娃娃……"

**2. 描写角度**
- 由上到下：山→太阳→草→花→风→雨
- 由远到近：花→蜜蜂→蝴蝶
- 由视觉到嗅觉到听觉

**3. 情景交融**
- 字里行间流露出对春天的喜爱和赞美
- 结尾三段直接抒情

#### 四、课堂小结（5分钟）

本文通过盼春、绘春、颂春三个部分，描绘了春草、春花、春风、春雨、迎春五幅图画，表达了作者对春天的赞美和热爱。

**写作启示**：
1. 抓住景物特征
2. 运用多种修辞
3. 调动多种感官
4. 做到情景交融

#### 五、作业布置（2分钟）

1. 背诵全文
2. 仿写一段描写景物的文字（200字左右）


## 教学反思

**成功之处**：
- 朗读指导到位，学生能体会文章情感
- 品析环节学生参与积极，能说出自己的理解

**不足之处**：
- 部分学生对修辞手法的作用理解不够深入
- 仿写环节时间紧张，未能充分展示

**改进措施**：
- 增加修辞手法的专项练习
- 仿写可以作为课后作业，下节课展示评价

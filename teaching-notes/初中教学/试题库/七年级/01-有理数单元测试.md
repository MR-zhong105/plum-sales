# 第一章 有理数 单元测试

## 基本信息

- **学科**: 数学
- **年级**: 七年级
- **试卷类型**: 单元测试
- **总分**: 100分
- **时长**: 90分钟

## 试题内容

### 一、选择题（每题3分，共30分）

1. 下列各数中，是负数的是（  ）
   A. 3    B. 0    C. -2    D. $\frac{1}{2}$

2. 如果收入100元记作+100元，那么支出50元记作（  ）
   A. +50元    B. -50元    C. +150元    D. -150元

3. 下列说法正确的是（  ）
   A. 0是正数
   B. 0是负数
   C. 0是整数
   D. 0是最小的数

4. 有理数-5的相反数是（  ）
   A. 5    B. -5    C. $\frac{1}{5}$    D. $-\frac{1}{5}$

5. $|{-3}|$ 等于（  ）
   A. 3    B. -3    C. $\pm3$    D. $\frac{1}{3}$

6. 下列各组数中，相等的一组是（  ）
   A. $-{3}^{2}$ 和 $(-3)^{2}$
   B. $-{3}^{2}$ 和 $-{3}^{2}$
   C. $-{2}^{3}$ 和 $(-2)^{3}$
   D. $-{2}^{3}$ 和 $-{2}^{3}$

7. 在数轴上，到原点距离等于3的点所表示的数是（  ）
   A. 3    B. -3    C. ±3    D. 6

8. 已知a、b在有理数轴上的位置如图所示，则下列结论正确的是（  ）
   （图略：a在原点左侧，b在原点右侧，|a|>|b|）
   A. a > b    B. a < b    C. |a| < |b|    D. a + b > 0

9. 计算 $(-2) + 5$ 的结果是（  ）
   A. -7    B. 3    C. -3    D. 7

10. 计算 $(-3) \times (-4)$ 的结果是（  ）
    A. -12    B. 12    C. -7    D. 7

### 二、填空题（每空2分，共20分）

11. -7的相反数是______，绝对值是______。

12. 比较大小：$-{3}^{2}$ ______ $(-3)^{2}$（填">"、"<"或"="）

13. 若 $|x| = 5$，则 $x$ = ______。

14. 计算：$(-18) \div 6 =$ ______。

15. 计算：$(-2)^{3} =$ ______。

16. 数轴上点A表示-3，点B表示2，则A、B两点间的距离是______。

17. 若a、b互为相反数，则 $a + b =$ ______。

18. 若a、b互为倒数，则 $ab =$ ______。

19. 计算：$-{1}^{2024} =$ ______。

20. 观察规律：-1, 3, -5, 7, -9, ...，第10个数是______。

### 三、解答题（共50分）

21. （8分）计算下列各题：
    (1) $12 + (-8)$
    (2) $(-15) + 7$
    (3) $(-6) \times 4$
    (4) $(-36) \div (-9)$

22. （10分）把下列各数在数轴上表示出来，并用"<"连接：
    $-3, \ 0, \ 2, \ -1.5, \ 4, \ -2$

23. （10分）计算：
    (1) $(-3) + 7 - (-2)$
    (2) $(-2) \times 3 + (-6) \div 2$
    (3) $-{1}^{4} - (1 - 0.5) \times \frac{1}{3}$
    (4) $-{3}^{2} + 2 \times (-4) - |{-5}|$

24. （12分）已知 $|a| = 3$，$|b| = 2$，且 $a < b$，求 $a + b$ 的值。

25. （10分）某小组6名同学的身高如下（单位：cm）：
    160, 158, 162, 155, 163, 164
    (1) 以160cm为标准，超过记为正，不足记为负，请记录各身高。
    (2) 计算他们的平均身高。

## 参考答案

### 一、选择题
1. C    2. B    3. C    4. A    5. A
6. C    7. C    8. B    9. B    10. B

### 二、填空题
11. 7, 7
12. <
13. ±5
14. -3
15. -8
16. 5
17. 0
18. 1
19. -1
20. 19（注：第n个数为 $(-1)^n \times (2n-1)$）

### 三、解答题
21. (1) 4    (2) -8    (3) -24    (4) 4

22. 数轴略，连接：$-3 < -2 < -1.5 < 0 < 2 < 4$

23. (1) 12    (2) -9    (3) $-\frac{7}{6}$    (4) -18

24. 解：由 $|a|=3$ 得 $a=\pm3$，由 $|b|=2$ 得 $b=\pm2$
    因为 $a < b$，所以 $a=-3$，$b=2$ 或 $b=-2$
    当 $a=-3, b=2$ 时，$a+b=-1$
    当 $a=-3, b=-2$ 时，$a+b=-5$
    所以 $a+b=-1$ 或 $-5$

25. (1) 0, -2, +2, -5, +3, +4
    (2) 平均身高 = $160 + \frac{0+(-2)+2+(-5)+3+4}{6} = 160 + \frac{2}{6} \approx 160.3$ cm
